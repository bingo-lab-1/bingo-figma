# 6.2 · 角色管理

<a id="1-背景与目标"></a>

## 1. 用途

让管理员用勾选的方式定义「这类岗位能做什么」,不用为每个人单独配一遍。

### 使用者

| 角色 | 用来做什么 | 没有会怎样 |
|---|---|---|
| 管理员 | 按岗位建角色,一次定义多人复用 | 每加一个人都要重配一遍权限,配错了也发现不了 |
| 风控 | 核对高风险操作被授予给了哪些角色 | 说不清谁能动钱,出事查不到授权源头 |
| 财务主管 | 确认下属角色只拿到该拿的资金操作 | 只能靠口头约定,权限越用越宽 |

权限是所有干预动作的闸门。角色让授权从「逐人配置」变成「按岗位定义」,
既少配错,也让「谁能做什么」这件事可以被审阅。

### 本次范围
- 不管账号绑定谁、能看哪些推广商(那是账号管理页的事)
- 不定义各业务模块具体有哪些节点(各模块在自己的模块文档里声明)
- 不做审批流 —— 角色改动即时生效,事后靠操作日志复核
- 本版不提供:角色类型、创建人与创建运营商字段;勾选预览面板;编辑前的绑定账号数提示;并发编辑拦截

### 适用范围

| 维度 | 取值 |
|---|---|
| 终端 | Web 后台,桌面优先(设计基准 1440px) |
| 响应式 | 版面按窗口宽度自适应,不做移动端专门适配 |
| 界面语言 | 简体中文 |
| 时区 | 时间按浏览器本地时区展示 |
| 货币 | 不涉及金额 |

## 3. 操作规则

### 角色被账号引用时能否删除(A4)

能。删除时自动解除这些账号的角色,见 R4。

### 新增角色(6.2-R2)

点击添加角色,填写弹窗并保存。

输入信息：角色名称(必填)· 角色标识(必填)· 描述 · 权限节点勾选集合。

1. 判权限;能进入本页的账号都能看到入口,无新增权限时由服务端拒绝
2. 校验角色标识全局唯一,且不是超级管理员保留标识
3. 校验勾中的节点**都真实存在于当前权限目录**,拒绝包含未知节点标识的提交 ——
   防止前端传入伪造节点
4. **不得授予超出自身的权限**:非超级管理员只能勾选自身已持有的节点
5. 保存后立即生效;**已登录的账号下一次请求按新权限判定**,不必重新登录
6. 写操作日志,记录操作人、时间与勾选集合

### 编辑角色(6.2-R3)

点击某行编辑,修改后保存。

输入信息：同 R2。

1. 判权限,回显该角色当前的勾选集合
2. 非超级管理员不能编辑系统角色或权限超出自身的角色
3. 系统角色只能改名称和描述,角色标识与权限不可改
4. 校验同 R2,角色标识不能改成超级管理员保留标识
5. 保存后**即时对该角色下所有账号生效**,不等重新登录
6. 并发编辑不拦截,后保存者覆盖先保存者
7. 写操作日志,记录改动前后的勾选集合差异

### 删除角色(6.2-R4)

点击某行删除并在确认弹窗确认。

输入信息：被删除的角色(单条)。

1. 判权限;非超级管理员不能删除权限超出自身的角色
2. 系统角色不可删除,页面不展示删除入口,服务端同样拒绝
3. 通过检查后删除角色及其勾选关系,**同时解除所有绑定该角色的账号的角色** ——
   这些账号立即不能进入后台,不再出现在账号列表,账号管理页也不能重新绑定
4. 确认弹窗不展示绑定账号数
5. 写操作日志

## 4. 特殊情况

### 边界处理

| # | 场景 | 触发条件 | 预期处理 |
|---|---|---|---|
| E1 | 越权配置 | 无角色管理权限的账号提交新增或编辑 | 拒绝并提示;服务端判定 |
| E2 | 伪造节点 | 请求中包含权限目录里不存在的节点标识 | 拒绝并提示,**不静默忽略未知节点** |
| E3 | 只勾操作节点 | 只勾操作节点未勾同页面的查看节点 | 允许保存;账号看不到该页入口 |
| E4 | 并发编辑覆盖 | 两人同时编辑同一角色 | 后保存者覆盖先保存者,不提示 |
| E5 | 删除仍被引用的角色 | 该角色仍有账号绑定 | 允许删除,账号解除角色(见 R4) |
| E6 | 改动影响面被低估 | 修改一个绑了多个账号的角色 | 不展示绑定账号数,保存后即时对全部账号生效 |
| E7 | 自我降权 | 收回自己所属角色的角色管理权限 | 允许,不额外提示,下一次请求即按新权限判定 |
| E8 | 空角色 | 一个节点都不勾就保存 | 允许保存;绑定该角色的账号没有任何页面权限,不视为全权限 |
| E9 | 授予超出自身的权限 | 非超级管理员勾选自身未持有的节点 | 拒绝,提示不能授予自身不具备的权限 |
| E10 | 系统角色保护 | 修改系统角色的标识或权限,或删除系统角色 | 拒绝;系统角色只能改名称和描述 |

### 新增角色遇到异常时(6.2-R2)

| 错误状况 | 提示 |
|---|---|
| 无新增权限 | 无此操作权限 |
| 角色名称或角色标识为空 | 定位到字段并提示 |
| 角色标识已存在 | 拒绝保存,提示保存失败 |
| 使用超级管理员保留标识 | 超级管理员角色只能由种子数据创建,不能通过接口新建 |
| 勾中了不存在的节点 | 权限不存在 |
| 勾中了自身未持有的节点 | 不能授予自身不具备的权限 |

### 编辑角色遇到异常时(6.2-R3)

| 错误状况 | 提示 |
|---|---|
| 无编辑权限 | 无此操作权限 |
| 目标角色超出自身权限 | 不能管理或授予超出自身权限的角色 |
| 修改系统角色标识 | 系统角色不允许修改标识 |
| 修改系统角色权限 | 系统角色权限不可通过界面修改 |
| 校验类错误 | 同 R2 |

### 删除角色遇到异常时(6.2-R4)

| 错误状况 | 提示 |
|---|---|
| 无删除权限 | 无此操作权限 |
| 系统角色 | 系统角色不可删除 |
| 角色已不存在 | 角色不存在 |

### 页面状态

| 状态 | 表现 |
|---|---|
| 错误 | 提示保存失败,弹窗不关闭,已勾选内容保留 |
| 树无数据 | 权限目录未取到时提示暂无权限数据,保存按钮不禁用 |
| 未归类节点 | 未能归到菜单的权限节点放入「其他」分组,仍可勾选 |

## 5. 验收场景

| 需求编号 | 场景与操作 | 预期结果 |
|---|---|---|
| 6.2-R1 | 角色列表与筛选：进入页面 · 点查询 · 翻页 | 按角色名称、角色标识筛选生效;分页与总数准确 |
| 6.2-R2 | 新增角色：点添加角色并提交 | 必填校验生效;角色标识重复拒绝;勾中的节点保存后与回显一致 |
| 6.2-R3 | 编辑角色：点某行编辑并提交 | 改动**即时对该角色下所有账号生效**;系统角色只能改名称和描述 |
| 6.2-R4 | 删除角色：点删除并确认 | 系统角色不可删除;删除仍被引用的角色时账号解除角色并失去后台访问 |

### 新增角色(6.2-R2)

- 正向:建一个只勾「财务管理 / 币种管理 / 查看币种配置」的角色 →
  绑定该角色的账号只能看到这一个页面,其余菜单不出现
- 正向:保存后重新打开编辑,勾选状态还原
- 正向:一个节点不勾直接保存 → 保存成功,绑定该角色的账号没有页面权限
- 逆向:角色标识重复 → 拒绝;角色名称留空 → 拒绝
- 逆向:构造请求勾中一个不存在的节点标识 → 服务端拒绝,不静默忽略
- 逆向:非超级管理员勾选自身未持有的节点 → 拒绝

### 编辑角色(6.2-R3)

- 正向:给一个已绑 3 个账号的角色加一个节点 → 三个账号下一次请求即拥有该权限,无需重登
- 逆向:修改系统角色的标识 → 拒绝
- 逆向:非超级管理员编辑权限超出自身的角色 → 拒绝
- 边界:两人同时编辑同一角色 → 后保存者覆盖先保存者

### 删除角色(6.2-R4)

- 正向:删除一个无账号绑定的角色 → 删除成功
- 正向:删除仍有账号绑定的角色 → 删除成功,这些账号下一次请求被拒绝进入后台,账号列表不再显示
- 逆向:删除系统角色 → 拒绝
- 逆向:连点两次删除 → 第二次提示角色不存在

### 术语与共用口径

> **权限模型的完整定义见同目录 [`权限模型.md`](权限模型.md)** ——
> 四层树的结构、授权规则、数据范围与全平台节点口径都在那里,本文不重复。

| 术语 | 定义 |
|---|---|
| 角色 | 一组被勾选的权限节点,账号通过绑定它获得功能权限 |
| 角色标识 | 角色的全局唯一代号,不影响权限 |
| 系统角色 | 系统预置的超级管理员角色,鉴权时视同拥有全部权限,不可删除 |

### 依赖与数据流

**数据流向**:管理员在弹窗中勾选权限节点 → 服务端校验节点存在且不超出操作人权限后保存 →
账号管理页给账号绑定该角色 → 各业务页面取数时按该账号的角色判定功能权限 →
操作留痕进操作日志。

**系统串接**:**无外部系统**。权限树的节点集合来自系统预置的权限目录,
不依赖第三方。与各业务模块的关系是**被依赖**:它们声明自己有哪些节点,本页负责勾选。

### 数据归属与职责

**数据归属**

- 拥有(owner=M6):角色 · 角色权限关联
- 只读:权限目录(系统预置,由 6.4 权限管理查看)

**前后端职责**

| 事项 | 归属 |
|---|---|
| 权限判定 | **服务端** |
| 节点存在性与授权不超出自身校验 | **服务端** |
| 系统角色保护 | **服务端**(界面隐藏删除只是体验,不作数) |
| 树的展开、勾选与全选 | 界面 |

### 新增角色的职责(6.2-R2)

| 归属 | 做什么 |
|---|---|
| 界面 | 必填校验、按菜单分组展示权限树、分组全选与已选计数 |
| 服务端 | 权限判定、角色标识唯一性、节点存在性校验、授权范围校验、保存与留痕 |

### 编辑角色的职责(6.2-R3)

| 归属 | 做什么 |
|---|---|
| 界面 | 回显当前勾选;系统角色隐藏权限树并锁定角色标识 |
| 服务端 | 同 R2 的全部校验,外加目标角色范围校验与系统角色保护 |

### 删除角色的职责(6.2-R4)

| 归属 | 做什么 |
|---|---|
| 界面 | 通用删除确认,系统角色不展示删除入口 |
| 服务端 | 目标角色范围校验、系统角色保护、解除账号角色、删除与留痕 |
