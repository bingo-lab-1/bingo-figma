# 6.1 · 用户管理

<a id="1-背景与目标"></a>

## 1. 用途

管理员创建和编辑后台账号，并为账号绑定一个角色。列表只包含已有角色的用户。后台账号新建后同时具有官方渠道下的测试玩家身份，可用于玩家端充值、活动和钱包流程；测试数据是否计入统计按各业务口径执行。

本页提供查询、添加和编辑，不提供删除、批量删除、启停、密码重置、验证码查看/重置、IP 白名单、账号到期时间或推广商范围编辑。登录限制和会员封禁由实际账号认证及会员管理流程执行。

后台桌面页面，简体中文，列表时间按浏览器本地时区显示。

## 2. 配置项

查询条件为用户名、邮箱、姓名，均可留空且可组合，按用户查询服务的包含匹配取数。点击查询应用输入并回到第一页；重置清空条件。

列表展示 ID、用户名、邮箱、姓名、角色、创建时间和编辑按钮。不存在推广商摘要、状态、登录时间或验证码列。没有对应角色显示名称时显示“-”。

| 配置或参数 | 当前规则 |
|---|---|
| A1 每页条数 | 默认 20，可切换 20/50/100 |
| A2 用户名 | 新增必填，去首尾空格、标准账号按小写保存，3～30 位字母、数字或下划线，全局唯一；编辑只读 |
| 邮箱 | 新增必填，校验格式，去首尾空格并小写保存，全局唯一；编辑表单不显示 |
| 姓名 | 新增和编辑必填，保存去首尾空格 |
| A3 密码 | 仅新增必填，服务端要求 8～128 字符，哈希保存；当前不要求 12～64 字符或三类字符组合 |
| A4 角色 | 必填单选，角色必须存在，操作人不得分配超出自身的角色 |
| A5 推广商范围 | 本页无此表单字段。充值与相关活动使用独立运营商范围机制，见权限模型 |
| A6 谷歌验证配置 | 本页不提供；不把原设计中的强制绑定、查看与重置写成当前能力 |
| A7 会话 | 后台登录后最长 30 天，活跃不延长绝对上限；后台禁止自助注册，未绑定角色或被限制登录的账号不能访问 |

## 3. 操作规则

### 新增（6.1-R2）

点“添加用户”，填写用户名、邮箱、姓名、密码和角色。服务端检查创建权限、角色范围和字段合法性；用户名或邮箱重复时拒绝。成功后保存用户、登录凭据和角色，并初始化玩家账号，关闭弹窗刷新列表。

新账号默认 `isTestAccount=true`、语言为英文，按普通无推广链接注册的规则分配官方渠道并初始化钱包等玩家数据。本页不能把测试标记改成正式账号。

### 编辑（6.1-R3）

只提交姓名与角色。服务端要求目标仍是已有后台账号；非系统管理员不能管理系统角色或权限超出自己的账号，也不能授予超出自身的角色。保存后下一次请求按当前角色权限判定，无需重登。允许把自己改为权限更少的角色，不增加自我降权确认。

当前账号新增/编辑流程没有写入通用操作日志的步骤；不能把用户记录保存或测试身份记录当成该页已提供角色变更审计展示。

### 页面未提供的操作（6.1-R4～R6）

本页没有启停、删除、批量删除、查看/重置谷歌验证码。既有登录限制仍由账号状态判断：账号被限制后不允许登录或继续后台访问。角色删除会解除账号角色，使账号从本页列表移出；本页编辑接口不能给已解除角色的普通用户重新绑角色。

## 4. 特殊情况

| 编号 | 场景 | 处理 |
|---|---|---|
| E1 | 无新增/编辑权限 | 服务端拒绝；按钮可见不表示可提交 |
| E2 | 用户名或邮箱重复 | 拒绝并提示邮箱或账号已存在 |
| E3 | 必填内容为空或密码不在 8～128 字符 | 拒绝，表单保留输入 |
| E4 | 用户名不符合 A2 | 拒绝并提示账号格式 |
| E5 | 操作目标或分配角色超出自身权限 | 拒绝 |
| E6 | 角色不存在或已被删除 | 拒绝；重新加载角色选项 |
| E7 | 连续点击保存 | 保存中按钮禁用；当前新增没有客户端请求号幂等契约，不能宣称所有并发提交合并为一笔 |
| E8 | 查询失败 | 列表错误提示及重试，查询条件保留 |
| E9 | 目标角色已解除 | 不能从本页编辑恢复，列表不包含该账号 |
| E10 | 在线账号改绑角色 | 下一次请求按新角色执行 |
| E11 | 操作人改绑自己 | 允许，后续按新权限执行 |

## 5. 验收场景

| 需求编号 | 场景与操作 | 预期结果 |
|---|---|---|
| 6.1-R1 | 组合用户名、邮箱、姓名查询并翻页 | 只返回有角色的匹配账号，列表字段和页数符合第 2 段 |
| 6.1-R2 | 新建合法账号；再提交相同用户名或邮箱 | 首次创建官方渠道测试玩家及登录凭据，重复账号拒绝 |
| 6.1-R2 | 密码分别为 7、8、128、129 字符 | 7/129 拒绝，8/128 可通过长度校验，其他字段仍须合法 |
| 6.1-R3 | 修改姓名、改绑允许的角色、尝试越权角色 | 合法修改保存；用户名只读，邮箱和密码不在编辑表单；越权拒绝 |
| 6.1-R4 | 查看本页操作列 | 没有账号启停开关；账号登录限制不能据此页推断为不存在 |
| 6.1-R5 | 查看删除及批量操作 | 当前没有删除、批量删除入口 |
| 6.1-R6 | 查找谷歌验证码操作 | 当前没有查看、重置和配置入口 |
| 6.1-R7 | 后台会话满 30 天、无角色账号登录、访问后台注册 | 会话失效需重登；无角色拒绝；后台自助注册拒绝 |
