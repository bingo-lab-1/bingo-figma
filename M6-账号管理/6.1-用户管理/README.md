# 6.1 · 用户管理

<a id="1-背景与目标"></a>

## 1. 用途

开通、停用和回收后台账号,并明确每个人能看哪些推广商的数据。

### 使用者

| 角色 | 用来做什么 | 没有会怎样 |
|---|---|---|
| 管理员 | 新人入职开号、离职停号、调岗换角色 | 账号靠口头交接,离职的人还能登进来 |
| 风控 | 核对谁能看到哪些推广商的数据 | 说不清数据边界,跨推广商泄露查不出 |
| 主管 | 给下属设到期时间与登录来源限制 | 外包与临时账号长期有效,没人记得回收 |

后台账号是所有操作的源头。开号快、停号准、边界清,
出事时才能一眼看出是谁做的、他本来该不该有这个权限。

### 本次范围
- 不定义角色里有哪些权限(那是角色列表页,权限模型见该页的辅助文件)
- 不管玩家账号(那是用户管理模块,后台账号与玩家是两回事)
- 不做登录流程本身(登录页、找回密码归基础设施)
- 不做审批流 —— 开号与改号即时生效,事后靠操作日志复核
- 本版不提供:账号删除与批量删除;账号类型、测试账号标记与登录时间;在本页修改用户名、邮箱和密码

### 适用范围

| 维度 | 取值 |
|---|---|
| 终端 | Web 后台,桌面优先(设计基准 1440px) |
| 响应式 | 版面按窗口宽度自适应,不做移动端专门适配 |
| 界面语言 | 简体中文 |
| 时区 | 时间按浏览器本地时区展示 |
| 货币 | 不涉及金额 |

### 配置限制与默认值

| 配置或参数 | 填写与执行规则 |
|---|---|
| 每页条数(A1) | 默认 20 条/页;界面可切换 20 / 50 / 100 |
| 账号名长度(A2) | 3 至 30 位字母、数字或下划线;去首尾空格后转小写保存 |
| 密码强度要求(A3) | 12至64字符,至少包含大写、小写、数字、符号中的三类;不得包含完整账号名 |
| 一个账号可绑角色数(A4) | **1 个**;(弹窗为单选) |
| 一个账号可绑推广商数(A5) | 不限,**至少 1 个**；(弹窗为多选必填) |
| 谷歌验证码默认状态(A6) | 普通账号默认关闭;财务资金权限账号必须绑定启用后才可执行资金操作；界面开关,财务账号不可关闭 |
| 后台登录限制(A7) | 登录后满 30 天强制失效,期间是否活跃不影响;后台不开放自助注册,账号只能由本页创建;未绑定角色的账号不能进入后台 |

## 3. 操作规则

财务账号重置验证器后,资金操作权限保持受限,直到重新绑定完成。

### 新增账号(6.1-R2)

点击添加用户,填写弹窗并保存。

输入信息：见“配置项”弹窗字段。

1. 判权限;能进入本页的账号都能看到入口,无新增权限时由服务端拒绝
2. 校验用户名、邮箱格式、密码强度,姓名与角色非空;校验用户名与邮箱全局唯一、角色存在、所选推广商都存在且启用
3. **不得授予超出自身的范围**:非超级管理员不能分配系统角色,也不能分配权限超出自身的角色;
   操作人只能把**自己已有的推广商**授予他人 ——
   否则任何能开号的人都可以给自己开一个权限更大、能看全部推广商的小号
4. 密码加密存储,任何接口都不回显明文
5. 保存后账号立即可用
6. 写操作日志,记录操作人、被建账号、角色与推广商范围

### 编辑账号(6.1-R3)

点击某行编辑,修改后保存。

输入信息：姓名 · 角色 · 推广商 · 谷歌验证配置 · IP白名单。

1. 判权限;能进入本页的账号都能看到入口,无编辑权限时由服务端拒绝
2. 只能编辑已绑定角色的后台账号
3. 非超级管理员不能编辑系统角色账号或权限超出自身的账号,新角色同样不得超出自身,推广商只能授予自己已有的
4. 保存后下一次请求即按新角色与推广商范围判定,不要求重新登录
5. 写操作日志,记录操作人、被改账号与改动前后的角色和推广商范围

### 启用与停用(6.1-R4)

点击某行的状态开关。

输入信息：目标状态(启用 / 停用)。

1. 判权限
2. 停用:立即禁止登录,并使该账号**已登录的会话同时失效** ——
   只挡登录不挡在线会话,等于停用要等到对方主动退出才生效
3. 启用:恢复登录能力,不重置密码与二次验证配置
4. **不允许停用自己** —— 会把自己锁在外面且无人可恢复
5. 写操作日志

### 删除账号(6.1-R5)

本版不提供。账号不能删除,其操作日志一直保留。

### 查看与重置验证码(6.1-R6)

点击查看验证码 · 点击重置验证码。

输入信息：目标账号(单条)。

1. 判权限;查看与重置**各自独立授权**,不合并
2. **查看**:返回该账号当前的二次验证信息。这个动作等于获得了以该账号身份登录的能力,
   因此必须逐次写操作日志,记录操作人、被查账号与时间
3. **重置**:作废旧的二次验证配置并生成新的,原持有人需重新绑定
4. 两个动作都进操作日志的重点关注项,按操作人与频次汇总

## 4. 特殊情况

### 边界处理

| # | 场景 | 触发条件 | 预期处理 |
|---|---|---|---|
| E1 | 越权开号 | 无新增权限的账号提交 | 拒绝并提示;服务端判定 |
| E2 | 授予超出自身的范围 | 操作人把系统角色、超出自身权限的角色或自己没有的推广商分配给账号 | 拒绝,只能分配不超出自身权限的角色和自己已有的推广商 |
| E3 | 停用不生效 | 停用了账号但对方仍在线 | 停用时同步使已登录会话失效,不等对方退出 |
| E4 | 把自己锁死 | 停用当前登录的账号 | 拒绝 |
| E5 | 账号追溯 | 查询账号历史操作 | 账号不能删除,操作日志按账号标识保留 |
| E6 | 账号过期未回收 | 到期时间已过但仍能操作 | 过期即不能登录,已登录会话同样失效 |
| E7 | 密码或密钥泄露 | 接口回显了密码或谷歌密钥明文 | 一律不回显,列表与详情均脱敏 |
| E8 | 批量删除误操作 | 批量删除勾中了不该删的账号 | 本版不提供批量删除 |
| E9 | 所绑角色被删除 | 角色删除时账号仍绑定该角色(6.2-R4) | 账号解除角色后不能进入后台,不再出现在本页列表,本页也不能重新绑定 |
| E10 | 在线账号被改角色 | 账号在线时被改绑角色,或其角色权限被修改 | 下一次请求即按新角色判定,不等对方退出 |
| E11 | 改绑自己 | 操作人把自己改绑到权限更小的角色 | 允许,不额外提示,保存后立即按新角色判定 |

### 新增账号遇到异常时(6.1-R2)

| 错误状况 | 提示 |
|---|---|
| 无新增权限 | 无此操作权限 |
| 用户名或邮箱已存在 | 邮箱或账号已存在 |
| 必填项未填 | 定位到具体字段并提示 |
| 用户名不符合规则 | 账号须为 3 至 30 位字母、数字或下划线 |
| 邮箱格式错误 | 邮箱格式不正确 |
| 未选推广商 | 请至少选择一个推广商 |
| 所选推广商超出自身范围 | 拒绝并说明只能授予自己已有的推广商 |
| 密码不满足强度 | 按 A3 提示具体要求 |
| 开启二次验证但未填谷歌配置 | 请补齐谷歌地址与密钥 |
| 角色不存在 | 角色不存在或已被删除 |
| 角色超出自身权限 | 不能管理或授予超出自身权限的角色 |

### 编辑账号遇到异常时(6.1-R3)

| 错误状况 | 提示 |
|---|---|
| 无编辑权限 | 无此操作权限 |
| 目标账号未绑定角色 | 只能编辑已有的后台账号 |
| 目标账号或新角色超出自身权限 | 不能管理或授予超出自身权限的角色 |
| 姓名或角色为空 | 名称和角色不能为空 |

### 启用与停用遇到异常时(6.1-R4)

| 错误状况 | 提示 |
|---|---|
| 无状态切换权限 | 提示无权限 |
| 停用自己 | 不能停用当前登录的账号 |
| 重复提交 | 只生效一次 |

### 查看与重置验证码遇到异常时(6.1-R6)

| 错误状况 | 提示 |
|---|---|
| 无查看权限 | 提示无权限,按钮不可见 |
| 无重置权限 | 同上,与查看分别判定 |
| 目标账号未开启二次验证 | 提示该账号未开启,无可查看或重置的内容 |

### 页面状态

| 状态 | 表现 |
|---|---|
| 错误 | 提示错误原因,弹窗不关闭,已填内容保留 |
| 已停用 | 列表中仍可见并明确标注,不从列表消失 |
| 已过期 | 特有态:到期时间已过的账号需可被筛出并明确标注,与手动停用区分开 |
| 未开启二次验证 | 特有态:查看与重置验证码的按钮置灰并说明原因,不是隐藏 |

## 5. 验收场景

| 需求编号 | 场景与操作 | 预期结果 |
|---|---|---|
| 6.1-R1 | 账号列表与筛选：进入页面 · 点查询 · 翻页 | 三项筛选可组合;列表只含已绑定角色的账号;敏感字段脱敏;分页与总数准确 |
| 6.1-R2 | 新增账号：点添加用户并提交 | 用户名与邮箱唯一;角色单选、推广商多选均必填;密码不回显 |
| 6.1-R3 | 编辑账号：点某行编辑并提交 | 改姓名、角色或推广商**即时生效**;用户名只读,邮箱与密码不在编辑弹窗中 |
| 6.1-R4 | 启用与停用：点状态开关 | 停用后立即不能登录,已登录会话同时失效 |
| 6.1-R5 | 删除账号：查看列表 | 当前不提供:列表没有删除与批量删除,操作日志保留 |
| 6.1-R6 | 查看与重置验证码：点查看验证码 · 点重置验证码 | 两个动作均需独立权限并写操作日志 |
| 6.1-R7 | 后台登录限制：登录满 30 天后继续访问 · 用未绑定角色的账号登录 · 访问后台注册入口 | 会话失效须重新登录;未绑定角色的账号被拒绝;后台注册被拒绝 |

### 新增账号(6.1-R2)

- 正向:建一个绑「财务专员」角色、推广商仅 A 的账号 → 该账号只能看到推广商 A 的数据,
  且只能做该角色勾中的操作
- 正向:密码字段在任何列表与详情中都不回显
- 逆向:用户名或邮箱重名 → 拒绝;角色不选 → 拒绝;推广商一个不选 → 拒绝
- 逆向:操作人只有推广商 A,却给新账号勾上 A 与 B → 拒绝
- 逆向:密码不满足 A3 → 拒绝
- 逆向:开启二次验证但谷歌密钥留空 → 拒绝
- 逆向:非超级管理员给新账号分配超出自身权限的角色 → 拒绝

### 编辑账号(6.1-R3)

- 正向:把在线账号改绑到另一角色 → 该账号下一次请求即按新角色判定,无需重新登录
- 逆向:非超级管理员编辑系统角色账号 → 拒绝
- 逆向:只有查看权限的账号提交编辑 → 拒绝

### 启用与停用(6.1-R4)

- 正向:停用一个在线账号 → 该账号当前会话立即失效,再次登录被拒
- 正向:重新启用 → 可正常登录,二次验证配置保持不变
- 逆向:停用自己 → 拒绝
- 逆向:连点两次 → 只生效一次

### 查看与重置验证码(6.1-R6)

- 正向:查看某账号验证码 → 操作日志立即出现一条记录,含操作人与被查账号
- 正向:重置后原配置失效,原持有人需重新绑定
- 逆向:只有查看权限的账号点重置 → 拒绝
- 逆向:对未开启二次验证的账号点查看 → 提示无内容,不报错

### 术语与共用口径

> 权限节点、角色、四层树、数据范围的定义见

| 术语 | 定义 |
|---|---|

### 依赖与数据流

**数据流向**:管理员在弹窗中填写账号信息并选定角色与推广商 →
服务端校验唯一性与授权范围后保存 → 该账号登录后,
功能权限按其角色判定、数据范围按其推广商判定 → 所有操作留痕进操作日志。

**系统串接**:**无外部系统**。推广商列表来自 [7.4 推广渠道](../../M7-代理管理/7.4-推广渠道/README.md),
本页只引用其标识与启停状态;二次验证使用标准的时间型一次性密码,不依赖第三方服务。

### 数据归属与职责

**数据归属**

- 拥有(owner=M6):后台账号 · 账号推广商关联
- 只读:角色(owner=M6,由 6.2 写入)· 推广商(owner=M7,由 7.4 写入)

**前后端职责**

| 事项 | 归属 |
|---|---|
| 权限判定 | **服务端** |
| 账号唯一性、授权范围不得超出自身 | **服务端** |
| 密码加密存储与不回显 | **服务端** |
| 停用时使在线会话失效 | **服务端** |
| 谷歌密钥脱敏 | **服务端** |
| 表单交互与即时格式提示 | 界面 |
| 二次确认与影响面提示 | 界面 + 服务端双重校验 |

### 新增账号的职责(6.1-R2)

| 归属 | 做什么 |
|---|---|
| 界面 | 必填校验、邮箱格式提示、密码强度提示、角色选择、推广商多选、二次验证开关联动 |
| 服务端 | 权限判定、账号规则与唯一性、角色与推广商有效性、授权范围、密码加密存储、留痕 |

### 启用与停用的职责(6.1-R4)

| 归属 | 做什么 |
|---|---|
| 界面 | 二次确认,停用时提示该账号将立即无法登录 |
| 服务端 | 权限判定、状态变更、**在线会话失效**、留痕 |

### 查看与重置验证码的职责(6.1-R6)

| 归属 | 做什么 |
|---|---|
| 界面 | 二次确认;查看结果不落地、不允许复制到剪贴板之外的地方 |
| 服务端 | 权限判定、返回或重置验证码、**强制留痕** |
