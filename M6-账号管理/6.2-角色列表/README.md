# 6.2 · 角色列表

<a id="1-背景与目标"></a>

## 1. 用途

让管理员用勾选的方式定义「这类岗位能做什么」,不用为每个人单独配一遍。

### 使用者

| 角色 | 用来做什么 | 没有会怎样 |
|---|---|---|
| 管理员 | 按岗位建角色,一次定义多人复用 | 每加一个人都要重配一遍权限,配错了也发现不了 |
| 风控 | 核对高风险操作被授予给了哪些角色 | 说不清谁能动钱,出事查不到授权源头 |
| 财务主管 | 确认下属角色只拿到该拿的资金操作 | 只能靠口头约定,权限越用越宽 |

权限是所有干预动作的闸门。角色让授权从「逐人配置」变成「按岗位定义」,
既少配错,也让「谁能做什么」这件事可以被审阅。

### 本次范围
- 不管账号绑定谁、能看哪些推广商(那是账号管理页的事)
- 不定义各业务模块具体有哪些节点(各模块在自己的模块文档里声明)
- 不做审批流 —— 角色改动即时生效,事后靠操作日志复核

### 适用范围

| 维度 | 取值 |
|---|---|
| 终端 | 桌面后台,最小宽度 1440 |
| 响应式 | 否 |
| 界面语言 | 简体中文 |
| 时区 | 运营时区,页面顶部标注 |
| 货币 | 不涉及金额 |

## 3. 操作规则

### 角色被账号引用时能否删除(A4)

不能,须先解绑。

### 新增角色(6.2-R2)

点击新增角色,填写弹窗并确认。

输入信息：角色名称(必填)· 角色类型(必填)· 备注 · 权限节点勾选集合。

1. 判权限;无权限不展示新增入口,服务端二次判定
2. 校验角色名称在同运营商下不重名
3. 校验勾中的节点**都真实存在于当前权限树**,拒绝包含未知节点标识的提交 ——
   防止前端传入伪造节点
4. 校验**父子完整性**:勾中任一操作节点必须同时持有其页面节点。
   界面上勾子节点应自动补齐父节点,服务端仍要独立校验一次
5. 保存后立即生效;**已登录的账号在下次取数时按新权限判定**,不必重新登录
6. 写操作日志,记录操作人、时间与勾选集合

### 编辑角色(6.2-R3)

点击某行编辑,修改后确认。

输入信息：同 R2。

1. 判权限,回显该角色当前的勾选集合
2. 提交前**告知该角色当前绑定了多少个账号** —— 改一个角色会同时改变这些人的权限,
   这是本页最容易被低估的影响面
3. 校验同 R2
4. 保存后**即时对该角色下所有账号生效**,不等重新登录
5. 并发编辑:后提交者被拒绝并提示刷新,不静默覆盖
6. 写操作日志,记录改动前后的勾选集合差异

### 删除角色(6.2-R4)

点击某行删除并通过二次确认。

输入信息：被删除的角色(单条)。

1. 判权限
2. 检查是否有账号绑定该角色;有则**拒绝**(见 A4),并指出账号数量 ——
   账号必须有角色,删掉角色会让这些账号处于无权限的悬空状态
3. 通过检查后删除并写操作日志

## 4. 特殊情况

### 边界处理

| # | 场景 | 触发条件 | 预期处理 |
|---|---|---|---|
| E1 | 越权配置 | 无角色管理权限的账号提交新增或编辑 | 拒绝并提示;界面不展示入口,服务端二次判定 |
| E2 | 伪造节点 | 请求中包含权限树上不存在的节点标识 | 拒绝并提示,**不静默忽略未知节点** |
| E3 | 父子不完整 | 只勾操作节点未勾其页面节点 | 拒绝并指出缺失的父节点 |
| E4 | 并发编辑覆盖 | 两人同时编辑同一角色 | 后提交者被拒绝并提示刷新 |
| E5 | 删除仍被引用的角色 | 该角色仍有账号绑定 | 拒绝并指出账号数量 |
| E6 | 改动影响面被低估 | 修改一个绑了多个账号的角色 | 提交前显式告知绑定账号数,二次确认 |
| E7 | 自我降权 | 收回自己所属角色的角色管理权限 | 允许但二次确认并明确提示后果,不静默生效 |
| E8 | 空角色 | 一个节点都不勾就保存 | 拒绝 —— 容易被误读为全权限 |

### 新增角色遇到异常时(6.2-R2)

| 错误状况 | 提示 |
|---|---|
| 无新增权限 | 提示无权限 |
| 角色名称为空或重名 | 定位到字段并提示 |
| 角色类型为空 | 请填写角色类型 |
| 勾中了不存在的节点 | 拒绝并提示权限项已失效,请刷新后重试 |
| 只勾了操作节点没勾页面节点 | 拒绝并指出缺失的父节点 |
| 一个节点都没勾 | 拒绝 —— 空角色没有意义,且容易被误当成「全权限」 |

### 编辑角色遇到异常时(6.2-R3)

| 错误状况 | 提示 |
|---|---|
| 无编辑权限 | 提示无权限 |
| 该角色已被他人修改 | 提示已被修改,请刷新后重试 |
| 校验类错误 | 同 R2 |
| 收回权限导致操作人自己失去角色管理权 | 允许但需二次确认并明确提示后果 |

### 删除角色遇到异常时(6.2-R4)

| 错误状况 | 提示 |
|---|---|
| 无删除权限 | 提示无权限 |
| 该角色仍被账号绑定 | 该角色正被 N 个账号使用,请先改绑后再删除 |
| 重复提交删除 | 只生效一次 |

### 页面状态

| 状态 | 表现 |
|---|---|
| 错误 | 弹窗内字段级提示,弹窗不关闭,已勾选内容保留 |
| 树加载中 | 权限树未加载完成前禁用确认按钮,避免提交空集合 |
| 节点已失效 | 特有态:回显时发现某节点已不在树上,明确标出而不是静默丢弃 |
| 影响面提示 | 编辑时显示该角色当前绑定的账号数 |

## 5. 验收场景

| 需求编号 | 场景与操作 | 预期结果 |
|---|---|---|
| 6.2-R1 | 角色列表与筛选：进入页面 · 点查询 · 翻页 | 按角色名称筛选生效;分页与总数准确 |
| 6.2-R2 | 新增角色：点新增角色并提交 | 必填校验生效;重名拒绝;勾中的节点与预览一致 |
| 6.2-R3 | 编辑角色：点某行编辑并提交 | 改动**即时对该角色下所有账号生效**;并发编辑不静默覆盖 |
| 6.2-R4 | 删除角色：点删除并确认 | 被账号引用时拒绝并指出引用方 |

### 新增角色(6.2-R2)

- 正向:建一个只勾「财务管理 / 充值管理 / 人工充值操作记录」的角色 →
  绑定该角色的账号只能看到这一个页面,其余菜单不出现
- 正向:预览面板与实际勾选一致,保存后重新打开编辑,勾选状态还原
- 逆向:角色名重复 → 拒绝;角色类型留空 → 拒绝;一个节点不勾 → 拒绝
- 逆向:构造请求勾中一个不存在的节点标识 → 服务端拒绝,不静默忽略
- 逆向:只勾「审核」不勾「提现订单」→ 拒绝并指出缺父节点

### 编辑角色(6.2-R3)

- 正向:给一个已绑 3 个账号的角色加一个节点 → 三个账号下次取数即拥有该权限,无需重登
- 正向:提交前能看到「该角色当前绑定 3 个账号」
- 逆向:两人同时编辑同一角色 → 后提交者被提示刷新,前者改动不被覆盖
- 逆向:把自己所属角色的角色管理权限取消 → 二次确认后允许,再次进入即无权限

### 删除角色(6.2-R4)

- 正向:删除一个无账号绑定的角色 → 删除成功,操作日志可查
- 逆向:删除仍被账号绑定的角色 → 拒绝并指出账号数量
- 逆向:连点两次删除 → 只生效一次

### 术语与共用口径

> **权限模型的完整定义见同目录 [`权限模型.md`](./权限模型.md)** ——
> 四层树的结构、授权规则、数据范围与全平台节点口径都在那里,本文不重复。

| 术语 | 定义 |
|---|---|
| 角色 | 一组被勾选的权限节点,账号通过绑定它获得功能权限 |
| 角色类型 | 角色的分类,必填。运营填写1至32字符的分类名称,去首尾空格;不影响权限,账号类型筛选引用该分类 |
| 预览 | 弹窗右侧的面板,实时显示当前已勾中的节点 |

### 依赖与数据流

**数据流向**:管理员在弹窗中勾选权限节点 → 服务端校验节点合法性与父子完整性后保存 →
账号管理页给账号绑定该角色 → 各业务页面取数时按该账号的角色判定功能权限 →
操作留痕进操作日志。

**系统串接**:**无外部系统**。权限树的节点集合来自平台自身的菜单与操作定义,
不依赖第三方。与各业务模块的关系是**被依赖**:它们声明自己有哪些节点,本页负责勾选。

### 数据归属与职责

**数据归属**

- 拥有(owner=M6):角色 · 角色权限关联
- 只读:权限节点集合(由平台菜单与各模块声明派生)

**前后端职责**

| 事项 | 归属 |
|---|---|
| 权限判定 | **服务端** |
| 节点合法性与父子完整性校验 | **服务端**(界面自动补齐父节点只是体验,不作数) |
| 并发控制 | **服务端** |
| 树的展开、勾选、预览回显 | 界面 |
| 二次确认与影响面提示 | 界面 + 服务端双重校验 |

### 新增角色的职责(6.2-R2)

| 归属 | 做什么 |
|---|---|
| 界面 | 必填校验、树的展开与勾选、预览面板实时回显、全选 |
| 服务端 | 权限判定、重名校验、节点合法性校验、父子完整性校验、保存与留痕 |

### 编辑角色的职责(6.2-R3)

| 归属 | 做什么 |
|---|---|
| 界面 | 回显当前勾选、二次确认(改动影响多个账号)、并发提示 |
| 服务端 | 同 R2 的全部校验,外加并发控制与影响面提示 |

### 删除角色的职责(6.2-R4)

| 归属 | 做什么 |
|---|---|
| 界面 | 二次确认,确认前显示该角色绑定了多少账号 |
| 服务端 | 引用检查、删除与留痕 |
