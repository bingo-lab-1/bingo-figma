# 6.3 · 操作日志

## 1. 背景与目标

**目标**:让全站每一次后台操作都能被查到是谁、什么时候、改了什么。

**谁在用**

| 角色 | 用来做什么 | 没有会怎样 |
|---|---|---|
| 风控 | 追查异常操作,还原一笔资金调整的来龙去脉 | 出了问题只能猜,查不到人也说不清经过 |
| 财务 | 对账不平时反查当天的人工干预 | 只能逐个页面翻记录,漏一个就查不出源头 |
| 管理员 | 核对权限改动与账号变更 | 谁给谁提了权限没有痕迹 |

**业务价值**:这是整个后台唯一的「事后说得清」的凭据。
各业务页面反复要求的「留痕」最终都落在这里,不各自建一套记录表。

**不做什么**
- 不提供任何修改能力 —— 纯只读,日志一旦写入不可改
- 不做告警与实时监控(那是运维侧的事,本页只负责可查)
- 不替代各业务页面自己的业务流水(如账变流水、人工调整记录),两者互补而非重复

**适用范围**

| 维度 | 取值 |
|---|---|
| 终端 | 桌面后台,最小宽度 1440 |
| 响应式 | 否 |
| 界面语言 | 简体中文 |
| 时区 | 运营时区,页面顶部标注 |
| 货币 | 不涉及金额 |

## 2. 入口

- 菜单:账号管理 → 操作日志
- 跳入:6.1 账号管理按操作者反查 · 各业务页面在追溯某次干预时跳入

## 3. 术语

> 权限节点与角色的定义见 `../6.2-角色列表/权限模型.md`,本文不重复。

| 术语 | 定义 |
|---|---|
| 变更前数据 | 这次操作动手之前该条记录的样子,用于比对改了什么 |
| 变更记录 | 本次操作实际改动的内容 |
| 接口描述 | 这次操作对应的业务动作说明,比原始路径可读 |
| 请求状态 | 本次操作最终成功还是失败 |

## 4. 关键参数与假设

| 编号 | 参数 | 取值 | 依据 | 在哪配 |
|---|---|---|---|---|
| A1 | 每页条数 | 50 条/页 | **未验证假设** | 界面可切换 |
| A2 | 默认查询窗 | 近 7 天 | **未验证假设** | 写死 |
| A3 | 日志保留期 | **待确认** | **未验证假设** | 配置项 |
| A4 | 查询响应上限 | 5 秒 | **未验证假设** | 写死,超时中断并给可读提示 |

> A3 直接决定这一页的价值。资金类纠纷往往在数月后才浮现,保留期太短等于没有留痕。

## 5. 字段清单

筛选面板与表头见 `截图/列表-筛选面板与表头.png`。

**筛选字段**

| 字段 | 类型 | 可输入数据与校验 |
|---|---|---|
| 操作者 | text | 后台账号,精确匹配 |
| 路径 | text | 请求路径,支持部分匹配 |
| 请求参数关键字 | text | 在请求参数中搜关键字 |
| 请求参数 | text | 精确匹配 |
| 请求参数2 | text | 第二个参数条件。**与「请求参数」的分工待确认** |
| 接口描述 | text | 按业务动作说明搜索 |
| 活动类型 | select | 全部 / 各类型。**枚举未取全**,见模块决策 D8 |
| 时间 | daterange | 起止时间,默认见 A2 |

> 三个参数类筛选(请求参数关键字 / 请求参数 / 请求参数2)含义重叠,
> 实采无法区分各自作用。写实现前需确认,否则三个框对使用者是同一件事的三种写法。

**表格列**

| 列 | 说明 | 默认显示 |
|---|---|---|
| 序号 | 当前页行号 | 是 |
| ID | 记录标识 | 是 |
| 活动类型 | 该操作归属的业务分类 | 是 |
| 操作人 | 执行操作的后台账号 | 是 |
| IP地址 | 操作来源地址 | 是 |
| 操作时间 | 按运营时区展示 | 是 |
| 请求路径 | 原始路径 | 是 |
| 请求参数 | 提交的内容,**可能含敏感字段,须脱敏** | 是 |
| 请求方法 | 请求类型 | 否 |
| 返回参数 | 处理结果,**可能含敏感字段,须脱敏** | 否 |
| 接口描述 | 业务动作说明,比路径可读 | 是 |
| 变更记录 | 本次改动的内容 | 是 |
| 变更前数据 | 动手之前的样子 | 是 |
| 耗时 | 本次请求耗时 | 否 |
| 代理头 | 客户端信息 | 否 |
| 请求状态 | 成功 / 失败 | 是 |

**请求参数与返回参数必须脱敏。** 这两列会原样带上提交内容,
其中可能包含密码、谷歌密钥、玩家手机号与收款账户。日志本身不能成为泄露渠道。

## 7. 需求详述

### 6.3-R1

**触发条件**:进入页面 · 点击查询 · 切换筛选 · 翻页。

**可输入数据**:见第 5 段筛选字段,全部可组合、均非必填。

**功能范围**

| 归属 | 做什么 |
|---|---|
| 界面 | 筛选交互、分页、长文本参数的折叠与展开 |
| 服务端 | 权限判定、**敏感字段脱敏**、筛选校验、排序分页、超时保护 |

**处理逻辑**

1. 判权限;无权限直接拒绝,不返回任何数据
2. **日志不受推广商范围过滤** —— 它是审计视图,按推广商切会让跨推广商的
   异常操作查不出来。是否放宽到全量见模块决策 D22
3. 按筛选条件取数,默认按操作时间降序
4. 请求参数与返回参数**在服务端脱敏后再返回**,不在界面遮挡
5. 长文本参数折叠展示,展开才完整呈现

**错误处理**

| 错误状况 | 提示 |
|---|---|
| 无查看权限 | 提示无权限,不展示列表 |
| 查询超时(见 A4) | 中断并提示缩小时间范围,不返回半截数据 |
| 起止时间颠倒 | 结束时间不能早于开始时间 |
| 超出保留期的时间范围 | 提示该时段日志已过保留期(见 A3) |

**测试案例**

- 正向:按操作者查询 → 只返回该账号的操作,按时间倒序
- 正向:请求参数中含密码的记录 → 该字段展示为脱敏形态,不出现明文
- 逆向:无权限账号进入 → 拒绝且不返回数据
- 逆向:查询超大跨度触发超时 → 中断并提示,不返回半截数据
- 逆向:查询超出保留期的时段 → 明确提示已过保留期,不返回空列表让人以为没操作

### 6.3-R2

**触发条件**:展开某条日志记录。

**可输入数据**:无。

**功能范围**

| 归属 | 做什么 |
|---|---|
| 界面 | 变更前数据与变更记录并排或上下呈现,长文本可展开 |
| 服务端 | 脱敏后返回两份数据 |

**处理逻辑**

1. 同时返回变更前数据与变更记录,**成对呈现**
2. 两份数据都按同一套规则脱敏,避免一边明文一边脱敏
3. 变更前数据为空时(如新增类操作)明确标注「无(新增操作)」,
   不显示空白让人误以为数据丢失

**错误处理**

| 错误状况 | 提示 |
|---|---|
| 变更前数据缺失 | 区分「新增操作本就没有」与「数据缺失」,分别标注 |
| 内容过长 | 折叠并提供展开,不截断后静默丢弃 |

**测试案例**

- 正向:展开一条编辑类日志 → 变更前与变更后成对可见,能看出改了哪个字段
- 正向:展开一条新增类日志 → 变更前明确标注「无(新增操作)」
- 逆向:变更前数据异常缺失 → 标注为数据缺失,与新增操作区分开

## 8. 数据流向与系统串接

**数据流向**:任意后台账号在任意页面执行操作 → 服务端在处理该操作时写入一条日志
(操作者、路径、参数、变更前后、结果)→ 本页按筛选条件读取并展示。
**本页只读,不产生任何写入。**

**系统串接**:**无外部系统**。日志由平台自身在处理请求时写入,不依赖第三方。
与各业务模块的关系是**被依赖**:它们要求的「留痕」统一落在这里,各自不建记录表。

## 9. 异常与边界

| # | 场景 | 触发条件 | 预期处理 |
|---|---|---|---|
| E1 | 越权查看 | 无权限账号直接访问本页地址 | 拒绝并提示,不返回任何数据 |
| E2 | 日志成为泄露渠道 | 请求参数中含密码、密钥、玩家手机号 | 服务端脱敏后再返回,不在界面遮挡了事 |
| E3 | 大跨度查询 | 时间范围放得很宽 | 按 A4 超时中断并提示缩小范围 |
| E4 | 超出保留期 | 查询早于保留期的时段 | 明确提示已过保留期,不返回空列表让人误判为无操作 |
| E5 | 日志写入失败 | 业务操作成功但日志没写上 | 视同异常并告警 —— 无痕迹的资金操作等于没有凭据 |
| E6 | 账号已删除 | 操作者账号被删除后查其历史 | 日志**保留**并仍显示原操作者标识,不因账号删除而清除 |

## 10. 状态清单

| 状态 | 表现 |
|---|---|
| 错误 | 列表区域内提示并可重试,不整页跳转;筛选条件保留 |
| 超出保留期 | 特有态:明确提示该时段已过保留期,与「无匹配记录」区分开 |
| 参数过长 | 特有态:折叠展示并提供展开,不静默截断 |
| 操作者已删除 | 特有态:仍显示原操作者标识并标注账号已删除 |

## 11. 涉及表与职责

**数据归属**

- 拥有(owner=M6):操作日志(本页**只读**,写入方是各业务操作本身)
- 只读:后台账号(owner=M6,由 6.1 写入)

**前后端职责**

| 事项 | 归属 |
|---|---|
| 权限判定 | **服务端** |
| 请求参数与返回参数脱敏 | **服务端**(不得由界面遮挡代替) |
| 筛选校验、超时保护 | **服务端** |
| 日志写入的完整性 | **服务端**,写入失败须告警 |
| 长文本折叠与展开 | 界面 |
