# 6.4 · 权限管理

## 1. 用途

管理员查看系统里有哪些权限点,核对权限名称、权限标识和用途,配合[角色管理](../6.2-角色管理/README.md)判断该勾选什么。

本页是只读目录,不提供新增、编辑和删除。权限点由系统按版本维护,角色授权在 6.2 完成。

后台桌面端使用,界面简体中文,时间按操作人浏览器时区展示,不涉及金额。

## 2. 查询条件

| 条件 | 含义和填写规则 |
|---|---|
| 权限名称 | 包含匹配,区分大小写,留空表示不限 |
| 权限标识 | 包含匹配,区分大小写,留空表示不限 |

两个条件同时填写时取交集。

## 3. 结果字段

| 字段 | 含义 |
|---|---|
| ID | 权限记录编号 |
| 权限名称 | 中文名称 |
| 权限标识 | 权限码,即服务端判定使用的标识,全平台唯一 |
| 描述 | 权限用途,空值显示 - |
| 创建时间 | 按创建时间倒序 |

## 4. 操作规则

输入条件后点“查询”生效,结果分页展示。“清空筛选”清空条件并回到第一页。

无结果时显示空状态。取数失败时显示错误,可重试。账号没有查看权限时菜单不显示,直接访问进入无权限页,服务端同样拒绝返回数据。

## 5. 验收场景

| 需求编号 | 场景与操作 | 预期结果 |
|---|---|---|
| 6.4-R1 | 打开页面 | 按创建时间倒序分页显示全部权限点 |
| 6.4-R2 | 权限标识填 `cms:` | 只返回标识包含 `cms:` 的权限点 |
| 6.4-R2 | 权限名称和权限标识同时填写 | 返回同时满足两个条件的权限点 |
| 6.4-R3 | 输入不存在的关键字 | 显示空状态 |
| 6.4-R4 | 查看页面操作 | 没有新增、编辑、删除入口 |
| 6.4-R5 | 账号没有 `permission:catalog:view` | 菜单不显示,直接访问进入无权限页,不返回权限数据 |

## 6. 相关资料

- 入口:系统管理 > 权限管理。
- 权限:查看 `permission:catalog:view`。
- 数据归属:权限点归 M6,由系统按版本维护;结构和判定规则见[权限模型](../6.2-角色管理/权限模型.md)。
