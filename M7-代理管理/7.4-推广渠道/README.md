# 7.4 · 推广渠道

## 1. 用途

运营在这里维护推广商和推广渠道，取得带渠道参数的推广链接。玩家打开链接注册后归属到对应渠道，渠道与推广商再被会员查询、账号数据范围、活动定向和同期群分析引用。网站中渠道独立成“推广渠道”一级菜单，不在“代理管理”分组下。

每个渠道有两条链接：H5 推广链接直接进入游戏；PWA 链接先进入安装页，玩家可以把游戏安装到手机桌面，也可以直接在网页玩，规则见[安装到桌面](../../玩家端/安装到桌面/README.md)。运营在渠道行查看每天的安装统计。

运营还可以为渠道配置广告回传。投放方在广告平台投放时，要让广告平台知道哪些广告带来了注册、首充和多少充值，才能按这些结果优化投放：按充值金额出价需要每笔充值的金额，按新增付费玩家优化需要单独的首充事件。渠道开启回传后，玩家正式注册、每笔充值入账时，系统把事件回传到该渠道配置的像素，运营可以查看每一次回传的结果。本版只接入 Facebook，回传三种事件，所有渠道相同：

- 正式注册回传“完成注册”，即 Facebook 标准事件 CompleteRegistration。
- 账号首充回传“订阅”（Subscribe），带这笔充值的美元金额。
- 每笔充值回传“购物”（Purchase），带这笔充值的美元金额。首充也是一笔充值，所以首充同时回传订阅和购物。

创建游客、安装到桌面都不回传。

页面面向桌面端，界面为简体中文，时间按查看者浏览器时间显示。回传金额一律折成美元；安装统计按平台业务时区的自然日汇总。

系统预置默认推广商“官方推广商”和其下的“官方渠道”。首次打开带渠道参数的链接时，系统自动创建的游客账号归属该渠道。不带渠道参数公开注册或创建游客账号时，带了有效邀请码、且邀请人所在渠道启用，归属邀请人所在渠道；否则归属官方渠道（见模块决策 D137）。这样好友打开只带邀请码的分享链接注册后，和邀请人属于同一推广商。

本版不提供修改推广商名称、把渠道移到其他推广商、批量操作和导出。广告回传不提供其他广告平台、按渠道选择回传的事件、广告消耗导入、按广告计划的报表、手动重发和回传记录导出。PWA 链接不提供按渠道配置不同的名称和图标。

## 2. 配置项

### 推广商

| 配置项 | 含义和填写规则 |
|---|---|
| 推广商名称 | 文本必填，保存时去首尾空格，新增时不能与已有推广商同名 |
| 类型 | 系统标记：默认或普通，不能配置。预置的官方推广商为默认，新增的都是普通 |

### 推广渠道

| 配置项 | 含义和填写规则 |
|---|---|
| 所属推广商 | 新增时取当前选中的推广商 |
| 渠道名称 | 文本必填，保存时去首尾空格，系统不校验重名 |
| 域名 | 必选，选项来自域名管理 |
| 渠道状态 | 启用或停用，新增默认启用 |

### 广告回传

新增和编辑渠道的弹窗里有“广告回传”一组配置，每个渠道一份，随渠道一起保存。

| 配置项 | 含义和填写规则 |
|---|---|
| 回传开关 | 开或关，默认关。关闭时本渠道不加载像素、不回传，其余各项可以不填，已填内容保留 |
| 像素 ID | 广告平台分配给像素的数字编号。开启回传时必填；只要填写就只接受数字 |
| 回传令牌 | 广告平台为该像素生成的回传凭据。开启回传时必填。保存后不再显示内容：再次打开时输入框为空，占位文字为“不修改请留空”，下方显示“已设置 重新填写即覆盖，留空则保持原令牌” |
| 测试码 | 选填。填写后本渠道的全部回传都带测试码，用于在广告平台的测试事件页核对；联调结束后清空 |

回传的事件不能配置，所有渠道相同。“广告回传”标题下方有一行只读说明，回传开关打开或关闭时都显示，写明回传内容：正式注册报完成注册，首充报订阅，每笔充值（含首充）报购物，均带金额。

### 列表

列表按创建时间倒序，默认每页 20 条，最多 100 条。

| 列表内容 | 规则 |
|---|---|
| 推广商页签 | 单选，默认第一个推广商，新建的排在前面；页签下方显示“当前推广商：推广商名称” |
| 筛选：渠道名称 | 包含匹配，不区分大小写。点“查询”生效，“清空筛选”清空并回到第 1 页 |
| 渠道名称 | 从同期群分析返回时，来源渠道标注“（来源渠道）” |
| 推广链接 | 两条链接，分别标注 H5 和 PWA，各带一个复制按钮。H5 是所选域名加 `ch=渠道ID` 参数；PWA 是该域名下的安装页地址加同一参数。网站管理没有配置应用图标时，PWA 链接下方提示“未配置应用图标，链接将直接进入游戏” |
| 渠道状态 | 启用或停用 |
| 回传状态 | 未开启、已开启、测试中。回传开关打开且填了测试码时显示测试中 |
| 创建时间 | 渠道创建时间 |
| 操作 | 同期群分析（有权限时显示）、回传记录、安装统计、编辑、启用或停用、删除 |

### 回传记录

渠道行点“回传记录”打开，只读。按事件发生时间倒序，默认每页 20 条。记录保留 90 天，时间按查看者浏览器时区显示。

| 内容 | 规则 |
|---|---|
| 筛选：事件 | 全部、完成注册、购物、订阅 |
| 筛选：状态 | 全部、等待回传、成功、重试中、已过期 |
| 筛选：UID | 精确匹配 |
| 筛选：时间 | 按事件发生时间选起止日期，打开时默认近 7 天，含当天。点“查询”生效；“清空筛选”清空全部筛选，包括时间 |
| 时间 | 事件发生时间，即注册成功或充值入账的时间 |
| UID | 产生事件的账号，可复制 |
| 事件 | 完成注册、购物或订阅。首充有订阅和购物两条记录，之后的每笔充值一条购物。改为固定事件（D151）之前生成的首充记录保留原来的事件，见特殊情况 |
| 金额 | 订阅和购物回传的美元金额，即这笔充值的美元金额；完成注册不显示金额 |
| 广告点击信息 | 有或无。账号保存了广告点击标识时为有 |
| 测试 | 是或否。最近一次发送带测试码为是 |
| 状态 | 等待回传：尚未发送。成功：广告平台已接收。重试中：上次发送失败，等待下次重试。已过期：事件发生满 7 天仍未成功，不再发送 |
| 说明 | 最近一次发送失败的原因，通常是广告平台返回的说明；之后发送成功也保留。没有失败过显示“-” |

### 安装统计

渠道行点“安装统计”打开，只读。每行是平台业务时区的一个自然日，最近的日期在前，不分页。

| 内容 | 规则 |
|---|---|
| 筛选：日期 | 起止日期，打开时默认近 7 天，含平台今天；可以快捷选择近 7 天、近 30 天、近 90 天。一次最多 90 天，结束日期不能晚于平台今天。点“查询”生效 |
| 日期 | 平台业务时区的自然日 |
| 打开安装页人数 | 当天打开过该渠道安装页的浏览器数，同一浏览器一天计一次 |
| 安装成功数 | 当天安装的次数，每次安装计一次。安卓以浏览器告知安装页已安装为准，玩家确认安装后即计入，系统此时可能还在安装；iPhone 无法得知添加是否完成，以第一次从桌面图标打开为准 |
| 选择网页玩人数 | 当天在该渠道安装页点击网页入口（如“Play in browser”）的浏览器数，同一浏览器一天计一次 |

数据来自玩家端上报，按渠道和自然日汇总，没有数据的日期显示 0。

## 3. 操作规则

### 新增推广商与删除推广商

“新增推广商”弹窗同时列出推广商的名称、类型和创建时间。添加成功后留在弹窗，列表和页签同步刷新。

删除推广商只开放给系统角色，需要二次确认。默认推广商不显示删除按钮。推广商下有渠道，或已被业务配置、历史记录引用时不能删除。

### 新增与编辑渠道

保存成功后提示“保存成功”并刷新列表，修改立即生效。编辑可改渠道名称、域名和广告回传配置，不改所属推广商和渠道状态。渠道名称未填提示“请输入渠道名称”，域名未选提示“请选择域名”。保存被服务端拒绝时弹窗不关闭，在弹窗内显示拒绝原因；保存进行中不能关闭弹窗。

修改域名只改变后台显示的 H5 推广链接和 PWA 链接。注册时系统只校验渠道是否存在且启用，不校验访问域名，已发出的旧链接继续有效；已绑定的会员不受影响。

### 启用与停用渠道

点“停用”或“启用”需要二次确认。

- 停用后：新会员不能通过此渠道注册，后台也不能把会员改绑到此渠道；已绑定会员的渠道归属和充值结算保留。
- 启用后：新会员可通过此渠道注册，后台可将会员绑定到此渠道。

官方渠道也可以停用。停用后，不带渠道参数、也不能归属邀请人所在渠道的公开注册和游客创建都被拒绝。

停用不改变广告回传和安装页：已归属账号的回传按回传开关执行，安装页照常显示，安装统计照常计数。

### 删除渠道

删除前弹窗提示影响。官方渠道、已有会员的渠道、已被业务配置或历史记录引用的渠道都不能删除，应改为停用。渠道或推广商一旦被引用就永久保留，引用后来消失也不能再删除。首页分时汇总只为有业务数据的渠道写入记录，没有业务发生的新渠道不因汇总而失去删除资格。

回传记录和安装统计也是历史记录：产生过回传记录或安装统计的渠道不能删除，回传记录超过保留期被清理后仍不能删除。渠道的回传配置不算引用，随渠道一起删除。

### 查看同期群分析

账号能访问同期群分析时，行内显示“同期群分析”，带当前推广商和渠道跳转；返回时恢复推广商、筛选和页码，并标注来源渠道。

### 复制推广链接与 PWA 链接

两条链接都带同一个渠道参数，点各自的复制按钮复制。玩家打开 PWA 链接看到什么取决于[11.3 网站管理](../../M11-内容管理/11.3-网站管理/README.md)：网站名称和应用图标都已配置时显示安装页；缺任意一项时直接进入游戏首页，链接上的参数原样保留，之后的注册仍归属该渠道。

没有配置应用图标时，列表在每条 PWA 链接下方提示“未配置应用图标，链接将直接进入游戏”。提示随每次列表查询重新读取，上传应用图标并保存后点“查询”即消失；玩家端在保存后约一分钟内才跟随新配置。

安装页不创建游客账号；玩家进入游戏后才创建，见[安装到桌面](../../玩家端/安装到桌面/README.md)。

### 查看安装统计

渠道行点“安装统计”打开该渠道每天的三项数据，默认近 7 天。统计只读，不提供导出。安装不回传广告平台，只在这里按渠道统计。

### 保存广告回传配置

回传配置随渠道一起保存，保存后立即生效：之后发生的注册和充值按新配置回传；等待回传和重试中的记录也按发送时的最新配置发送，记录的测试列随之更新，事件不变。已经成功的记录不再变化。

回传开关打开时像素 ID 和回传令牌必填：像素 ID 未填提示“请输入像素 ID”，含非数字字符提示“像素 ID 只能填写数字”；没有已保存的令牌又未填写时提示“请输入回传令牌”。已保存的令牌留空保存则保持不变，重新填写即覆盖。开关关闭时各项仍可填写并照常保存，清空的像素 ID 和测试码随保存清除。

关闭回传后不再生成新记录，玩家端不再加载像素，尚未成功的记录停止发送并保留；重新开启后，事件发生未满 7 天的记录继续发送。关闭期间发生的注册和充值不生成记录，重新开启后也不补报。

### 记录广告点击

玩家打开带广告点击标识的链接时，玩家端把这次点击连同首次看到它的时间和落地页地址保存下来，保存方式与渠道参数相同：之后的链接带了新的点击就替换，不带则保留。注册时把保存的点击一并提交；系统自动创建游客账号时只提交本次落地链接里的点击。服务端把它保存在账号上，每个账号只保存一次，之后不再修改。点击信息缺失或格式不对时只是不保存，不影响注册。

链接里没有广告点击标识的账号照常回传，由广告平台自行判断归属。

### 加载像素与浏览器事件

访客或账号所属的渠道开启了回传时，玩家端加载该渠道的像素，并从浏览器上报下表四种事件：已有账号的看账号注册时所属的渠道，还没有账号的访客看落地链接里的渠道。注册和充值的转化只由服务端回传。

| 事件 | 玩家的动作 | 金额 |
| --- | --- | --- |
| 浏览 | 打开页面上报一次，之后在站内每打开一个页面再上报一次 | 无 |
| 查看内容 | 进入任意游戏，自研游戏和第三方游戏都算。在同一个游戏里切换牌桌或合约不另报；换一个游戏或重新进入再报一次 | 无 |
| 加入购物车 | 打开充值页。一次访问只报一次，在法币和加密货币之间切换、改金额或方式都不另报；离开后再进入另报 | 无 |
| 发起结账 | 提交充值：法币充值订单创建成功时报一次，同一订单再次打开或重试不重复报；加密货币点“复制地址”且复制成功时报一次，同一次访问里同一地址只报一次 | 法币带订单金额和币种；加密货币无 |

这些浏览器事件只出现在广告平台的事件管理工具里，不进回传记录；浏览器拦截广告脚本时不会发出。转盘充值弹窗和首充补助付款页走各自的下单流程，提交时不报发起结账。

渠道没有开启回传时，玩家端不加载任何广告脚本，也不向广告平台发送请求。

### 注册回传

玩家完成正式注册时，回传一次“完成注册”，邮箱注册和手机注册都算。游客绑定邮箱后在 Settings 设置登录密码、原地转为会员（[M4 决策 D143](../../M4-活动管理/README.md#7-决策清单)），同样回传一次完成注册，记在原 UID 上。系统自动创建游客账号不回传；游客用邮箱或手机注册的是新账号，按新账号的正式注册回传。

### 充值回传

每笔充值入账时，回传一次“购物”。账号的第一笔充值是首充，另外再回传一次“订阅”：一笔首充生成订阅和购物两条记录，时间和金额相同，各自发送、各自重试。金额为这笔充值的本金按[标准计价](../../M2-会员管理/2.1-会员列表/标准计价.md)折成的美元金额，不含赠送和活动奖励。

充值沿用财务的充值事实，三种来源都算：链上入金、法币充值订单、后台人工加款时勾选“计入充值”的本金。首充按账号计，每个账号只回传一次订阅；之后的每笔充值只回传购物。

### 回传去向

事件回传到账号注册时所属渠道的像素。后台之后把会员改绑到其他渠道，不改变该账号的回传去向。

只回传渠道开启回传之后发生的注册和充值。测试账号的注册和充值不回传，也不生成记录。是否为测试账号，注册看注册时的标记，充值看入账时的标记。

### 发送与重试

回传与注册、充值入账分开执行：记录通常在事件发生后一分钟左右生成并发送；回传失败或广告平台不可用，不影响注册成功和充值入账。玩家关闭页面、浏览器拦截广告脚本，都不影响注册和充值的回传。

发送失败后自动重试，间隔逐次加长，最长一小时一次。事件发生满 7 天仍未成功的，记录标记为已过期，不再发送。同一条记录每次发送使用同一个事件编号，确认成功后不再发送。

### 随事件发送的资料

每次回传发送：事件名称、发生时间、事件编号、订阅和购物的美元金额、账号保存的广告点击标识和浏览器标识、账号创建时（注册或系统创建游客时）的 IP 地址和浏览器类型、不含链接参数的落地页地址，以及由 UID 经不可逆处理得到的账号标识。账号没有保存 IP 地址和浏览器类型时取最近一次登录的；没有保存落地页时用注册所在站点的首页。本版不发送邮箱、手机号和姓名。

### 查看回传记录

渠道行点“回传记录”打开该渠道的记录，可按事件、状态、UID 和时间筛选。记录只读，本版不提供手动重发和导出。

## 4. 特殊情况

| 情况 | 如何处理 |
|---|---|
| 推广商同名 | 新增时提示“已存在同名推广商，请更换名称”，不提交 |
| 删除默认推广商 | 服务端拒绝，提示“默认推广商不能删除” |
| 删除下有渠道的推广商 | 拒绝，提示“推广商下存在渠道，不能删除”，停用的渠道也算 |
| 删除已有业务配置或历史记录的推广商 | 拒绝，提示“推广商已有业务配置或历史记录，不能删除” |
| 非系统角色删除推广商 | 拒绝，提示“仅超级管理员可执行此操作” |
| 删除官方渠道 | 拒绝，提示“官方默认渠道用于直接注册，不能删除；如需停止新注册，请停用渠道” |
| 删除已有会员的渠道 | 拒绝，提示“推广渠道已关联会员，请停用渠道” |
| 删除已有业务配置或历史记录的渠道 | 拒绝，提示“推广渠道已有业务配置或历史记录，请停用渠道”；产生过回传记录或安装统计的渠道同样处理 |
| 操作期间渠道所属推广商发生变化 | 拒绝，提示“推广渠道已变化，请刷新后重试”，原数据不变；编辑保存时提示显示在弹窗内 |
| 玩家用已停用渠道的链接注册 | 注册被拒绝，玩家端提示“The invitation code or registration link is invalid. Check the code or ask for a new link.” |
| 玩家用不存在的渠道参数注册 | 注册被拒绝，玩家端提示同上 |
| 创建游客时渠道已停用或不存在 | 不创建游客账号，登录弹窗提示“Unable to start a guest account. Log in to an existing account or contact support.” |
| 不带渠道参数注册，邀请码无效或邀请人所在渠道已停用 | 归属官方渠道，注册照常（官方渠道也停用时按上文拒绝）；邀请码无效时不建立邀请关系 |
| 链接同时带渠道参数和邀请码 | 归属链接中的渠道，不按邀请人改归属 |
| 账号没有 `system:domain:view` | 域名下拉没有选项，无法新增渠道 |
| 没有推广商 | “新增推广渠道”不可用，列表为空 |
| 当前推广商下没有渠道或筛选无结果 | 列表显示“暂无数据”和“调整筛选条件后再试。” |
| 操作成功但列表刷新失败 | 提示“渠道状态已更新，列表刷新失败，请重试”“推广渠道已删除，列表刷新失败，请重试”“推广商已删除，列表刷新失败，请重试”或“保存成功，推广商列表刷新失败，请重试”。操作已生效，不用重复操作 |
| 开启回传但像素 ID 或回传令牌未填 | 不提交，分别提示“请输入像素 ID”“请输入回传令牌” |
| 像素 ID 含非数字字符 | 不提交，提示“像素 ID 只能填写数字”；回传开关关闭时同样校验 |
| 像素 ID 或回传令牌填错，广告平台拒绝 | 注册和充值入账不受影响；记录显示重试中，说明列显示广告平台返回的原因；改正配置后，未过期的记录在下一次重试时发送成功 |
| 广告平台暂时不可用 | 同上，自动重试 |
| 充值的币种暂时折不出美元金额 | 这笔充值的记录保持等待回传、不显示金额，取得标准计价后发送；满 7 天仍取不到则标记为已过期。首充的订阅和购物两条都这样处理 |
| 首充的订阅和购物一条成功、一条失败 | 两条记录分开处理：失败的一条按重试规则继续发送，成功的一条不再发送 |
| 同一账号两笔充值几乎同时入账 | 两笔都回传购物；只有业务时间较早的一笔是首充，另外回传订阅 |
| 一笔充值入账晚于已回传订阅的首充，业务时间却更早 | 只回传购物；每个账号只有一次订阅，已有的首充不变 |
| 首充是勾选“计入充值”的人工加款 | 回传订阅和购物，金额为加款本金折成的美元金额 |
| 人工加款未勾选“计入充值” | 不算充值，不回传；之后第一笔计入充值的入账才是首充 |
| 充值入账后被冲正 | 已回传的事件不撤回，广告平台没有撤回事件的办法。被冲正的首充仍是首充：该账号之后的充值只回传购物，不再回传订阅 |
| 玩家打开网站，系统自动创建游客账号 | 不回传完成注册，也不生成记录；玩家之后完成正式注册或原地转为会员时才回传 |
| 游客账号充值 | 按该账号回传：第一笔回传订阅和购物，之后每笔回传购物。游客原地转为会员后 UID 不变，首充不另算；游客用邮箱或手机注册得到的新账号另算首充 |
| 开启回传前已注册或已充值的账号 | 开启前的注册和充值不补报，开启后的每笔充值回传购物。开启前已有充值的账号不再回传订阅；开启前没有充值的账号，开启后的首充回传订阅和购物 |
| 关闭回传时仍有未成功的记录 | 停止发送并保留；重新开启且事件发生未满 7 天的继续发送，满 7 天的标记为已过期 |
| 关闭回传期间的注册和充值 | 不生成记录，重新开启后也不补报；关闭期间完成首充的账号，重新开启后的充值只回传购物 |
| 修改像素 ID、回传令牌或测试码 | 之后发送的回传按新配置，包括等待回传和重试中的记录，记录的测试列随之更新；已成功的记录不变 |
| 改为固定事件（D151）之前生成的首充记录 | 保留原来的事件，不改写：当时回传购物的仍显示购物，回传订阅的仍显示订阅；尚未成功的按记录上的事件继续发送 |
| 改为固定事件（D151）之前入账的充值 | 不补报：首充不补发另一个事件，当时没有回传的复充不补发购物 |
| 账号在注册之后才被标为测试账号 | 标记之后入账的充值不回传 |
| 广告平台已接收，但系统记下结果前服务中断 | 该记录稍后以同一事件编号再发送一次，广告平台可能把这一个事件计两次 |
| 渠道被停用 | 停用只影响新会员注册；已归属账号的回传按回传开关执行。安装页照常显示，访问和安装照常计入该渠道的安装统计 |
| 账号只有 `promotion:channel:view` | 可以看回传状态、回传记录和安装统计；可以打开渠道弹窗，保存时服务端拒绝，弹窗内显示原因，原配置不变 |
| 渠道没有回传记录或筛选无结果 | 显示“暂无数据” |
| 在回传记录点“清空筛选” | 事件、状态、UID 和时间全部清空，列出该渠道保留期内的全部记录 |
| 网站管理未配置应用图标 | 每条 PWA 链接下方提示“未配置应用图标，链接将直接进入游戏”；玩家打开 PWA 链接直接进入游戏首页，注册仍归属该渠道 |
| 网站配置读取失败 | 提示保持上一次读取的结果，从未读取成功时不显示；链接照常显示和复制 |
| 安装统计的日期范围超过 90 天，或结束日期晚于平台今天 | 不查询，表格位置分别提示“日期范围最多包含 90 个自然日”“结束日期不能晚于平台今天” |
| 所选日期没有安装数据 | 每天一行，三项都显示 0 |
| 玩家从应用自带的浏览器转到 Chrome 或 Safari | 两个浏览器各计一次打开安装页人数 |
| PWA 链接不带渠道参数，或渠道不存在 | 这次访问不计入任何渠道的安装统计 |
| 玩家端上报失败 | 不影响安装和游戏，这次访问不计入统计 |
