# 7.4 · 推广渠道

## 1. 用途

运营在这里维护推广商和推广渠道，取得带渠道参数的推广链接。玩家打开链接注册后归属到对应渠道，渠道与推广商再被会员查询、账号数据范围、活动定向和同期群分析引用。网站中渠道独立成“推广渠道”一级菜单，不在“代理管理”分组下。

页面面向桌面端，界面为简体中文，时间按查看者浏览器时间显示。

系统预置默认推广商“官方推广商”和其下的“官方渠道”。玩家不带渠道参数公开注册或创建游客账号时，归属官方渠道；首次打开带渠道参数的链接时，系统自动创建的游客账号归属该渠道。

本版不提供修改推广商名称、把渠道移到其他推广商、批量操作和导出。

## 2. 配置项

### 推广商

| 配置项 | 含义和填写规则 |
|---|---|
| 推广商名称 | 文本必填，保存时去首尾空格，新增时不能与已有推广商同名 |
| 类型 | 系统标记：默认或普通，不能配置。预置的官方推广商为默认，新增的都是普通 |

### 推广渠道

| 配置项 | 含义和填写规则 |
|---|---|
| 所属推广商 | 新增时取当前选中的推广商 |
| 渠道名称 | 文本必填，保存时去首尾空格，系统不校验重名 |
| 域名 | 必选，选项来自域名管理 |
| 状态 | 启用或停用，新增默认启用 |

### 列表

列表按创建时间倒序，默认每页 20 条，最多 100 条。

| 列表内容 | 规则 |
|---|---|
| 推广商页签 | 单选，默认第一个推广商，新建的排在前面；页签下方显示“当前推广商：推广商名称” |
| 筛选：渠道名称 | 包含匹配，不区分大小写。点“查询”生效，“清空筛选”清空并回到第 1 页 |
| 渠道名称 | 从同期群分析返回时，来源渠道标注“（来源渠道）” |
| 域名 | 显示推广链接：所选域名加 `ch=渠道ID` 参数 |
| 状态 | 启用或停用 |
| 创建时间 | 渠道创建时间 |
| 操作 | 同期群分析（有权限时显示）、编辑、启用或停用、删除 |

## 3. 操作规则

### 新增推广商与删除推广商

“新增推广商”弹窗同时列出推广商的名称、类型和创建时间。添加成功后留在弹窗，列表和页签同步刷新。

删除推广商只开放给系统角色，需要二次确认。默认推广商不显示删除按钮。推广商下有渠道，或已被业务配置、历史记录引用时不能删除。

### 新增与编辑渠道

保存成功后提示“保存成功”并刷新列表，修改立即生效。编辑只改渠道名称和域名，不改所属推广商和状态。

修改域名只改变后台显示的推广链接。注册时系统只校验渠道是否存在且启用，不校验访问域名，已发出的旧链接继续有效；已绑定的会员不受影响。

### 启用与停用渠道

点“停用”或“启用”需要二次确认。

- 停用后：新会员不能通过此渠道注册，后台也不能把会员改绑到此渠道；已绑定会员的渠道归属和充值结算保留。
- 启用后：新会员可通过此渠道注册，后台可将会员绑定到此渠道。

官方渠道也可以停用。停用后，不带渠道参数的公开注册和游客创建都被拒绝。

### 删除渠道

删除前弹窗提示影响。官方渠道、已有会员的渠道、已被业务配置或历史记录引用的渠道都不能删除，应改为停用。渠道或推广商一旦被引用就永久保留，引用后来消失也不能再删除。首页分时汇总只为有业务数据的渠道写入记录，没有业务发生的新渠道不因汇总而失去删除资格。

### 查看同期群分析

账号能访问同期群分析时，行内显示“同期群分析”，带当前推广商和渠道跳转；返回时恢复推广商、筛选和页码，并标注来源渠道。

## 4. 特殊情况

| 情况 | 如何处理 |
|---|---|
| 推广商同名 | 新增时提示“已存在同名推广商，请更换名称”，不提交 |
| 删除默认推广商 | 服务端拒绝，提示“默认推广商不能删除” |
| 删除下有渠道的推广商 | 拒绝，提示“推广商下存在渠道，不能删除”，停用的渠道也算 |
| 删除已有业务配置或历史记录的推广商 | 拒绝，提示“推广商已有业务配置或历史记录，不能删除” |
| 非系统角色删除推广商 | 拒绝，提示“仅超级管理员可执行此操作” |
| 删除官方渠道 | 拒绝，提示“官方默认渠道用于直接注册，不能删除；如需停止新注册，请停用渠道” |
| 删除已有会员的渠道 | 拒绝，提示“推广渠道已关联会员，请停用渠道” |
| 删除已有业务配置或历史记录的渠道 | 拒绝，提示“推广渠道已有业务配置或历史记录，请停用渠道” |
| 操作期间渠道所属推广商发生变化 | 拒绝，删除时提示“推广渠道已变化，请刷新后重试”，编辑保存时只提示“保存失败”，原数据不变 |
| 玩家用已停用渠道的链接注册 | 注册被拒绝，玩家端提示“The invitation code or registration link is invalid. Check the code or ask for a new link.” |
| 玩家用不存在的渠道参数注册 | 注册被拒绝，玩家端提示同上 |
| 创建游客时渠道已停用或不存在 | 不创建游客账号，登录弹窗提示“Unable to start a guest account. Log in to an existing account or contact support.” |
| 账号没有 `system:domain:view` | 域名下拉没有选项，无法新增渠道 |
| 没有推广商 | “新增推广渠道”不可用，列表为空 |
| 当前推广商下没有渠道或筛选无结果 | 列表显示“暂无数据”和“调整筛选条件后再试。” |
| 操作成功但列表刷新失败 | 提示“渠道状态已更新，列表刷新失败，请重试”“推广渠道已删除，列表刷新失败，请重试”“推广商已删除，列表刷新失败，请重试”或“保存成功，推广商列表刷新失败，请重试”。操作已生效，不用重复操作 |

## 5. 验收场景

| 需求编号 | 场景与操作 | 预期结果 |
|---|---|---|
| 7.4-R1 | 新增推广商后切到该页签新增渠道 | 渠道归属该推广商，状态启用，列表显示带 `ch` 参数的推广链接 |
| 7.4-R2 | 玩家打开推广链接注册 | 玩家归属该渠道 |
| 7.4-R3 | 玩家不带渠道参数注册 | 玩家归属官方渠道 |
| 7.4-R4 | 停用渠道后，玩家用该链接注册，运营把会员改绑到该渠道 | 两者都被拒绝；已绑定会员的归属不变 |
| 7.4-R5 | 重新启用渠道 | 新注册和后台绑定恢复 |
| 7.4-R6 | 停用官方渠道后，不带渠道参数注册或创建游客 | 被拒绝，不创建账号，分别按特殊情况中的文案提示 |
| 7.4-R7 | 修改渠道域名 | 后台推广链接更新，旧链接仍能带渠道注册，已绑定会员不变 |
| 7.4-R8 | 删除新建且没有会员和业务引用的渠道 | 删除成功 |
| 7.4-R9 | 删除已有会员的渠道 | 拒绝并提示改为停用，渠道保留 |
| 7.4-R10 | 删除官方渠道 | 拒绝，渠道保留 |
| 7.4-R11 | 系统角色删除没有渠道和引用的普通推广商 | 删除成功，页签同步移除 |
| 7.4-R12 | 非系统角色删除推广商，或删除默认推广商 | 拒绝，推广商保留 |
| 7.4-R13 | 新增与已有推广商同名的推广商 | 不提交，提示更换名称 |
| 7.4-R14 | 按渠道名称片段查询，大小写与原名称不同 | 返回匹配的渠道 |
| 7.4-R15 | 没有 `promotion:channel:delete` 的账号确认删除渠道 | 服务端拒绝，渠道保留 |
| 7.4-R16 | 新建渠道经过多次首页分时汇总、期间没有业务发生，然后删除；已有业务数据写入汇总的渠道删除 | 前者删除成功；后者拒绝，提示“推广渠道已有业务配置或历史记录，请停用渠道”，渠道保留 |
