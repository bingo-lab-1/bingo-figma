# M7 · 代理管理

## 1. 定位与边界

**做什么**:代理返佣活动的配置与计佣、佣金记录查询,代理关系与代理列表,以及推广商和推广渠道的维护。
**首版只做一级(直属)代理**:玩家邀请直属下级,按下级的充值与投注获得返佣。

**收入本仓库的理由**:返佣的判档、打码与冲回全部踩在资金语义上(打码任务、标准计价、
账变来源标识),文档必须与 `资金模型.md`、`标准计价.md` 同仓演进,拆开引用立刻断链 ——
与财务收入本仓库同一个道理。

**不做什么**
- 不做二级返佣、团队模式、三级分销 —— 模式枚举预留,首版不开放(7.1-A1)
- 本模块不设计玩家代理界面;[玩家端Account](../玩家端/Account/README.md)按7.1定义直属邀请与佣金查询、领取交互
- 不做投注折算比例 —— 本版投注返佣按实际下注的 USD 金额计算(7.1-A12)

**铁律**
- **资金域不得反向依赖活动域**(00-公共约定 依赖铁律):佣金入账与冲回一律通过财务账变完成,
  账变带来源标识,本模块不直接改钱包余额
- **佣金记录是审计数据**:计算依据入账后不可改,状态流转逐笔留痕

## 2. 术语表

| 术语 | 定义 | 代码标识 |
|---|---|---|
| 代理关系 | 玩家之间由**邀请码**建立的上下级绑定,绑定后**不可换绑**(D28);完整规则见 7.3 | 代理关系 |
| 直属下级 | 通过邀请直接绑定在某玩家名下的玩家 | 代理关系.下级 |
| 一级代理(直属代理) | 拥有至少一个直属下级的玩家,返佣活动的参与与发放对象 | — |
| 佣金 | 按下级充值或投注计算、发给上级的返佣金额 | 佣金记录 |

## 3. 依赖关系

**上游依赖(我引用)**
- 财务(M5 与 `资金模型.md`):充值订单、钱包与账变、打码任务、标准计价换算记录 ——
  佣金的计算、入账与冲回全部依赖
- 玩法:注单与下注金额(**本仓库范围外**)
- M2 会员管理:用户标签当前命中集(2.5)、玩家档案
- M8 系统管理:域名台账(8.2),7.4 生成推广链接时选用
- M6 账号管理:权限模型与全站操作日志

**下游被依赖(谁引用我)** ← 改代理关系或佣金数据前先看这行
- [M9/9.1 同期群分析](../M9-数据分析/9.1-同期群分析/README.md)：广告归因使用原始注册邀请链及其业务时点定位根用户；分析结果保留获客统计依据，解除不把既有贡献转移到另一根。该消费不新增 M7 补绑、换绑或佣金权益，关系资料不足时只开放注册日口径。
- M2 会员管理:渠道与代理的只读引用(00-公共约定 归属表)
- 推广商与推广渠道(7.4):被 M2 会员查询、M4 活动定向、M6 账号数据范围、M9 同期群分析只读引用
- [玩家端Account](../玩家端/Account/README.md):读取本人直属关系、佣金记录及开放状态,一次领取全部已开放佣金;不增设代理钱包或佣金提现
- [M4 / 4.16 邀请宝箱](../M4-活动管理/4.16-邀请宝箱/README.md):只读 7.3 的稳定关系标识、注册绑定及解除业务时点,据此认定直属下级;有效人数、设备计奖占位、基础奖励和里程碑奖励均由 M4 维护,不复用 7.1 的返佣金额或判档人数。
- [M4 / 4.17 拼多多活动](../M4-活动管理/4.17-拼多多活动/README.md):按 7.3-R7 读取同一份直属新注册绑定与解除事实,为每名合格新好友至多赠送一次旋转机会,并界定本轮加速好友及其关系有效期间。机会余额、注册 IP 名额、轮次进度和加速条件由 M4 维护,不使用佣金判档人数替代活动统计。

4.16 只消费关系事实,不补绑或换绑,也不使注册依赖活动是否可用。解除前已有效的邀请人数和已解锁奖励按活动规则保留;解除前未达标的下级停止继续达标,迟到事实按原业务时点恢复。该依赖新增 7.3-R6 的关系事实输出与恢复要求,不扩展代理列表界面,不修改 7.1 佣金规则。奖励入账与打码由 M4 调用 M5,财务不反向查询 M4 资格。

4.17 同样只读原始关系事实。解除前合法产生的机会及本轮贡献保留,解除业务时点起的新充值、投注不计入原上级本轮加速;迟到事实按原业务时点恢复,不能记入通知到达时的新一轮。旧邀请机会可以跨轮使用,旧好友及其旧充值、投注不能带入新轮加速。R7 不增加补绑、换绑、解除入口或代理列表界面,不改变 7.1 返佣、4.16 奖励或注册成功规则。

## 4. 数据模型

**拥有的数据**(owner=M7)

| 数据 | 说明 | 现状 |
|---|---|---|
| 返佣活动配置 | 开关、名称、时区、人群、模式、比例、档位、打码倍数、领取时点,每次保存生成不可变版本 | 已有 |
| 佣金记录 | 每笔佣金的来源、计算依据快照、状态与流转流水 | 已有 |
| 佣金领取单 | 一次领取的金额、关联记录与账变 | 已有 |
| 代理关系 | 上下级绑定;规则见7.3及D28 | 已有 |
| 推广商 | 渠道的上级归属,含系统预置的默认推广商 | 已有 |
| 推广渠道 | 渠道名称、所属推广商、域名、启停状态,含系统预置的官方渠道 | 已有 |

**只读引用**:充值订单 · 钱包 · 打码任务 · 换算记录(owner=财务)·
注单与下注金额(owner=玩法,**范围外**)·
标签命中集(owner=M2)· 玩家渠道归属(owner=M2)· 域名(owner=M8)。

## 7. 决策清单

| # | 规则主题 | 涉及范围 | 执行结论 |
|---|---|---|---|
| D25 | 投注返佣的结算周期与判档基数 | 7.1 数据结构 · 7.1-R5 | **已定**(2026-11-02 确认):判档按**产生投注的下级本人累计下注**,发放按**本笔下注金额** × 档位比例;两类佣金逐笔生成待领取记录,按配置的锁定天数与每日开放时点到期后**由代理手动领取**,领取入账时产生打码任务(7.1-A4/A5/A14) |
| D26 | 佣金入账币种 | 7.1-R4 · 7.1-R5 | **已定**(2026-08-13 业务确认):以标准计价币种 USD 入账 USD 钱包彩金余额(7.1-A9),钱包未开设时领取时自动开设 |
