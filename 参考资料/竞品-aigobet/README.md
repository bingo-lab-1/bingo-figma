## 三条最重要的结论
1. **活动引擎是最大的产品债**：aigobet 已到 159 个 action_type、40+ 活动一活动一页配置。
   抄它的**功能清单和参数骨架**，但把数据模型做成配置化多态引擎（见 `02`），别抄它一活动一表的结构。
2. **真金/彩金分账 + 打码解锁**是资金核心，冻结/解冻是多路径状态机（资损高发）——优先建模（见 `03`）。
3. **三套身份体系并存**（VIP双轨 / 用户标签 / 测试账号标记），抄前先定 SSOT（见 `01`）。
