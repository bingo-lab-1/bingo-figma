# 8.2 · 域名管理

## 1. 用途

运营维护一份平台域名台账,记录每个域名的地址和用途说明,供内部统一查阅。

本页只做登记,列表是 [7.4 推广渠道](../../M7-代理管理/7.4-推广渠道/README.md)新增、编辑渠道时域名下拉的选项来源。渠道保存所选域名本身,不关联本页记录,所以新增、修改或删除记录都不改变已有渠道的推广链接,也不改变玩家实际访问和注册来源记录。

后台桌面端使用,界面简体中文,时间按操作人浏览器时区展示,不涉及金额。

## 2. 配置项

**筛选条件**

| 条件 | 含义和填写规则 |
|---|---|
| 域名 | 包含匹配,不区分大小写,留空表示不限 |

**列表字段**:ID、域名、描述(空值显示 -)、创建时间、操作(编辑、删除)。按创建时间倒序。入口按钮为新增域名。

**新增与编辑表单**

| 配置项 | 含义和填写规则 |
|---|---|
| 域名 | 必填,以 `http://` 或 `https://` 开头,保存时去除首尾空格,全平台唯一。示例:https://example.com |
| 描述 | 选填,多行文本,保存时去除首尾空格 |

## 3. 操作规则

新增和修改保存后立即写入台账。删除需要确认,删除后不可恢复。

## 4. 特殊情况

| 情况 | 如何处理 |
|---|---|
| 域名为空 | 提示“请输入域名”,不提交 |
| 域名没有协议头 | 提示“请输入正确的域名，例如：https://example.com”,不提交 |
| 域名已存在 | 提示保存失败,原数据不变 |
| 编辑时清空描述 | 原描述保持不变 |

## 5. 验收场景

| 需求编号 | 场景与操作 | 预期结果 |
|---|---|---|
| 8.2-R1 | 新增 `https://a.example.com`,填写描述 | 列表出现该记录 |
| 8.2-R2 | 域名填 `example.com` | 提示“请输入正确的域名，例如：https://example.com”,不提交 |
| 8.2-R3 | 新增已存在的域名 | 提示保存失败,列表不变 |
| 8.2-R4 | 修改域名和描述 | 列表显示新值 |
| 8.2-R4 | 编辑时清空描述后保存 | 描述保持原值 |
| 8.2-R5 | 删除一条记录并确认 | 列表不再显示,玩家访问不受影响 |
| 8.2-R6 | 账号没有 `system:domain:view` | 菜单不显示,直接访问进入无权限页 |
| 8.2-R6 | 账号有查看权限但没有 `system:domain:create`,提交新增 | 服务端拒绝,提示保存失败,列表不变 |

## 6. 相关资料

- 入口与关联页面:系统管理 > 域名管理。
- 权限:查看 `system:domain:view`,新增 `system:domain:create`,编辑 `system:domain:edit`,删除 `system:domain:delete`。
- 数据与责任:域名台账归 M8。
- 共用规则:权限判定见[权限模型](../../M6-账号管理/6.2-角色管理/权限模型.md)。
