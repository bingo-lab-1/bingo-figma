# 11.1 · 多语言

## 1. 用途

运营维护平台的语言清单。语言开关决定后台多语言表单出现哪些页签,也决定玩家端语言切换里有哪些选项。

本页只管语言是否可用,不维护翻译内容:玩家端固定文案随前端发版,通知和网站文本分别在 [11.2](../11.2-通知管理/README.md)、[11.3](../11.3-网站管理/README.md) 填写。玩家端当前只支持 `en` 和 `tc` 两个语言代码。

后台桌面端使用,界面简体中文,时间按操作人浏览器时区展示,不涉及金额。

## 2. 配置项

**筛选条件**(可组合,留空表示不限)

| 条件 | 含义和填写规则 |
|---|---|
| 语言名称 | 包含匹配,不区分大小写 |
| 语言代码 | 包含匹配,不区分大小写 |
| 状态 | 已开启 / 已关闭 |

**列表字段**:ID、语言名称、语言代码、状态、创建时间、操作。按创建时间倒序。

**新增与编辑表单**

| 配置项 | 含义和填写规则 |
|---|---|
| 语言名称 | 必填,保存时去除首尾空格。显示在后台页签和玩家端语言切换里,示例:繁體中文 |
| 语言代码 | 必填,保存时去除首尾空格,全平台唯一。新增时填写,编辑时不可修改,示例:tc |
| 状态 | 开关,默认开启 |

## 3. 操作规则

### 新增语言

状态开启时,保存后立即成为启用语言。此后通知和网站表单要求补齐该语言的文本,旧内容在下次编辑时才需要补。

### 修改语言

可以修改语言名称和状态,保存后立即生效。

### 关闭语言

关闭后,后台多语言表单不再显示该语言页签,玩家端语言切换不再显示该语言;已保存的该语言文本保留,重新开启后恢复使用。

玩家正在使用的语言被关闭时,玩家端自动切到 English;English 也已关闭时切到第一个可用语言。语言清单读取失败时不切换,玩家继续使用当前语言。

### 删除语言

确认后删除记录,不可恢复。删除不清理通知和网站里已保存的该语言文本。

## 4. 特殊情况

| 情况 | 如何处理 |
|---|---|
| 语言名称或代码为空 | 提示“请输入语言名称”或“请输入语言代码”,不提交 |
| 语言代码已存在 | 提示保存失败,原数据不变 |
| 新增 `en`、`tc` 以外的代码 | 允许保存,后台出现页签,通知和网站表单要求填写该语言;玩家端不显示该语言 |
| 新环境未录入语言 | 系统不预置语言,需要手工新增 `en`、`tc`。清单为空时后台多语言表单没有页签,玩家端不显示语言切换 |
| 全部语言已关闭 | 与清单为空的表现相同,玩家继续使用当前语言 |

## 5. 验收场景

| 需求编号 | 场景与操作 | 预期结果 |
|---|---|---|
| 11.1-R1 | 新增语言名称“繁體中文”、代码 `tc`,状态开启 | 列表出现该语言;通知和网站表单出现该语言页签;玩家端语言切换显示“繁體中文” |
| 11.1-R2 | 新增语言时填写已存在的语言代码 | 提示保存失败,列表不变 |
| 11.1-R2 | 语言名称只填空格后保存 | 提示“请输入语言名称”,不提交 |
| 11.1-R3 | 编辑一条语言 | 语言代码不可修改,名称和状态可修改 |
| 11.1-R4 | 关闭 `tc`,正在使用繁体的玩家刷新页面 | 玩家端切到 English,语言切换不再显示繁体;后台表单不再显示该页签 |
| 11.1-R4 | 重新开启 `tc` | 页签恢复,此前保存的繁体文本仍在 |
| 11.1-R5 | 新增代码 `ja` 并开启 | 后台出现页签;玩家端语言切换不显示 |
| 11.1-R6 | 删除一条语言并确认 | 列表不再显示该语言,通知和网站已保存文本不变 |
| 11.1-R7 | 账号没有 `cms:language:view` | 菜单不显示,直接访问进入无权限页 |
| 11.1-R7 | 账号有查看权限但没有 `cms:language:create`,提交新增 | 服务端拒绝,提示保存失败,列表不变 |

## 6. 相关资料

- 入口与关联页面:内容管理 > 多语言。启用语言被 [11.2](../11.2-通知管理/README.md)、[11.3](../11.3-网站管理/README.md) 及游戏平台、类型、子游戏的多语言表单使用。
- 权限:查看 `cms:language:view`,新增 `cms:language:create`,编辑 `cms:language:edit`,删除 `cms:language:delete`。
- 数据与责任:语言清单归 M11。
- 共用规则:权限判定见[权限模型](../../M6-账号管理/6.2-角色列表/权限模型.md)。
