# M11 · 内容管理

## 1. 定位与边界

**做什么**:维护玩家端面向所有人展示的基础内容:可用语言、站内通知、网站标题与分享信息、新版首页活动入口。

**不做什么**
- 不做界面文案翻译 —— 玩家端固定文案随前端发版,本模块只决定语言开关
- 不做推送、邮件、短信,也不做定时发布、草稿和已读统计 —— 通知保存后立即生效,只在玩家端通知弹窗展示
- 不定义活动规则 —— 首页活动入口只是跳转,活动资格和奖励归 M4
- 不管理首页游戏内容 —— Hot Games 的游戏与供应商归 [M10 游戏管理](../M10-游戏管理/README.md)
- 不做后台账号、角色和权限配置 —— 归 M6

**铁律**
- **权限判定一律在服务端**。四个页面的按钮都不按权限隐藏,无编辑权限的账号在提交时被服务端拒绝
- **保存即生效**。本模块没有审批和发布步骤,玩家下一次加载页面就看到新内容
- **首页活动入口只接受站内路径**,外部链接一律拒绝

## 2. 术语表

| 术语 | 定义 |
|---|---|
| 语言代码 | 语言的唯一标识。玩家端当前只识别 `en`(English)和 `tc`(繁體中文) |
| 启用语言 | 状态为已开启的语言。后台多语言表单按它生成页签,玩家端按它生成语言切换项 |
| 全体通知 | 没有选择目标用户的通知 |
| 指定用户通知 | 选择了目标用户的通知 |
| 网站 Metadata | 全站一份的图片、标题和描述,用于页面标题和社交分享卡片 |
| 首页活动入口 | 新版首页 Hot Games 右侧的竖排跳转入口,最多 3 个 |
| 配置版本 | 首页活动入口配置每次保存加一的序号,用于发现两人同时修改 |

**上游依赖(我引用)**
- M2 用户管理:通知的目标用户选项来自会员清单,账号需要 `user:list:view`

- 图片上传能力(**本仓库范围外**):网站图片与活动图标

**下游被依赖(谁引用我)** ← 改语言开关或内容结构前先看这行
- 玩家端:语言切换、通知弹窗、页面标题与分享卡片、首页活动栏
- 后台多语言表单:通知(11.2)、网站(11.3),以及游戏平台、游戏类型、子游戏(**本仓库范围外**)都按启用语言出页签
