# M11 · 内容管理

## 1. 定位与边界

**做什么**:维护玩家端面向所有人展示的基础内容:站内通知、网站标题与分享信息、新版首页活动入口。

**不做什么**
- 不做语言配置和界面文案翻译 —— 玩家端固定提供英文、中文两种语言(D113),固定文案随前端发版
- 不做推送、邮件、短信,也不做定时发布、草稿和已读统计 —— 通知保存后立即生效,只在玩家端通知弹窗展示
- 不定义活动规则 —— 首页活动入口只是跳转,活动资格和奖励归 M4
- 不管理首页游戏内容 —— Hot Games 的游戏与供应商归 [M10 游戏管理](../M10-游戏管理/README.md)
- 不做后台账号、角色和权限配置 —— 归 M6

**铁律**
- **权限判定一律在服务端**。三个页面的按钮都不按权限隐藏,无编辑权限的账号在提交时被服务端拒绝
- **保存即生效**。本模块没有审批和发布步骤,玩家下一次加载页面就看到新内容
- **首页活动入口只接受站内路径**,外部链接一律拒绝

## 2. 术语表

| 术语 | 定义 |
|---|---|
| 内容语言 | 玩家端提供的两种语言:英文(`en`)和中文(`zh`,简体中文)。后台的多语言名称与文本按这两种语言分别填写,必填项两种都要填;玩家按当前界面语言看到对应内容 |
| 全体通知 | 没有选择目标用户的通知 |
| 指定用户通知 | 选择了目标用户的通知 |
| 网站 Metadata | 全站一份的图片、标题和描述,用于页面标题和社交分享卡片 |
| 首页活动入口 | 新版首页 Hot Games 右侧的竖排跳转入口,最多 3 个 |
| 配置版本 | 首页活动入口配置每次保存加一的序号,用于发现两人同时修改 |
