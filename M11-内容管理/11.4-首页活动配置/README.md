# 11.4 · 首页活动配置

## 1. 用途

运营配置玩家端新版首页 Hot Games 右侧的竖排活动入口,最多 3 个,用来把玩家引到站内活动页。

本页只配置入口的文字、图标和跳转路径,活动规则由各活动维护。入口只有英文和繁体两套名称,不跟随 [11.1](../11.1-多语言/README.md) 的启用语言。本页不提供按用户、渠道或时间投放,也不提供外部链接。

后台桌面端使用,界面简体中文,不涉及金额和时间。

## 2. 配置项

每个入口包含以下配置,没有默认内容。

| 配置项 | 含义和填写规则 |
|---|---|
| 入口标识 | 必填,最多 50 字符,只能用小写字母、数字和中划线,中划线只能夹在字母或数字之间,同一份配置内不能重复。示例:vip-daily |
| 站内路径 | 必填,最多 200 字符,以单个 `/` 开头,不能含空格和反斜杠。示例:/pdd-spin |
| 英文名称 | 必填,最多 30 字符,保存时去除首尾空格。示例:VIP Daily |
| 繁体中文名称 | 必填,最多 30 字符,保存时去除首尾空格。示例:會員簽到 |
| 活动图标 | 必填,上传 PNG、JPEG 或 WebP,2 MB 以内,建议 1:1 正方形。保存的地址必须是 https 地址 |
| 顺序 | 按列表从上到下显示,用上移、下移调整 |

入口总数最多 3 个,达到上限后新增按钮不可用。

## 3. 操作规则

### 编辑与保存

进入页面自动载入当前配置,重新载入按钮读取服务端最新配置。新增、删除、排序都只改页面内容,点击保存才提交。没有改动时保存按钮不可用,图标上传中不能保存。

一次保存提交整份列表。服务端校验全部入口后,整份替换原配置,配置版本加一,并写入操作日志,记录修改前后的完整内容。保存结果以服务端返回为准,页面随后显示新版本内容。

### 玩家端生效

玩家下次加载首页时读取新配置,不需要发版。

| 情况 | 玩家端表现 |
|---|---|
| 有入口 | 在 Hot Games 右侧按配置顺序显示图标和名称,点击进入站内路径 |
| 语言 | 繁体界面显示繁体名称,其他情况显示英文名称 |
| 玩家点击入口的关闭按钮 | 该入口在本次页面隐藏,刷新后恢复 |
| 没有入口 | 不显示活动栏 |

## 4. 特殊情况

| 情况 | 如何处理 |
|---|---|
| 两人同时修改 | 后保存的人提示“首页活动入口已更新，请刷新后重试”,原配置不变,重新载入后再改 |
| 入口标识重复 | 提示“入口标识不能重复”,不提交 |
| 内容不符合规则 | 页面提示对应字段;页面未拦截的内容(如入口标识超过 50 字符)由服务端拒绝,提示“首页活动入口格式无效”,原配置不变 |
| 路径是 `//` 开头、外部地址或含反斜杠 | 拒绝保存,原配置不变 |
| 图片类型或大小不符合要求 | 提示“请选择 PNG、JPEG 或 WebP 图片。”或“图片不能为空，且不能超过 2 MB。”,不上传 |
| 图片损坏或上传失败 | 提示上传失败原因,原图标保留,可重新上传 |
| 站内路径不存在或活动已下线 | 系统不校验路径是否存在,入口继续显示,由运营手动移除 |
| 已保存的配置损坏 | 后台提示“首页活动入口配置无效，请联系管理员”,不能读取和保存;玩家端不显示活动栏,首页其他内容正常 |
| 活动入口读取失败 | 玩家端不显示活动栏,首页其他内容正常 |
| 配置版本达到上限 | 提示“配置版本已达到上限”,原配置不变 |

## 5. 验收场景

| 需求编号 | 场景与操作 | 预期结果 |
|---|---|---|
| 11.4-R1 | 新增 2 个入口并保存 | 提示保存成功;玩家刷新首页,活动栏按列表顺序显示 2 个入口,点击进入对应站内页 |
| 11.4-R2 | 已有 3 个入口 | 新增按钮不可用 |
| 11.4-R2 | 绕过页面提交 4 个入口 | 提示“首页活动入口格式无效”,原配置不变 |
| 11.4-R3 | 入口标识填 `VIP_daily` | 提示只能使用小写字母、数字和中划线,不提交 |
| 11.4-R3 | 站内路径填 `https://example.com` 或 `//example.com` | 提示必须是以 / 开头的站内路径,不提交 |
| 11.4-R3 | 站内路径含反斜杠并绕过页面校验提交 | 服务端拒绝,原配置不变 |
| 11.4-R4 | 两个入口使用相同入口标识 | 提示“入口标识不能重复”,不提交 |
| 11.4-R5 | 上传 3 MB 图片 | 提示图片不能超过 2 MB,不上传 |
| 11.4-R5 | 图标上传中点击保存 | 保存按钮不可用 |
| 11.4-R6 | A、B 打开同一版本,A 先保存,B 再保存 | B 提示“首页活动入口已更新，请刷新后重试”,配置为 A 的内容 |
| 11.4-R7 | 删除全部入口并保存 | 玩家端不显示活动栏 |
| 11.4-R8 | 已保存的配置内容损坏 | 后台提示配置无效;玩家端首页正常打开,不显示活动栏 |
| 11.4-R9 | 玩家关闭一个入口后刷新页面 | 关闭后该入口隐藏,其余入口保留;刷新后恢复 |
| 11.4-R10 | 繁体玩家查看活动栏 | 显示繁体名称,英文玩家显示英文名称 |
| 11.4-R11 | 账号只有 `cms:home-activity:view`,修改后保存 | 服务端拒绝,原配置不变 |
| 11.4-R12 | 保存成功后查看操作日志 | 能查到操作人和修改前后的配置内容 |

## 6. 相关资料

- 入口与关联页面:内容管理 > 首页活动配置,页面标题为“热门游戏活动入口”。保存记录在[操作日志](../../M6-账号管理/6.3-操作日志/README.md)查询。
- 权限:查看 `cms:home-activity:view`;保存和上传图标 `cms:home-activity:edit`。
- 数据与责任:入口配置归 M11;落地页是否存在、活动是否进行中由对应活动维护。
- 共用规则:活动规则见 [M4 活动管理](../../M4-活动管理/README.md);权限判定见[权限模型](../../M6-账号管理/6.2-角色管理/权限模型.md)。
