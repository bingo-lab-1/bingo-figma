# 11.3 · 网站管理

## 1. 用途

运营维护全站一份的网站配置，分两部分：网站品牌，即网站名称、Logo、网站图标和应用图标；网站 Metadata，即一张分享图片，以及英文、中文的网站标题和描述。玩家端用 Metadata 生成浏览器页面标题、搜索摘要和社交分享卡片。网站名称和应用图标同时是玩家把游戏安装到桌面后显示的名称和图标，两项都配置后玩家端才提供安装，见[安装到桌面](../../玩家端/安装到桌面/README.md)。

本页不提供按页面或按渠道配置,也不改玩家端页面正文。

后台桌面端使用,界面简体中文。标题和描述固定填写英文、中文两种,都必填；网站名称只填一份。不涉及金额和时间。

## 2. 配置项

### 网站品牌

| 配置项 | 含义和填写规则 |
|---|---|
| 网站名称 | 必填，一行文字，最多 30 个字，保存时去首尾空格。页面提示：玩家端的推广协议、条款等文字用它称呼本站，没有上传 Logo 时页头也显示它。玩家安装到桌面后，它显示在桌面图标下方，也显示在安装页，不另设桌面名称；名称较长时手机系统会截断 |
| Logo | 选填，单张 PNG/JPEG/WebP，10 MB 以内。页面提示：建议透明底横版，不上传时玩家端页头显示网站名称 |
| 网站图标 | 选填，单张 PNG/JPEG/WebP，10 MB 以内，建议正方形、至少 192 × 192 px，系统保存为 192 × 192 px，可以是透明底。只显示在浏览器标签页和收藏夹，不上传则不显示；不能代替应用图标 |
| 应用图标 | 选填，排在网站图标之后。必须是正方形且边长不小于 512 px，系统统一保存为 512 × 512 px 的图片。页面提示“PNG / JPEG / WebP · 10 MB 以内 · 须为正方形、至少 512 × 512 px；请使用不透明底（透明底在 iPhone 上显示为黑色），主体放在中间、四周留边（安卓会把图标裁成圆形或圆角）；玩家安装到桌面后显示为桌面图标，不上传则不提供安装” |

### 标题与分享

| 配置项 | 含义和填写规则 |
|---|---|
| 分享图片 | 必填，单张 PNG/JPEG/WebP，前端上限 10 MB，服务端只接受边长不超过 4096 px 的静态图片。发布图按 1200×630 范围等比缩小为 JPEG，不放大小图；当前玩家 Metadata 仍声明 1600×900，声明尺寸与实际发布尺寸可能不同 |
| 标题 | 英文、中文都必填,多行文本 |
| 描述 | 英文、中文都必填,多行文本 |

系统没有预设内容。首次保存前,玩家端使用默认标题和描述“Bingo”,没有分享图片，也不提供安装。

## 3. 操作规则

### 查看与保存

进入页面自动载入当前配置。保存时网站品牌、分享图片和英文、中文文本一起提交,整份覆盖原配置,主分支在 generateMetadata 中直接查询并解析配置，没有该功能专用的 60 秒进程缓存。

保存不做版本校验,两人同时编辑时后保存的内容覆盖先保存的内容。

### 上传应用图标

选择图片后立即上传并检查。不是正方形或边长小于 512 px 的图片被拒绝，在该项下方提示原因，原图标不变。上传成功后还要点“保存”才生效。清除已上传的图标并保存后，玩家端不再提供安装。

保存后约一分钟内，玩家端的安装到桌面跟随新配置：网站名称和应用图标都已配置时，每个页面都向浏览器声明可以安装，PWA 链接显示安装页；缺任意一项时不提供安装，PWA 链接直接进入游戏首页。没有应用图标时，[7.4 推广渠道](../../M7-代理管理/7.4-推广渠道/README.md)的列表在每条 PWA 链接下方提示“未配置应用图标，链接将直接进入游戏”。

修改网站名称或应用图标后，新安装的玩家使用新的名称和图标。已安装设备上的名称和图标何时更新由手机系统决定，见[安装到桌面](../../玩家端/安装到桌面/README.md)。

### 玩家端取值

网站品牌只由玩家仓库 `feat/us-ui-dev` 分支读取：页头 Logo、推广协议和条款中的站名、网站图标和安装到桌面都按它显示；玩家 `main` 只读取下述 Metadata。

玩家主分支支持 en/tc，标题和描述先取当前 locale；值为 null 或缺失时取默认 en。后台保存 en/zh，因此 tc 页面通常使用英文。当前语言值为空字符串时不会切到英文，最终标题或描述为空则回到默认“Bingo”，不带分享图片。配置请求失败或 JSON 无法解析时没有专用异常恢复，不能保证 Metadata 生成正常完成。

## 4. 特殊情况

| 情况 | 如何处理 |
|---|---|
| 网站名称未填 | 提示“网站名称不能为空，且最多 30 个字符”，不提交。输入框最多输入 30 个字，服务端同样校验必填和长度 |
| 分享图片未上传 | 提示“请上传分享图片”,不提交 |
| 英文或中文的标题或描述未填 | 提示带语言的字段名,如“请输入英文标题”“请输入中文描述”,自动切到出错语言,页签标红,不提交 |
| 已有配置缺少英文或中文 | 再次保存时要求补齐缺少的标题和描述 |
| 应用图标不是正方形或边长小于 512 px | 上传被拒绝，提示“上传失败：图片需为正方形，且边长不小于 512 像素”，原图标不变 |
| 未上传应用图标，或网站名称还没有设置 | 玩家端不提供安装，PWA 链接直接进入游戏首页并保留链接上的参数 |
| 配置读取失败 | 后台表单保持空白，重新填写并保存会覆盖原配置；玩家 Metadata 查询或 JSON 解析错误可能导致生成失败，不能视为正常默认内容 |
| 保存失败 | 提示保存失败,原配置不变,可重新提交 |
| 账号只有 `cms:website:view` | 可以查看全部配置，包括应用图标；保存由服务端拒绝，原配置不变 |

## 5. 验收场景

| 需求编号 | 场景与操作 | 预期结果 |
|---|---|---|
| 11.3-R1 | 填写网站名称,上传分享图片,填写中文和英文的标题与描述,保存 | 提示保存成功；玩家重新生成 Metadata 时查询配置；en 页面使用英文，tc 缺失时也取英文，分享图共用 |

| 11.3-R3 | 配置只有 en/zh，使用 tc 页面访问 | 使用英文标题和描述；若最终标题或描述为空才使用默认 Bingo |
| 11.3-R4 | 从未保存过配置,打开玩家端 | 页面标题和描述为“Bingo”,没有分享图片 |

| 11.3-R6 | 在网站品牌上传边长 512 px 以上的正方形应用图标并保存 | 保存成功；再次打开能看到已保存的图标；约一分钟后 PWA 链接显示安装页 |
