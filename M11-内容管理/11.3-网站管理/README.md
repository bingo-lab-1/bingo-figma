# 11.3 · 网站管理

## 1. 用途

运营维护全站一份的网站 Metadata:一张分享图片,以及英文、中文的网站标题和描述。玩家端用它生成浏览器页面标题、搜索摘要和社交分享卡片。

本页不提供按页面或按渠道配置,也不改玩家端页面正文。

后台桌面端使用,界面简体中文,文本固定填写英文、中文两种,都必填,不涉及金额和时间。

## 2. 配置项

| 配置项 | 含义和填写规则 |
|---|---|
| 图片 | 必填,单张。分享卡片按 1600×900 声明尺寸,建议按此比例制作 |
| 标题 | 英文、中文都必填,多行文本 |
| 描述 | 英文、中文都必填,多行文本 |

系统没有预设内容。首次保存前,玩家端使用默认标题和描述“Bingo”,没有分享图片。

## 3. 操作规则

### 查看与保存

进入页面自动载入当前配置。保存时图片和英文、中文文本一起提交,整份覆盖原配置,玩家下次加载页面生效。

保存不做版本校验,两人同时编辑时后保存的内容覆盖先保存的内容。

### 玩家端取值

玩家端按当前界面语言取英文或中文的标题和描述,不改用另一种语言。标题或描述任一取不到时,整体回到默认标题和描述“Bingo”,也不带分享图片。

## 4. 特殊情况

| 情况 | 如何处理 |
|---|---|
| 图片未上传 | 提示“请上传图片”,不提交 |
| 英文或中文的标题或描述未填 | 提示带语言的字段名,如“请输入英文标题”“请输入中文描述”,自动切到出错语言,页签标红,不提交 |
| 已有配置缺少英文或中文 | 再次保存时要求补齐缺少的标题和描述 |
| 配置读取失败 | 后台表单保持空白,重新填写并保存会覆盖原配置;玩家端使用默认标题和描述,页面正常打开 |
| 保存失败 | 提示保存失败,原配置不变,可重新提交 |

## 5. 验收场景

| 需求编号 | 场景与操作 | 预期结果 |
|---|---|---|
| 11.3-R1 | 上传图片,填写中文和英文的标题与描述,保存 | 提示保存成功;刷新玩家端,中文界面的页面标题和分享卡片使用中文内容,英文界面使用英文内容 |
| 11.3-R2 | 不上传图片直接保存 | 提示“请上传图片”,不提交 |
| 11.3-R2 | 英文描述未填时保存 | 切到英文页签并提示“请输入英文描述”,不提交 |
| 11.3-R3 | 配置里缺少中文标题,玩家使用中文界面访问 | 页面标题和描述为“Bingo”,没有分享图片,不使用英文内容 |
| 11.3-R4 | 从未保存过配置,打开玩家端 | 页面标题和描述为“Bingo”,没有分享图片 |
| 11.3-R5 | 账号只有 `cms:website:view`,修改后保存 | 服务端拒绝,提示保存失败,原配置不变 |

## 6. 相关资料

- 入口与关联页面:内容管理 > 网站管理,页面标题为“网站 Metadata”。语言范围见 [M11 决策 D113](../README.md#7-决策清单)。
- 权限:查看 `cms:website:view`;保存和上传图片 `cms:website:edit`。
- 数据与责任:网站 Metadata 归 M11,玩家端只读展示。
- 共用规则:权限判定见[权限模型](../../M6-账号管理/6.2-角色管理/权限模型.md)。
