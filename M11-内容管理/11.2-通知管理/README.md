# 11.2 · 通知管理

## 1. 用途

运营发布站内通知，玩家主分支在首页通知轮播区查看。通知可以发给全体用户,也可以发给选定的用户。

保存后立即生效,没有草稿和发布步骤。本页不提供定时发布、推送、邮件、短信和已读统计。

后台桌面端使用,界面简体中文,通知内容固定填写英文、中文两种,都必填,时间按操作人浏览器时区展示,不涉及金额。

## 2. 配置项

**筛选条件**(可组合,留空表示不限)

| 条件 | 含义和填写规则 |
|---|---|
| 标题 | 在中文和英文标题里做包含匹配,任一语言包含即命中,区分大小写 |
| 描述 | 在中文和英文描述里做包含匹配,任一语言包含即命中,区分大小写 |

筛选区默认展开全部条件。切换为选择模式后只显示已添加的条件,可用“添加筛选”增减;模式和已添加条件按后台账号保存在当前浏览器。没有已填写的条件时“清空筛选”不可用。

**列表字段**

| 字段 | 含义 |
|---|---|
| ID | 通知编号 |
| 标题 | 显示简体中文标题 |
| 描述 | 显示简体中文描述,最多两行 |
| 目标用户 | “全体用户”,或“指定用户 (人数)” |
| 创建时间、更新时间 | 按创建时间倒序 |
| 操作 | 编辑、删除 |

**新增与编辑表单**

| 配置项 | 含义和填写规则 |
|---|---|
| 标题 | 英文、中文都必填,多行文本 |
| 描述 | 英文、中文都必填,多行文本 |
| 目标用户 | 选填,多选,选项来自会员清单。不选表示全体用户 |

## 3. 操作规则

### 新增通知

点“添加通知”打开表单。英文、中文的标题和描述都填写后才能保存。保存后立即对目标玩家可见。

### 修改通知

文本修改后立即替换原内容。目标用户可以换成其他用户,但不能清空:已指定用户的通知清空目标后保存,原目标用户保持不变。要改成全体用户,须删除后重新新增。

### 删除通知

确认后删除，不可恢复；玩家再次查询时不再返回该通知，已打开的轮播没有实时删除订阅。

### 玩家端展示

已登录玩家查询全体通知及目标包含本人的通知；未登录访客查询全体通知。两者都在首页展示。

主分支使用 cache-and-network 查询，按接口列表顺序展示。多于一条时每 5 秒切换，也可点击圆点；这是轮播切换，不是每 5 秒重新请求。没有通知时隐藏区域，加载中显示提示，没有未读标记、已看时间、按日分组或通知弹窗。字符串文本直接显示；对象优先取当前 locale，缺失或为空时取英文。主分支 locale 为 en/tc，因此后台新保存的 en/zh 内容在 tc 页面通常显示英文。

## 4. 特殊情况

| 情况 | 如何处理 |
|---|---|
| 英文或中文的标题或描述未填 | 提示带语言的字段名,如“请输入英文标题”“请输入中文描述”,自动切到出错语言,页签标红,不提交 |
| 已有通知缺少英文或中文 | 编辑时要求补齐缺少的标题和描述后才能保存 |
| 账号没有 `user:list:view` | 目标用户下拉没有选项,只能发全体通知;编辑已有指定用户通知时原目标保持不变 |
| 目标玩家没有任何可见通知 | 首页隐藏通知区域 |
| 保存失败 | 提示保存失败,原数据不变,可重新提交 |

## 5. 验收场景

| 需求编号 | 场景与操作 | 预期结果 |
|---|---|---|
| 11.2-R1 | 填写英文、中文的标题和描述,不选目标用户,保存 | 列表目标用户显示“全体用户”;未登录访客及已登录玩家下次查询首页通知时均可见 |
| 11.2-R2 | 中文已填、英文标题未填时保存 | 切到英文页签并提示“请输入英文标题”,不提交 |
| 11.2-R3 | 选择 2 名目标用户保存 | 列表显示“指定用户 (2)”;这 2 名玩家登录后可见,其他已登录玩家不可见 |
| 11.2-R4 | 未登录访客打开首页 | 查询并展示全体通知，多个结果每 5 秒轮播 |
| 11.2-R5 | 编辑已指定用户的通知,清空目标用户后保存 | 提示保存成功,目标用户保持原值 |
| 11.2-R6 | 用中文关键字筛选标题 | 返回中文标题包含该关键字的通知 |
| 11.2-R6 | 用只出现在英文标题里的关键字筛选 | 返回该通知 |
| 11.2-R7 | 删除一条通知并确认 | 后台列表移除，玩家下次查询时不再返回 |
| 11.2-R8 | 通知只有 en/zh 文本，玩家使用 tc 界面查看 | 读取不到 tc 时显示英文；不是隐藏英文 |
| 11.2-R9 | 账号只有 `cms:notification:view`,提交新增 | 服务端拒绝,提示保存失败,列表不变 |

## 6. 相关资料

- 入口与关联页面:内容管理 > 通知管理。玩家端入口是首页轮播区。语言范围见 [M11 决策 D113](../README.md#7-决策清单)。
- 权限:查看 `cms:notification:view`,新增 `cms:notification:create`,编辑 `cms:notification:edit`,删除 `cms:notification:delete`。选择目标用户另需 `user:list:view`。
- 数据与责任:通知内容归 M11,会员清单归 M2。
- 共用规则:权限判定见[权限模型](../../M6-账号管理/6.2-角色管理/权限模型.md)。
