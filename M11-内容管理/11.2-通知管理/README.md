# 11.2 · 通知管理

## 1. 用途

运营发布站内通知,已登录玩家(含游客账号)点击玩家端顶部通知按钮后在弹窗里查看。通知可以发给全体用户,也可以发给选定的用户。

保存后立即生效,没有草稿和发布步骤。本页不提供定时发布、推送、邮件、短信和已读统计。

后台桌面端使用,界面简体中文,通知内容按启用语言分别填写,时间按操作人浏览器时区展示,不涉及金额。

## 2. 配置项

**筛选条件**(可组合,留空表示不限)

| 条件 | 含义和填写规则 |
|---|---|
| 标题 | 只在繁体(`tc`)标题里做包含匹配,区分大小写 |
| 描述 | 只在繁体(`tc`)描述里做包含匹配,区分大小写 |

**列表字段**

| 字段 | 含义 |
|---|---|
| ID | 通知编号 |
| 标题 | 显示繁体标题 |
| 描述 | 显示繁体描述,最多两行 |
| 目标用户 | “全体用户”,或“指定用户 (人数)” |
| 创建时间、更新时间 | 按创建时间倒序 |

**新增与编辑表单**

| 配置项 | 含义和填写规则 |
|---|---|
| 标题 | 每个启用语言都必填,多行文本 |
| 描述 | 每个启用语言都必填,多行文本 |
| 目标用户 | 选填,多选,选项来自会员清单。不选表示全体用户 |

## 3. 操作规则

### 新增通知

每个启用语言的标题和描述都填写后才能保存。保存后立即对目标玩家可见。

### 修改通知

文本修改后立即替换原内容。目标用户可以换成其他用户,但不能清空:已指定用户的通知清空目标后保存,原目标用户保持不变。要改成全体用户,须删除后重新新增。

### 删除通知

确认后删除,玩家端立即不再显示,不可恢复。

### 玩家端展示

已登录玩家看到全体通知,以及目标用户包含本人的通知。未登录访客没有通知入口。

通知按创建时间倒序展示,多条时每 5 秒自动切换,玩家也可以手动切换。描述最多显示三行。文本按玩家当前语言取值,该语言缺失时显示英文,英文也缺失时不显示。

## 4. 特殊情况

| 情况 | 如何处理 |
|---|---|
| 某个语言的标题或描述未填 | 提示“请输入标题”或“请输入描述”,自动切到出错语言,页签标红,不提交 |
| 新增语言后编辑旧通知 | 要求补齐新语言的标题和描述 |
| 账号没有 `user:list:view` | 目标用户下拉没有选项,只能发全体通知;编辑已有指定用户通知时原目标保持不变 |
| 目标玩家没有任何可见通知 | 玩家端弹窗显示“暂无通知” |
| 保存失败 | 提示保存失败,原数据不变,可重新提交 |

## 5. 验收场景

| 需求编号 | 场景与操作 | 预期结果 |
|---|---|---|
| 11.2-R1 | 填写全部启用语言的标题和描述,不选目标用户,保存 | 列表目标用户显示“全体用户”;所有已登录玩家的通知弹窗出现该通知 |
| 11.2-R2 | 繁体已填、英文标题未填时保存 | 切到英文页签并提示“请输入标题”,不提交 |
| 11.2-R3 | 选择 2 名目标用户保存 | 列表显示“指定用户 (2)”;这 2 名玩家登录后可见,其他已登录玩家不可见 |
| 11.2-R4 | 未登录访客打开玩家端 | 顶部不显示通知按钮 |
| 11.2-R5 | 编辑已指定用户的通知,清空目标用户后保存 | 提示保存成功,目标用户保持原值 |
| 11.2-R6 | 用繁体关键字筛选标题 | 返回繁体标题包含该关键字的通知 |
| 11.2-R6 | 用只出现在英文标题里的关键字筛选 | 查不到该通知 |
| 11.2-R7 | 删除一条通知并确认 | 列表和玩家端都不再显示 |
| 11.2-R8 | 玩家使用繁体,通知没有繁体文本但有英文 | 显示英文文本 |
| 11.2-R9 | 账号只有 `cms:notification:view`,提交新增 | 服务端拒绝,提示保存失败,列表不变 |

## 6. 相关资料

- 入口与关联页面:内容管理 > 通知管理。玩家端入口是顶部通知按钮。可填语言来自 [11.1](../11.1-多语言/README.md)。
- 权限:查看 `cms:notification:view`,新增 `cms:notification:create`,编辑 `cms:notification:edit`,删除 `cms:notification:delete`。选择目标用户另需 `user:list:view`。
- 数据与责任:通知内容归 M11,会员清单归 M2。
- 共用规则:权限判定见[权限模型](../../M6-账号管理/6.2-角色管理/权限模型.md)。
