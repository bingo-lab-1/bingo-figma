# 5.16 · 币种管理

## 1. 用途

财务或技术运营维护平台币种主数据:有哪些币种、是否可用、能否充值和提现。汇率由系统自动同步,本页只读展示。

本页不配置链、合约地址和 RPC,这些在 [5.15 Crypto配置](../5.15-Crypto配置/README.md)。一个币种支持多条链时只保留一条币种记录,不重复新增。

后台桌面端使用,界面简体中文,时间按操作人浏览器时区展示。汇率含义为“1 单位该币种等于多少 USD”。

## 2. 配置项

**筛选条件**(可组合,留空表示不限)

| 条件 | 含义和填写规则 |
|---|---|
| 名称 | 包含匹配,区分大小写 |
| 类型 | 全部 / 加密货币 / 法币 |
| 状态 | 全部 / 正常 / 禁用 |

**列表字段**

| 字段 | 含义 |
|---|---|
| 类型、名称、货币 | 币种基本信息,货币即货币代码 |
| 价格最小变动单位、数量最小变动单位 | 见下方“新增与编辑表单” |
| 汇率 | 系统同步的最新值,没有值时显示“不可用” |
| 汇率来源、汇率时点 | 最新汇率的来源和行情时间,空值显示 - |
| 允许提现、允许充值、是否默认、状态 | 当前开关 |
| 创建时间、操作 | 默认币种排最前,其余按创建时间倒序 |

**新增与编辑表单**

| 配置项 | 含义和填写规则 |
|---|---|
| 类型 | 必选,加密货币 / 法币,默认加密货币 |
| 状态 | 必选,正常 / 禁用,默认正常 |
| 名称 | 必填,最多 100 字符,保存时去除首尾空格。忽略大小写和首尾空格后全平台唯一 |
| 货币代码 | 必填,保存时转大写,全平台唯一。法币为 3 位英文字母;加密货币为 2 至 20 位英文字母或数字,且至少含一个字母 |
| 价格最小变动单位 | 必填,大于 0,默认 0.01 |
| 数量最小变动单位 | 必填,大于 0,默认 0.001 |
| 允许提现 | 开关,默认开启 |
| 允许充值 | 开关,默认开启 |
| 设为默认 | 开关,默认关闭 |

## 3. 操作规则

### 配置的业务影响

| 配置 | 影响 |
|---|---|
| 状态 | 禁用后该币种不再用于充值、提现和第三方游戏钱包,活动发奖按币种不可用处理 |
| 允许充值 | 状态正常且开启时,才出现在 Crypto 入金选项和充值商品中 |
| 允许提现 | 状态正常且开启时,才能发起提现 |
| 价格最小变动单位 | 决定派彩拆分真金和彩金时的舍入位数 |
| 数量最小变动单位 | 只做记录,业务不读取 |
| 默认币种 | 全平台只有一个,当前只影响币种列表排序 |

### 新增与编辑

保存后立即生效。已有币种的全部表单字段都可以修改,包括货币代码。

保存时勾选“设为默认”,其他币种自动取消默认。

### 设为默认

列表操作需要确认,确认后该币种成为默认,其他币种变为非默认。已是默认的币种不显示该操作。

### 删除

删除需要确认。币种已被钱包、Crypto 资产等业务数据引用时不能删除。

### 汇率同步

| 币种 | 同步方式 |
|---|---|
| USDT 及法币 | 系统每分钟从 CoinGecko 同步 |
| 其他加密货币 | 系统按 Binance 的 USDT 交易对价格乘以 USDT 汇率折算,每 10 秒写入一次,另有备用通道每分钟补取 |

汇率不能手工修改。资金换算只使用 2 分钟内的汇率,超过后按汇率不可用处理,不按 1:1 猜测。

系统启动时会用 Binance 交易规则覆盖加密货币(USDT、USD 除外)的两个最小变动单位,手工修改值不保留。

## 4. 特殊情况

| 情况 | 如何处理 |
|---|---|
| 名称已存在 | 提示“该货币名称已存在，请使用其他名称”,不保存 |
| 货币代码已存在 | 提示“该货币代码已存在，请使用其他代码”,不保存 |
| 货币代码格式不对 | 提示对应格式要求,法币和加密货币分别校验,不保存 |
| 最小变动单位小于等于 0 | 提示“价格最小变动单位须为大于 0 的有效数字”或数量对应提示,不保存 |
| 删除被引用的币种 | 提示“操作失败，请检查输入或稍后重试”,记录保留 |
| 删除默认币种或禁用默认币种 | 允许。删除后平台没有默认币种,列表排序回到按创建时间 |
| 汇率尚未同步或来源中断 | 列表显示“不可用”或保留最后值;依赖换算的业务按汇率不可用处理 |
| 编辑的币种已被删除 | 提示“货币不存在，请刷新后重试” |

## 5. 验收场景

| 需求编号 | 场景与操作 | 预期结果 |
|---|---|---|
| 5.16-R1 | 新增加密货币,代码填 `usdc` | 保存后货币代码为 `USDC`,列表显示该币种,汇率同步前显示“不可用” |
| 5.16-R2 | 新增法币,代码填 `USDT` | 提示法币代码须为 3 位英文字母,不保存 |
| 5.16-R3 | 新增币种,名称与已有币种只差大小写或首尾空格 | 提示“该货币名称已存在，请使用其他名称”,不保存 |
| 5.16-R3 | 新增币种,货币代码已存在 | 提示“该货币代码已存在，请使用其他代码”,不保存 |
| 5.16-R4 | 关闭某币种的允许充值 | 该币种不再出现在 Crypto 入金选项和充值商品中 |
| 5.16-R5 | 关闭某币种的允许提现 | 该币种不能发起提现 |
| 5.16-R6 | 禁用某币种 | 充值、提现选项都不再出现该币种 |
| 5.16-R7 | 点击设为默认并确认 | 该币种变为默认并排到最前,原默认币种变为非默认 |
| 5.16-R7 | 新增或编辑时勾选设为默认 | 同样只保留这一个默认币种 |
| 5.16-R8 | 删除被钱包引用的币种 | 提示操作失败,记录保留 |
| 5.16-R8 | 删除未被引用的币种并确认 | 提示货币已删除,列表不再显示 |
| 5.16-R9 | 查看编辑表单 | 没有汇率字段 |
| 5.16-R9 | 汇率超过 2 分钟未更新时发生需要换算的业务 | 按汇率不可用处理,不使用旧值 |
| 5.16-R10 | 账号没有 `finance:currency:view` | 菜单不显示,直接访问进入无权限页 |
| 5.16-R10 | 账号有查看权限但没有 `finance:currency:delete`,提交删除 | 服务端拒绝,记录保留 |

## 6. 相关资料

- 入口与关联页面:财务管理 > 币种管理。链和合约配置见 [5.15 Crypto配置](../5.15-Crypto配置/README.md)。
- 权限:查看 `finance:currency:view`,新增 `finance:currency:create`,编辑 `finance:currency:edit`,删除 `finance:currency:delete`,设为默认 `finance:currency:set-default`。
- 数据与责任:币种主数据归 M5,汇率由系统同步。
- 共用规则:金额精度约定见 [00-公共约定](../../00-公共约定/README.md),标准计价见[标准计价](../../M2-用户管理/2.1-用户列表/标准计价.md)。
