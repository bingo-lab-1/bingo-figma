# 5.18 · 法币通道配置

## 1. 用途

维护法币支付提供商、入金收单及出金代付通道，查看各法币的配置覆盖。页面已实现配置保存与可用状态计算；支付网关和代付执行尚未接入，配置显示可用不等于玩家已经能实际收付款。

## 2. 配置项

| 对象 | 字段与约束 |
|---|---|
| 提供商 | 标识 2～32 位，以小写字母开头，后续为小写字母、数字、下划线或中划线；创建后不可改。名称 1～50 字符且唯一；凭据只填 Secrets Manager 引用名，3～256 字符，不收明文密钥；备注最多 200 字符；默认停用 |
| 通道归属 | 提供商、入金/出金方向、法币、支付方式，创建后不可改变；币种必须为法币 |
| 提供商通道码 | 1～64 字符，以字母或数字开头，后续允许字母、数字、下划线、点、冒号、中划线 |
| 金额范围 | 最小额和最大额均为正数，最多 12 位整数，小数位遵循币种精度，最大额不小于最小额 |
| 费用 | 百分比 0（含）～100（不含），最多 4 位小数；固定费非负、按币种精度且小于最小交易额；未填均为 0 |
| 排序与启用 | 排序为 0～9999 整数，默认 0；通道默认停用 |

## 3. 操作规则

提供商、通道和币种覆盖分别列示。创建、编辑通过表单保存，保存后重新读取结果；服务端校验外键、字段和唯一性并写操作日志。没有删除提供商或通道接口。

通道状态按优先级显示首要不可用原因：通道停用、提供商停用、币种停用、币种对应资金方向关闭；全部满足才显示可用。币种覆盖分别统计入金和出金的可用数/已配置数：币种停用或方向关闭时为关闭；方向开放但没有可用通道时为无通道；存在可用通道时为就绪。

## 4. 特殊情况

| 情况 | 处理 |
|---|---|
| 修改不可变归属或提供商标识 | 拒绝保存 |
| 提供商或币种不存在、币种是 Crypto | 拒绝保存 |
| 名称或唯一通道冲突 | 提示冲突，不能生成重复配置 |
| 固定费达到最小额、费用或精度越界 | 拒绝保存，不自动截断 |
| 提供商或币种关闭 | 原配置保留，派生可用状态同步变为不可用 |
| 查询失败或没有编辑权限 | 页面显示错误；保存由服务端权限校验拒绝，不视为已保存 |

## 5. 验收场景

| 需求编号 | 场景与操作 | 预期结果 |
|---|---|---|
| 5.18-R1 | 新建提供商及通道 | 默认停用，只记录密钥引用 |
| 5.18-R2 | 编辑已建通道的币种、方向、提供商或支付方式 | 服务端拒绝 |
| 5.18-R3 | 最小额、最大额、费用、排序处于边界或超界 | 合法值保存，非法值拒绝，精度不被悄悄截断 |
| 5.18-R4 | 依次关闭通道、提供商、币种、资金方向 | 显示对应首要原因，覆盖数量按同一规则重算 |
| 5.18-R5 | 只具查看权限提交修改 | 服务端拒绝；不同编辑权限分别约束提供商和通道 |
| 5.18-R6 | 所有配置显示就绪后尝试玩家法币支付 | 配置就绪不绕过尚未接入的支付能力，不能宣称已付款 |
