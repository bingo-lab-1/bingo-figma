# 5.5 · 充值商品配置

## 1. 背景与目标

**目标**:让运营自己配置玩家能买哪些充值档位、每档给多少钱、送多少彩金,改档位不用等版本。

**谁在用**

| 角色 | 用来做什么 | 没有会怎样 |
|---|---|---|
| 运营 | 调整档位与赠送力度,配合活动节奏 | 每次调价都要排开发,活动赶不上节点 |
| 财务 | 核对每个档位的实收与赠送成本 | 赠送成本算不清,活动预算失控 |
| 市场 | 设置热门标记与排序,引导玩家买高档位 | 只能按默认顺序展示,转化率上不去 |

**业务价值**:充值档位是收入的直接入口。配置化让运营能按天调整,同时把「送多少」这件
花钱的事收进有权限、有留痕的通道,而不是散落在各处硬编码里。

**不做什么**
- 不定义活动规则本身(绑定的活动由玩法侧维护,本页只做绑定关系)
- 不做支付方式与套餐的编排(那是 5.6 与通道管理的事)
- 不做价格的多币种换算(每个运营商各自配置,不跨币种折算)
- 不定义彩金入账后的打码规则(见第 3 段引用的资金模型)

**适用范围**

| 维度 | 取值 |
|---|---|
| 终端 | 桌面后台,最小宽度 1440 |
| 响应式 | 否 |
| 界面语言 | 简体中文 |
| 时区 | 运营时区,页面顶部标注 |
| 货币 | 多币种共存,金额必须带币种标识 |

## 2. 入口

- 菜单:财务管理 → 充值管理 → 充值商品配置
- 跳入:5.6 充值套餐列表(查看套餐绑定了哪些商品)· 5.2 充值订单查询(按商品ID 反查配置)

## 3. 术语

> 资金类术语(真金、彩金、打码任务)统一定义在
> `../../M2-用户管理/2.1-用户列表/资金模型.md` 第 2 段;
> 商品、商品模板、套餐的定义见 `../README.md` 第 2 段。此处不重复。

| 术语 | 定义 |
|---|---|
| 面值 | 商品的名义金额,用于玩家端展示的「充值 X」 |
| 售价 | 玩家实际支付的金额。与面值可以不等(折扣档) |
| 获得的真金数量 | 玩家支付后进入真金轨的金额 |
| 复充赠送彩金 | 非首充时是否额外赠送彩金的开关 |
| 赠送真金 | 是否额外赠送真金的开关 |

**「彩金前端展示金额」跟随「彩金金额」。** 两个字段当前取同一个值:后端配置的彩金金额
就是玩家端看到的赠送彩金金额,不存在「实发 80、显示 100」的分离。
这与打码量展示的向上取整**是两回事** —— 那个是精度处理,这里是配置值。

## 4. 关键参数与假设

| 编号 | 参数 | 取值 | 依据 | 在哪配 |
|---|---|---|---|---|
| A1 | 金额字段留空时的默认值 | 0 | 已验证(界面提示原文「不输默认为0」) | 写死 |
| A2 | 售价与面值的关系 | 可不等,均须大于 0 | **未验证假设** | 写死 |
| A3 | 彩金入账的打码倍数 | 按绑定活动配置,**不在本页配** | 已定 | 玩法侧,**本仓库范围外** |
| A4 | 排序值的取值范围 | 正整数,越小越靠前 | **未验证假设** | 写死 |
| A5 | 商品下架后已有订单的处理 | 在途订单照常完成,新订单不可下单 | **未验证假设** | 写死 |

> A3 是本页与资金模型的接缝:本页决定**送多少彩金**(本金),玩法侧决定**要打几倍**(倍数)。
> 两者缺一,这笔彩金入账就建不出打码任务。

## 7. 需求详述

### 5.5-R2

**触发条件**:点击新增商品 · 点击某行的编辑 · 在弹窗内提交。

**可输入数据**:见第 5 段新增与编辑表单字段。金额精度按币种(法币 2 位、加密 8 位)。

**功能范围**

| 归属 | 做什么 |
|---|---|
| 界面 | 必填校验、金额格式提示、开关联动(未开启复充赠送彩金时彩金金额不生效) |
| 服务端 | 权限判定、字段校验、保存、留痕;保证改动不回溯影响历史数据 |

**处理逻辑**

1. 判权限;无权限不展示新增与编辑入口,服务端二次判定
2. 校验必填与数值合法性:面值、售价、真金数量、彩金金额均不得为负
3. 彩金前端展示金额须与彩金金额一致(当前口径),不一致则拒绝并提示
4. 保存后**立即对新订单生效**
5. **不回溯**:已生成的充值订单、已入账的金额、已创建的打码任务**一律不受影响** ——
   改配置只影响未来,不改写过去
6. 记录操作人、操作时间与改动前后值

**错误处理**

| 错误状况 | 提示 |
|---|---|
| 无配置权限 | 提示无权限 |
| 必填项未填 | 定位到具体字段并提示 |
| 金额为负 | 金额不能为负 |
| 售价为 0 但商品处于上架状态 | 上架商品的售价必须大于 0 |
| 彩金展示金额与实际彩金金额不一致 | 两者当前必须一致,请修改后重试 |
| 绑定了已下线的活动 | 该活动已下线,请重新选择 |
| 并发编辑 | 提示该商品已被他人修改,请刷新后重试,不静默覆盖 |

**测试案例**

- 正向:新增一档售价 30、真金 30、彩金 10 的商品并上架 → 玩家端可见,下单后真金轨入 30、
  彩金轨入 10,彩金按绑定活动的倍数建打码任务
- 正向:把某商品的彩金金额从 10 改成 20 → **已完成的历史订单与已建任务不变**,新订单按 20 生效
- 逆向:彩金金额填 10、展示金额填 20 → 拒绝(当前两值须一致)
- 逆向:金额填负数 → 拒绝;必填项留空 → 拒绝;绑定已下线活动 → 拒绝
- 逆向:两人同时编辑同一商品 → 后提交者被提示刷新,不静默覆盖前者

### 5.5-R4

**触发条件**:点击某行的删除并通过二次确认。

**可输入数据**:被删除的商品(单条)。

**功能范围**

| 归属 | 做什么 |
|---|---|
| 界面 | 二次确认,确认前显示该商品是否被套餐引用 |
| 服务端 | 引用检查、在途订单检查、删除与留痕 |

**处理逻辑**

1. 判权限
2. 检查该商品是否被任何套餐引用;被引用则拒绝
3. 检查是否存在未终态的在途订单;存在则拒绝
4. 通过检查后删除并留痕;**已完成的历史订单保留对该商品的引用信息**,不因删除而丢失溯源

**错误处理**

| 错误状况 | 提示 |
|---|---|
| 无配置权限 | 提示无权限 |
| 被套餐引用 | 该商品正被套餐 X 使用,请先解除绑定 |
| 存在在途订单 | 该商品还有未完成订单,暂不可删除 |
| 重复提交删除 | 只生效一次 |

**测试案例**

- 正向:删除一个无引用、无在途订单的商品 → 删除成功,历史订单仍能查到它的商品ID 与当时配置
- 逆向:删除被套餐引用的商品 → 拒绝并指出是哪个套餐
- 逆向:删除有在途订单的商品 → 拒绝
- 逆向:连点两次删除 → 只生效一次

## 8. 数据流向与系统串接

**数据流向**:运营在弹窗中填写配置 → 服务端校验并保存商品与模板 →
玩家端下单时按当前配置计算实付、获得真金与赠送彩金 →
成交后由充值订单完成入账并按绑定活动的倍数创建打码任务 → 结果呈现在 5.2 充值订单查询。

**系统串接**:**与玩法侧有接缝,无第三方直连**。绑定活动的类型与彩金倍数由玩法侧维护
(**本仓库范围外**),本页只做绑定关系与本金金额。责任边界:
**本页决定送多少(本金),玩法侧决定要打几倍(倍数)**;倍数缺失时该笔彩金入账整笔拒绝,
不得退化成 0 倍放行,这一约束由入账侧执行,本页不兜底。

## 9. 异常与边界

| # | 场景 | 触发条件 | 预期处理 |
|---|---|---|---|
| E1 | 越权配置 | 无配置权限的账号提交新增或编辑 | 拒绝并提示;界面不展示入口,服务端二次判定 |
| E2 | 并发编辑覆盖 | 两人同时编辑同一商品 | 后提交者被拒绝并提示刷新,不静默覆盖 |
| E3 | 改配置影响历史 | 修改彩金金额后回看旧订单 | 历史订单与已建打码任务**一律不受影响**,改动只对新订单生效 |
| E4 | 删除仍被引用的商品 | 商品被套餐引用或有在途订单 | 拒绝删除并指出引用方 |
| E5 | 展示金额与实际不一致 | 彩金前端展示金额被单独调高 | 当前口径两值须一致,不一致拒绝保存;若历史数据已不一致,**以后端配置值入账**并告警 |
| E6 | 绑定已下线活动 | 活动下线后商品仍绑着它 | 下单时该笔彩金无倍数可用,按倍数缺失**整笔拒绝入账**并告警,不静默按 0 倍发放 |
| E7 | 下架商品仍被下单 | 玩家端缓存了已下架的档位 | 下单时二次校验上架状态,已下架则拒绝,不按打开页面时的状态放行 |

## 10. 状态清单

| 状态 | 表现 |
|---|---|
| 错误 | 弹窗内字段级提示,弹窗不关闭,已填内容保留 |

## 11. 涉及表与职责

**数据归属**

- 拥有(owner=M5):充值商品 · 商品模板
- 只读:活动类型与彩金倍数(owner=玩法,**本仓库范围外**)· 币种与精度配置
  (owner=系统设置,**本仓库范围外**)

**前后端职责**

| 事项 | 归属 |
|---|---|
| 权限判定 | **服务端**,按角色的权限节点判定 |
| 可见范围过滤 | **服务端**,按账号绑定的推广商过滤,列表、汇总与导出一律先过滤再返回(见 `../README.md` 第 6 段) |
| 字段校验、引用检查、并发控制 | **服务端** |
| 配置改动不回溯影响历史数据 | **服务端** |
| 表单交互、开关联动、即时格式提示 | 界面 |
| 二次确认与操作留痕 | 界面 + 服务端双重校验 |
