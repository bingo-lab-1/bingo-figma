# 未落地需求

模块和玩家端正文描述系统当前行为。已写成规则、但代码尚未实现的需求集中放在这里,避免把目标写成现状。某项需求实现后,把规则移回所属页面,并从本清单删除对应行。

本清单只收录与当前实现不同的历史产品候选，不表示已排期或必须恢复旧设计。编号沿用原页面的 A、R、E 编号，原提案可在 Git 历史查看。当前行为以各模块正文和[代码核对基线](../00-公共约定/代码核对基线.md)为准；保存完整配置、注册奖自动发放等已明确采用的行为不再当作待补缺口。
