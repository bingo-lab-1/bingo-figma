# 3.3 · 提现审核规则

## 1. 用途
配置提现的自动过审 / 转人工 / 自动拒绝规则。**决定人工审核工作量与资损风险的平衡点。**

## 2. 入口
菜单:财务管理 → 提现 → 审核规则 · 跳入:提现订单详情「命中规则」

## 3. 字段清单
**规则字段**:规则名称* · 优先级(数字,小者先匹配)· 启用开关 · 条件(JSON)· 动作
**条件可选项**:金额区间 · 币种 · VIP 等级 · 是否首提 · 打码是否达标 · 用户标签 · 渠道 · 当日提现次数 · 注册天数 · 累计充提差额
**动作**:`autoPass` 自动过审 / `toManual` 转人工 / `autoReject` 自动拒绝
**表格列**:`优先级 | 规则名 | 条件摘要 | 动作 | 启用 | 更新时间 | 操作`

## 4. 需求清单

| ID | 需求 | 验收标准 | 权限码 | 人日 |
|---|---|---|---|---|
| 3.3-R1 | 规则列表 | 按 priority 升序展示;显示条件摘要与动作 | `finance:withdraw:view` | 0.5 |
| 3.3-R2 | 条件构建器 | 支持金额/币种/VIP/首提/打码/标签/渠道/次数/注册天数组合 | `finance:rule:edit` | 3 |
| 3.3-R3 | 规则 CRUD | 新增/编辑/删除;名称唯一;写 操作日志 | `finance:rule:edit` | 1 |
| 3.3-R4 | 优先级调整 | 拖拽排序即时保存;优先级唯一 | `finance:rule:edit` | 1 |
| 3.3-R5 | 启用/停用 | 二次确认;停用后不参与匹配 | `finance:rule:edit` | 0.5 |
| 3.3-R6 | 匹配引擎 | 按 priority 升序命中即止;无命中默认 `toManual` | — | 1 |
| 3.3-R7 | 规则测试器 | 输入订单参数试跑,返回命中规则与动作,不产生真实数据 | `finance:rule:edit` | 1 |

## 5. 状态清单
空(无规则=全部转人工)/ 加载 / 错误 / 无权限 / 编辑中 / 规则冲突提示

## 6. 交互流程
规则按 `priority` 升序匹配,**命中即止**。无规则命中 → 默认 `toManual`(安全兜底)。

## 7. 涉及表
提现审核规则(owner)· 提现订单

## 8. 关联页面
跳出:提现订单(3.2)· 提现配置(3.4)
