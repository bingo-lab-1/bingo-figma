# 1.1 · 大盘概览

## 1. 用途
一屏看清平台经营健康度。**后台的默认落地页。**

## 2. 入口
菜单:数据中心 → 大盘概览(登录后默认页)

## 3. 字段清单

**筛选**:渠道(多选)· 币种 · 时间范围(今日/昨日/本周/本月/自定义)

**核心指标卡(12)**
| 指标 | 公式 | 环比 |
|---|---|---|
| 注册人数 | count(新注册) | ✅ |
| 首充人数 FTD | count(首次充值) | ✅ |
| 充值金额 | sum(paid 订单) | ✅ |
| 充值人数 | distinct(充值用户) | ✅ |
| 提现金额 | sum(completed 提现) | ✅ |
| 提现人数 | distinct | ✅ |
| 投注金额 | sum(bet) | ✅ |
| 派彩金额 | sum(payout) | ✅ |
| **GGR** | 投注 − 派彩 | ✅ |
| **NGR** | GGR − 彩金成本 − 返佣 | ✅ |
| 彩金成本 | sum(活动发放) | ✅ |
| 活跃人数 | distinct(登录或投注) | ✅ |

> ⚠️ 所有指标的**口径与时区必须先统一**(见 `01-模块总览.md` 决策清单 #4),否则各处对不上。

## 4. 需求清单

| ID | 需求 | 验收标准 | 权限码 | 人日 |
|---|---|---|---|---|
| 1.1-R1 | 筛选区(渠道/币种/时间范围) | 切换任一条件,全部指标卡与图表同步刷新;重置恢复默认 | `analytics:overview:view` | 1 |
| 1.1-R2 | 12 个核心指标卡 | 每卡显示数值+环比;口径与 `01-模块总览` 决策清单 #4 一致 | 同上 | 3 |
| 1.1-R3 | 分时趋势图 | 可切换指标;X 轴按运营时区切分 | 同上 | 1.5 |
| 1.1-R4 | 分布图(渠道/游戏占比) | 占比合计 100%;点击图例可隐藏 | 同上 | 1 |
| 1.1-R5 | 指标卡下钻 | 点击卡片跳对应明细页并带上当前筛选条件 | 继承目标页权限 | 1 |
| 1.1-R6 | 数据延迟提示 | 顶部显示「数据截至 HH:mm」;单卡失败不影响其他卡 | 同上 | 0.5 |

## 5. 状态清单
| 状态 | 表现 |
|---|---|
| 空 | 「所选条件无数据」 |
| 加载 | 指标卡骨架屏 |
| 错误 | 卡片级错误 + 重试(单卡失败不影响其他) |
| 无权限 | 菜单不可见 |
| 数据延迟 | 顶部提示「数据截至 HH:mm」 |

## 6. 交互流程
点击指标卡 → 下钻到对应明细页(充值→M3.1,提现→M3.2,投注→M2.3)。

## 7. 涉及表
`DailySummary` `ChannelDailySummary` `DashboardTimeSummary`(owner)
**只读**:不直连 `Transaction`/`BetRecords` → `../表设计.prisma`
