# 1.7 · 活动 ROI 日报

> P1 页面,当前为精简规格。排期时按 10 段模板补全。

## 1. 用途
每个活动的**发放成本 vs 带来存款**。**决定哪些活动该砍、哪些该加码。**

## 2. 入口
菜单:数据中心 → 活动 ROI · 跳入:活动配置「效果数据」

## 3. 字段清单(草案)
**表格列**:`日期 | 活动编码 | 活动名称 | 分类 | 领取人数 | 领取笔数 | **发放成本** | 参与用户当日充值 | **ROI** | 打码完成率 | 彩金转真金率`

> **打码完成率**是关键指标 —— 完成率过低说明打码倍数过高(用户放弃),过高说明倍数过低(在漏钱)。

## 4. 操作与权限
`analytics:report:view` 查看 · `analytics:export` 导出

## 5. 状态清单
空 / 加载 / 错误 / 无权限 / 活动已下线(仍显示历史)

## 6. 涉及表
`ActivityRoiDaily`(只读)· 数据源 `ActivityClaim`(M4)→ `../表设计.prisma`

## 7. 关联页面
活动引擎(M4.1)· 活动领取记录(M4.3)· 打码核销(M3.7)
