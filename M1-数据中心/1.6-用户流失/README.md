# 1.6 · 用户流失

> P1 页面,当前为精简规格。排期时按 10 段模板补全。

## 1. 用途
识别流失与高流失风险用户,供召回活动圈人。

## 2. 入口
菜单:数据中心 → 玩家分析 → 用户流失(**「玩家分析」是分组**)

## 3. 字段清单(草案)
**筛选**:流失天数区间 · 渠道 · VIP 等级 · 累计充值区间 · 是否首充
**表格列**:`用户ID | 昵称 | 渠道 | VIP | 累计充值 | 累计提现 | 最后登录 | 最后投注 | 流失天数 | 标签`

**流失定义**( 待定):N 天未登录?还是 N 天未投注?N 取多少?

## 4. 操作与权限
`analytics:report:view` 查看 · `analytics:export` 导出(用于召回活动)

## 5. 状态清单
空 / 加载 / 错误 / 无权限 / 导出量超限提示

## 6. 涉及表
只读 用户 登录记录(M2)· 每日汇总

## 7. 关联页面
用户留存(1.5)· 用户列表(M2.1)· 用户标签(M2.5,导出后打标召回)
