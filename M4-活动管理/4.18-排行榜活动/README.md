# 4.18 · 排行榜活动

## 1. 活动介绍

玩家在指定游戏范围内的原始下注金额,按投注最终结算时间计入日榜和周榜。每期奖池由固定基础彩金和全平台合格投注的一定比例组成,达到最低投注门槛的真实玩家按排名分享奖励,在下一日或下一周开放后手动领取彩金。

**本文覆盖真实玩家排名和派奖。** 合成账号、虚构投注和模拟名次不得进入正式榜单、奖池或获奖名单;测试预览与正式活动隔离。本版不包含以隐藏身份的机器人占用真实获奖名额和奖金的设计。

| 项目 | 本版范围 |
|---|---|
| 榜单 | 仅日榜、周榜;独立开关、配置、奖池和结算。同一玩家可以同时获奖,同一笔合格投注可同时计入两个榜单 |
| 参与人群 | 本运营商所有真实玩家,排除测试账号;无需报名,不设置参与标签、渠道或VIP等级门槛 |
| 获奖范围 | 固定前50名,运营不可调整;还须满足最低上榜投注金额。实际人数不足时保留空缺 |
| 排名金额 | 原始下注金额,按现有USD标准计价统一汇总;不乘游戏有效投注折算比例,不按净输赢排名 |
| 时间 | 复用平台业务时区,不是查看者浏览器时区。日榜为每日00:00至次日00:00;周榜为周一00:00至下周一00:00 |
| 奖励 | 使用平台统一的真实奖励币种,每笔奖励手动领取后入彩金并建立独立打码任务;不根据玩家投注币种切换奖励币种 |
| 数据与入口 | M4拥有活动规则、期间、排名快照及领取记录;M2的2.7玩家排行榜仍是独立运营查询页,不承担本活动派奖 |

后台使用简体中文,最小宽度1280px。配置、实时榜单、历史结算和领取记录均放在本活动内部。玩家展示需明确业务时区、USD排名单位、实际奖励币种、排除游戏、最低门槛、分奖规则和领取期限。

## 2. 运营配置

### 配置字段

每运营商一套活动,日榜和周榜分别配置A5～A11;A1、A3、A4共用。固定50名属于产品规则,页面与服务端均不可改为其他数量。

| 编号 | 配置项 | 填写与执行规则 |
|---|---|---|
| A1 | 活动名称、说明 | 名称1～40字符,必填;说明最多2000字符。文案不得覆盖服务端规则或承诺未分配的奖励 |
| A2 | 日榜、周榜开关 | 分别开启或关闭,默认关闭;可以只开一种。不开设月榜,不提供其他自定义周期 |
| A3 | 业务时区、奖励币种C | 只读展示平台业务时区及统一奖励币种;C必须是资金域支持发放彩金的真实币种。缺少任一项时不能发布,不默认采用浏览器时区或USD钱包 |
| A4 | 排除厂商、游戏 | 默认不排除;从受控厂商和游戏目录多选。命中任一排除项的投注不参与排名和奖池;排除厂商同时排除其全部游戏。不提供独立活动游戏字典 |
| A5 | 最低上榜投注金额S | 非负USD金额,最多8位小数,默认0;S=0仍要求该玩家本期有正投注额。门槛只影响获奖资格,不缩小全平台奖池的投注基数 |
| A6 | 每期基础彩金B | 非负金额,按C的资金精度填写,必填无默认;每个日榜期、周榜期分别加入一次,不是首次活动一次性加入 |
| A7 | 投注转入奖池比例p | 0～100%,最多4位小数,必填无默认;B与p不能同时为0。原表1%仅为示例,不是固定值 |
| A8 | 获奖名次和奖励区间 | 名次固定1～50。允许配置连续整数区间,须完整覆盖1～50且无重叠、无空档;每区间的奖池比例为正数,最多4位小数,全部合计100%。区间内按配置名额数平均分配 |
| A9 | 彩金打码倍数Y | 正数,最多2位小数,必填无默认;领取金额W形成W×Y的独立打码任务,不得复用充值本金的打码配置 |
| A10 | 开放领取时间 | HH:mm,必填。日榜为该期结束当天的指定时刻,即投注日的次日;周榜为该期结束的下周一指定时刻。时间以A3为准,不是自动入账时间 |
| A11 | 领取有效期 | 必选“限时领取”或“不过期”,不默认替运营选择。限时填写1～365整数天,从实际开放领取起连续N×24小时;不过期不设置截止时刻 |

金额、倍数和乘积须满足资金支持范围,不静默截断运营输入。发布预览展示两榜完整配置、首个生效期间及一组分奖示例;显示“区间总比例”和“每个名次比例”,防止将区间10%误认为每人10%。

### 保存、发布和生效

草稿可不完整,非法已填值不能保存;发布须完整校验。保存、发布和启停记录操作者、时间及前后版本,并发编辑不得覆盖他人的更新。发布与开启为不同操作。

|---|---|
| 首次开启或重新开启 | 从下一个完整日榜/周榜期间开始接纳投注,显示准确开始时刻;不补计开启之前的半个期间 |

期间采用业务时区的自然日/自然周边界,不是固定24/168小时计时;夏令时切换时仍以当地00:00为界,不得重复或遗漏投注。时区采用平台已有的可识别区域时区值,不能只保存含糊的“美国时间”。

## 3. 参与和领奖规则

### A12 · 投注范围与期间归属

活动只采纳本运营商真实玩家在非排除游戏中、已最终结算且未作废的正原始下注金额。真钱和彩金支持的真实下注均按原始下注额计算;零金额免费局不凭空产生投注金额。派彩、净赢和游戏折算比例不改变排名金额;其他活动、打码及佣金仍使用各自有效投注规则。

测试账号的投注不进入排名或奖池。保存下注时和结算时的测试标记依据,任一时点为测试即排除;改回正常账号不补计这些历史投注。缺少可靠身份事实时进入核查,不能默认当作正常玩家。普通封禁不直接抹除已发生的真实投注,领奖时按账户及资金限制处理。

每笔投注按稳定业务标识在每个榜单的同一期间只计算一次;多次派彩、重复回调和重试不能重复累计。完整取消或作废不计入,部分取消只保留实际未取消的原始下注额。最终结算时间由投注域提供,不使用回调到达时间代替。

期间为[start,end):结算时刻恰好等于end的投注属于下一期。跨日下注、次日结算的投注归次日日榜;周日下注、周一结算的投注归新周周榜。尚未最终结算的投注等待其最终结算后归期,不是要求所有未结投注完成才能结束上一期。

日榜、周榜独立判断开启状态、期间及门槛;同一笔投注可以为两个榜单分别增加一次金额,不拆半、不择一。下注原币种、原金额、取消修正和来源事实均留存,活动不新增玩家扣款。

### A13 · 统一排名与并列规则

各笔投注使用资金域已保存的USD标准金额,保留8位小数汇总,排序不使用页面四舍五入后的显示值。汇率时点沿用原始账变入账时间,归期使用最终结算时间,二者分别保存;不得因本活动按结算时间归期而按结算日汇率重算旧投注。

合计投注额>0且≥S的真实玩家按金额从高到低排序,前50名产生获奖资格。金额相同时,先达到该最终累计金额的玩家排前:按组成该累计额的有效投注中最后一笔最终结算时间比较;时刻仍相同则按稳定用户ID升序。迟到通知按原业务时刻重算,不得以接口先后到达决定胜负。

取消修正后按剩余有效事实重新计算金额和达到时刻。最低门槛未达到的玩家不占获奖名次,页面展示其个人投注额及未达标提示;合格但超过50名的玩家显示个人实际名次及无本期奖励。

### A14 · 奖池与分奖

令Q为本期所有符合A12的投注USD标准金额合计,包含尚未达到个人门槛S的真实玩家投注。日榜和周榜各自汇总Q,不可将日榜的奖金或剩余奖池转入周榜。

奖池以实际奖励币种C计价。C=USD时汇率为1;C不是USD时,取资金域提供的本期结束时汇率h,其含义为“1单位C对应多少USD”,保留汇率来源、时点和数值。该汇率仅用于把奖池预算折算成实际奖励币种,不重算A13的历史投注标准金额,也不把统计USD直接记入钱包。

- 最终奖池P = 按C精度向下取整(B + Q × p / 100 ÷ h)。
- 区间名额数n = 结束名次 − 开始名次 + 1。
- 该区间每个名次奖励W = 按C精度向下取整(P × 区间比例 / 100 ÷ n)。

分母固定为配置名额数,不因实际获奖人数不足临时放大每人金额。空缺名次的份额、精度尾差及过期未领取金额不发放、不向其他玩家重分配、不滚入下一期。页面须公开这一规则,区分“可分配奖池”与“实际发放奖金”;不得承诺奖池必定全额派完。

例如C=USD、B=100、Q=90000、p=1%,则P=1000 USD。第11～20名共10个名额配置10%,每名应得10 USD;若仅第11～13名有合格玩家,该区间只形成30 USD奖励,剩余70 USD不分配。这个例子不作为默认参数。

期间内的奖池及个人奖励标为“预估”,展示数据更新时间;非USD奖池可使用当前可用报价估算,最终结果仍以本期结束汇率和结算快照为准。汇率未知不显示为0或静默换用现价。向下取整后为0的名次保留结果,不创建零金额领奖申请或任务。

### A15 · 结算和开放领取

期间结束后进入“结算中”。投注域提供该时间范围事实齐备的依据,资金域提供所需标准金额和汇率;来源不完整不能把缺失当0直接定榜。依据齐备后锁定期间、规则版本、排名、奖池、每名奖励、币种、汇率、Y及领取安排,形成可核对的结算快照。

实际开放时刻取“配置开放时刻”和“结算完成时刻”的较晚者。发生结算延迟时,限时领取从实际开放起算,不消耗玩家尚不能操作的期限。期间状态与奖励状态分别保存:

| 对象 | 状态及含义 |
|---|---|
| 期间 | 未开始、进行中、结算中、已结算;数据异常显示原因和核查状态,不冒充已结算 |
| 个人奖励 | 待开放、可领取、领取处理中、已领取、已过期;处理中保留具体资金结果或未知原因 |

玩家可同时持有日榜、周榜及多个历史期间的奖励。每笔单独展示金额、币种、打码倍数和准确截止时刻或“不过期”,按各自依据领取,不拼成使用最新配置的一笔奖励。

### A16 · 手动领取与资金

玩家点击领取时,服务端校验归属、结算快照、开放状态、期限、账户限制和原资金结果,受理唯一申请。限时奖励要求受理时刻早于截止时刻,到达截止即不接受新申请。未点击领取不自动入账、不建立打码任务,奖金不记为充值。

资金域按锁定的C、W和Y完成彩金入账、账变及W×Y独立打码任务,结果一致后才记为已领取。既有本金或彩金任务继续保留;活动不直接修改钱包,不在领取时用当前汇率或当前配置重算金额。资金仅消费已确定的奖励及来源,不反向查询排名或活动规则。

同一运营商、榜单类型、期间和玩家只能对应一份奖励。重复点击、跨设备及更换请求编号均返回原申请或结果,不能再次入账。资金结果未知保留处理中,查询并恢复原申请;已在有效期内受理的申请在截止或活动关闭后仍按原依据完成。

### 玩家展示与后台记录

玩家可切换日榜和周榜,查看本期起止、时区、奖池、前50名、个人投注及名次、奖励规则和历史领取入口。未满50名时只展示真实合格人数及空缺说明,不补造账号或投注。其他玩家的用户ID至少遮挡一半字符,短ID也不得完整暴露;遮挡不用于暗示虚假参与者是真人。

实时数据齐备后5分钟内更新并标注时间;结算中的排名和奖金继续标为非最终结果。已结算榜展示冻结结果。不能将未领取奖金展示为钱包余额,领奖按钮不能称为“提现”。

## 4. 特殊情况

| 编号 | 情况 | 处理 |
|---|---|---|
| E1 | 测试账号、排除游戏、无投注或未达到S | 测试和排除游戏不贡献排名及奖池;真实合格投注低于S仍贡献奖池,但玩家不进入获奖名单。标签变化不影响本活动资格 |
| E2 | 原始标准金额、结算事实或结束时汇率缺失 | 显示核查/结算中,补齐后按原业务期间和原规则恢复;不使用0、通知时间或随意现价代替,不提前生成错误奖金 |
| E3 | 数据迟到、撤单、部分退款 | 定榜前按原业务归属重新计算。定榜后进入受控核查并暂停受影响的尚未受理领取,保留原快照和修正版本;不得静默修改已公布结果。已受理或已到账奖励按资金纠错流程逐笔核对,不自动扣回余额、清除任务或换号补发 |
| E4 | 名次不足、精度尾差或奖金取整为0 | 空缺保留,未分配及尾差不滚存;0金额不发奖。全部无人符合时记录空榜,基础彩金仍作为该期预算留痕,实际发放为0 |
| E5 | 限时奖励到期 | 未受理的奖励失效;已受理继续查证并履约。活动期限不使已入账彩金或已建任务自动失效;不过期奖励不运行到期失效逻辑 |
| E6 | 系统故障阻塞领取 | 记录受影响奖励及实际阻塞区间,限时奖励截止顺延这些区间的并集时长,重复故障记录不重复顺延;已经受理的申请沿原申请恢复。个人离线、忘记领取或账户风险限制不按技术故障顺延 |
| E7 | 关闭活动、切换配置或币种不可用 | 已开始期间及历史奖励沿原依据履约;币种不可用时记录资金异常,不静默改币种或倍数。已发布版本不能覆盖历史快照 |
| E8 | 伪造排名、越权领奖或重复请求 | 正式排名只接纳可追溯真实投注;服务端拒绝人工改分、模拟参与者进入正式榜及他人领奖,重复本人请求返回原结果并留痕 |
