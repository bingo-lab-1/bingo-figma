# 4.8 · 注册送好礼

> 2026-09-15 修订：以 KAN-217、KAN-237–240 为准，注册获得资格，玩家手动领取后才入账并生成打码任务。替代旧稿的注册自动发放规则。

<a id="1-背景与目标"></a>

## 1. 活动介绍

运营配置固定注册奖励；新玩家完成平台注册要求后获得一份领取资格，领取成功后获得真实彩金和对应独立打码任务。
例如 10 USDT、20 倍：未领取余额和任务不变；领取成功到账 10 USDT，新增需完成 200 USDT 有效投注的任务。

### 本次范围

- 每运营商一套活动配置、草稿发布、启停、同页活动记录以及玩家手动领取入口。
- 固定正数奖励；不做随机抽奖、充值翻倍、受众/渠道/标签筛选或额外手机号、CPF 条件。
- 不提供后台代领、玩家取消任务或领取有效期。
- 复用平台投注模式、钱包账变、独立打码与提现规则，不建立新钱包。

<a id="5-字段清单"></a>

## 2. 运营配置

| 字段 | 填写与校验 |
|---|---|
| 活动名称（A1） | 发布时必填，1–40 字符；每运营商一套配置 |
| 奖励金额（A3） | 单个固定正数，符合奖励币种精度；遵循现有资金金额安全边界 |
| 奖励币种（A4） | 平台已开通币种；改变币种不会自动换算金额，发布前明确核对 |
| 打码倍数（A5） | 必填正数，最多两位小数；缺失不默认为零；金额乘倍数不得超出资金存储范围 |
| 平台投注模式（A6） | 只读；从平台基础设置读取，不保存在活动版本内 |
| 活动开关（A8） | 首次发布后仍需手动开启；关闭停止新资格，旧资格仍可领取 |

<a id="48-r1"></a>

### 4.8-R1 查看与保存草稿

允许不完整草稿，但已填写字段必须合法。保存不改变线上奖励。保存失败或版本冲突保留输入；以配置修订号防止并发覆盖。

<a id="48-r2"></a>

### 4.8-R2 核对与发布

预览活动名称、币种、固定金额、打码倍数和需完成有效投注额。确认时再次校验草稿修订号和币种状态。
发布形成不可变版本；开启期间的新版本只影响发布后注册的玩家。首次发布保持关闭。

<a id="48-r3"></a>

### 4.8-R3 开启与停用

开启前须有合法发布版本。启停和发布均记录原始生效时间，可追溯注册时规则。
关闭提示：“停止新增资格，已有资格仍可领取”。重开不重置参与次数，不补关闭期间注册的玩家。

## 3. 参与和领奖规则

### A2 注册资格与次数

每运营商每玩家终身一次。以可信注册成功事实和原注册时间判断资格，晚到或重复注册消息不得使用消息处理时的新规则。
活动开启前、关闭期间注册的用户不补资格。注册初始化未完成时可恢复核查，活动处理失败不撤销已成功注册。
按注册时版本锁定金额、币种、倍数；领取不要求先充值。登录、充值、访问活动页和后台定时任务均不能代领。

### A8 旧资格

没有到期时间。改版、停用或重开后仍按原金额、原币种和原倍数领取。
币种停用时保留资格并说明原因，恢复后继续原奖励，不自动换币或取消。

<a id="48-r4"></a>

### 4.8-R4 注册获得资格

可信注册成功 → 查询注册时启停及发布版本 → 幂等保存资格和奖励快照。
此阶段不增加余额、不创建打码任务，也不影响玩家原有提现资格。

<a id="48-r5"></a>

### 4.8-R5 玩家手动领取

1. 服务端只允许登录玩家领取本人资格；客户端不提交玩家 ID、奖励金额或倍数。
2. 领取前展示金额、币种和预计有效投注额，并明确告知暂不能自行取消任务；该币种全部余额（包括后续充值）的提现会受到未完成任务约束。
3. 检查当前账号、奖励币种和钱包状态；受限时保留资格并提示。
4. 记录玩家已提交领取后进入处理中。不同设备、不同请求编号及重复点击仍只使用同一资格和付款依据。
5. 彩金入账、独立打码任务及领取成功结果在同一事务提交；任一失败全部回滚。
6. 成功后查询原结果和原任务进度；不重新发钱、不重建或重置任务。

### A9 失败与恢复

资金结果未知先查询原依据，仅恢复玩家已经提交的领取。未领取资格绝不自动付款。
处理中不显示已到账；币种或钱包暂不可用时保留原申请。历史缺少手动领取凭据的处理中记录进入核查，不能直接自动付款。

### A6/A7 平台投注与资金规则

- 两种投注模式及成功充值认定以[资金模型](../../M2-用户管理/2.1-用户列表/资金模型.md#平台充值前投注资格)为准。
- 默认充值投注限制：未充值也能领取，但须成功充值后才能投注。
- 无限制投注：无需先充值，可使用已到账彩金，仍须通过余额、封禁和游戏状态检查。
- 每次新投注读取当前平台模式；未知模式或必要事实不可用时拒绝新投注，已受理投注继续结算和退款。
- 真实充值按原币净额判断，人工加款不算；退款/拒付后全部归零则恢复充值限制。
- 未领取前已经结算的投注不能抵扣新任务；不保存多余流水供未来任务使用。
- 每笔奖励独立任务，核销遵循原币 FIFO；奖励输完或活动关闭不清任务，玩家不能自行取消。
- 任意 active 任务阻止该币种整个钱包提现；其他币种独立判断。

## 4. 特殊情况

| 情况 | 处理 |
|---|---|
| 无资格 | 说明没有可领取注册奖励，不显示可领取按钮 |
| 待领取 | 显示奖励和预计打码额，不显示为余额或实际任务 |
| 处理中 | 显示原领取处理状态，刷新或换设备仍查询同一结果 |
| 已领取 | 显示实际到账结果和剩余打码量，不提供取消或再次领取 |
| 重复、并发领取 | 只有一份领取、一笔账变和一条任务 |
| 账号受限 | 拒绝新领取，保留原资格；资金处理前再次校验 |
| 配置并发修改 | 拒绝覆盖，保留输入，要求刷新核对 |
| 跨用户/运营商 | 服务端拒绝越权，不信任客户端传入归属 |
| 币种停用 | 保留原币种、金额、倍数；恢复后继续 |
| 旧自动发放记录 | 已到账不重复奖励；缺少手动凭据的处理中记录须核查 |
