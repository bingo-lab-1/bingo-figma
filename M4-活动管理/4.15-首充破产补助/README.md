# 4.15 · 首充破产补助

## 1. 活动介绍

符合活动人群的玩家完成首次真实充值后,游戏净亏损达到首充金额的设定比例,获得一个补助宝箱。玩家可以按配置直接领取基础彩金,或从宝箱入口再次充值后手动领取翻倍彩金。每个运营商内每个账号最多获得一个宝箱、成功领取一次。

活动帮助运营配置首充后的亏损补助,客服可以查明首充、亏损、宝箱、关联充值和最终发奖依据。“破产”指达到活动亏损门槛,不要求钱包余额为零。

### 范围

- 提供不翻倍、固定充值翻倍、随机充值翻倍三种模式,一次只能启用一种。基础奖金支持比例区间,上下限相等为固定比例。
- 用户标签控制参与人群,渠道定向通过标签表达。本活动独立于 M5 的限次充值赠送,不把“第1次比例奖励”视为真实首充。
- 普通领取与翻倍领取二选一;开箱、达到亏损条件或充值成功都不代替玩家手动领取宝箱彩金。
- 后台配置、活动内部记录与玩家领取规则一并交付。单钱包、账变、打码和提现约束复用资金模型。
- 不提供每日重置、反复补助、已领基础奖后充值补差或玩家取消已入账奖励的入口。

后台采用桌面运营页面,最低宽度1280px,界面为简体中文,玩家提示按运营语言展示。时间保存统一时间点,界面注明运营时区。参与币种由运营选择,每份参与记录的亏损与关联充值使用原首充币种；新宝箱的普通和翻倍彩金发入 USD 钱包。原有宝箱沿用自身保存的奖励币种和金额，不改写历史。

### 保存与启停

配置必须完整且合法才能保存。点击“保存”一次提交当前输入，服务端在同一事务中校验修订号、生成规则版本并记录操作日志；不完整或版本冲突时拒绝写入并保留页面输入。保存不自动启用活动，启停独立操作。没有独立的服务端草稿或第二次发布步骤；保存同时需要本活动的 edit 与 publish 权限，启停需要 switch 权限。

活动首次保存不自动开启。保存和启停保存后立即生效,不等下一业务日。首充成功时锁定当时已生效版本和参与依据;后续保存仅影响新参与。活动关闭期间完成首充的账号不建立参与记录,之后开启也不补。关闭停止新参与,已经进入观察、已经产生宝箱或已关联订单继续按原配置和期限履约。重新开启不清除历史参与与已领取结果。配置操作及启停记录操作人、时间和变更内容。

### 玩家可见信息

开箱前后应展示基础彩金、能否普通领取、翻倍所需充值金额、翻倍后的总彩金和两类彩金各自的打码要求。选择充值前展示该单本金X及该笔充值不再获得商品固定/比例赠送的说明。随机倍数在付款前展示已锁定的实际值,不能只展示可能的最大值。

首次出现宝箱时提示一次,用户关闭后保留活动入口和未领取标记;同一会话不反复强制弹窗。开箱或刷新不改变奖励。金额展示使用真实可领值,未领取金额不计入钱包余额。

### A15 · 真实首充与人群认定

M5 提供当前运营商的第一笔可计奖充值事实，来源含链上入金、支付订单和新链路勾选计入充值的人工加款。普通调整、历史人工补录、人工商品订单、赠金和失败订单不构成这里的首充。测试账号和后台账号与普通玩家同样参与(D111)。并发首笔顺序由财务提供,不能以消息到达顺序各算一次。

记首充有效实付金额为P、成功时间为T0。P不包含商品或其他活动彩金,也不以商品面值、通道扣费后的商户净收入替代。P须大于0且币种在活动范围内。

首充成功时活动已开启才建立一次参与记录;人群或币种不符合时记为“不符合首充条件”,之后不再参与。记录首充单、P、币种、T0、活动版本、标签条件及当时命中依据。基础奖金能否达到一个最小币种单位在生成宝箱时判断,见A17。指定标签按T0的有效规则和事实判断;数据迟到按原时点恢复,无法可靠判断时记录核查原因,不按后续标签状态随意补资格。

标签后来摘除、正常配置修改不撤销已取得的参与权;账户封禁、资金限制仍在实际操作时校验。首充时不符合的用户不因后来换标签、换币种、再次充值或活动重启而取得另一份首充机会。后续充值不提高P,不重开观察期,也不因第二次充值自动终止原观察。

### A16 · 亏损计算与宝箱触发

观察期开始包含T0;限时模式结束为T0＋N小时且不包含结束时刻。不限模式持续观察到首次达标。只统计T0以后受理,且在观察期内最终结算的同币种投注。

**游戏净亏损L＝max(累计最终结算投注金额－这些投注的累计总派彩金额,0)。** 充值与彩金出资的游戏输赢均计入。总派彩包含游戏实际返还的本金部分,不能只取净利润;不按游戏有效投注折算系数加权。未结算、取消、作废不计,退款或冲正使用修正后的事实。提现、人工扣款、赠金和充值均不当作游戏盈亏。

系统定期核对以及玩家打开活动页、领取、建单时,按当时观察窗口内的累计结果计算L,L≥P×A5比例时触发一个宝箱;两次核对之间L短暂达标又回落的不触发。门槛计算保留高精度,不提前向下取整放宽条件。观察期结束仍未达标不再触发,记录保持“观察亏损中”并显示观察截止,不在下一次充值重新开始。迟到结算按原业务时间恢复,不能把截止后的新投注算入,也不能只读当前余额替代历史触发依据。

正常后续赢钱不撤销已经合法形成的宝箱;原结算撤单、首充退款等事实修正另按特殊情况处理。生成或恢复同一个宝箱不增加参与次数。宝箱首次可展示时间独立记录,领取期限从该时间开始,刷新和技术重试不重置期限。

### A17 · 基础彩金和随机结果锁定

固定比例（上下限相等）先算原币基础额 S＝P×比例/100，按参与时锁定的原币精度向下舍入；再以生成宝箱时锁定的 USD 汇率 r 计算 B＝floor(S×r, USD金额小数位)。

比例区间:在比例下限与上限之间按0.01个百分点等概率抽取一个比例,先算 S＝P×抽中比例/100 并按原币精度向下舍入，再用生成宝箱时锁定的 USD 汇率计算 B。计算结果不足一个最小单位时,宝箱记为“精度后金额为零”,玩家不可领取,不产生彩金。

B在首次形成宝箱时只生成一次并保存；同时保存原币基础额 S、奖励币种、奖励精度、汇率、汇率来源和观测时间、抽中比例及版本。缺少有效且新鲜的 USD 换算依据时暂不生成宝箱，记录 reward_conversion_unavailable，恢复后再核对；不按 1:1 估算，不提前开始宝箱选择倒计时。随机翻倍模式同步为A10的每个金额区间和兜底区间各按0.01倍步长等概率抽取一次并锁定,充值金额决定使用哪个结果;固定比例或随机基础奖均不能通过刷新、重开、取消未支付订单或领取重试重新抽取。

固定翻倍模式由关联订单金额命中档位得到M;随机翻倍模式按关联订单金额命中的区间或兜底,使用宝箱已锁定的M。最终翻倍彩金 C＝floor(S×M×r, 奖励精度)，直接使用原币基础额和宝箱锁定汇率计算，不把已经舍入的 B 再乘 M。这里M是总额倍数,领取金额为C,不再额外发B。

### A18 · 普通领取

玩家在领取期限内点击普通领取,服务端校验资格归属、模式、账户限制、是否已有翻倍支付占用及原领取结果。允许不充值领取时,一次发放B彩金,同时建立B×普通彩金倍数的独立任务。

同一宝箱只能受理一条最终领取路径。普通领取成功后结束,后来充值不补差、不再领翻倍。打开宝箱、登录或后台恢复不能代替玩家首次领取。

### A19 · 选择翻倍与关联充值

当前平台未接入翻倍充值使用的支付通道:玩家端提示支付不可用,提交建单返回支付通道不可用,以下关联充值规则在通道接入后执行;未接入期间固定和随机模式的宝箱只能走普通领取,不允许普通领取的宝箱没有可用的领取路径。

1. 玩家在领取期限内选择翻倍,从活动入口选择当前币种的充值商品。关联充值必须为同币种单笔真实支付,不累计多笔凑门槛。
2. 固定模式按该订单应付金额取最高满足门槛的一档;随机模式按该金额命中对应币种的金额区间或兜底。下单前显示B、已选M、最终C、对应彩金倍数和充值X,并保存宝箱、配置版本、应付金额和条件。
3. 本单的赠送用途锁定为“首充破产补助翻倍”。排除该单M5商品固定彩金和限次比例彩金,不占用或消耗限次比例机会。原首充已发的奖励保留,不事后回收;其他订单及VIP、签到继续按自身规则执行。
4. 不能把普通充值完成后再追认为翻倍单。创建关联订单即占用宝箱,同一宝箱最多存在一笔待支付、支付中或支付结果未知的关联订单,期间普通领取和创建第二笔关联订单不可用。
5. 已确认未支付且不可继续支付的终态订单可解除占用;仍在领取期限内时可重新选普通/翻倍,随机结果不变。关闭页面、支付超时或网络错误不能直接视为未支付。
6. 支付成功须核验真实支付事实及金额币种与订单一致。本金按M5订单快照到账并建立充值金额×X的任务;活动保存翻倍条件已满足,不自动入宝箱彩金。金额不一致由财务核查,不偷偷降档、升档或改发商品赠送。
7. 创建关联订单时即锁定其支付有效期,以真实业务支付时间判断。领取期限内合法创建且在该订单支付有效期内实际付款的,即使成功通知在有效期后到达也按原规则履约;实际付款超出订单支付有效期的异常收款进入财务核查,不得静默吞款或自动发奖。
8. 一旦关联充值确认成功,保留一次手动领取C的权益,不再用原宝箱选择截止时间使其过期,不可改领基础奖。界面明确显示“充值成功,翻倍彩金待领取”;用户手动领取后才入彩金并建任务。

本活动免除的是该单商品赠送,不是充值本金打码。无商品绑定的自由Crypto入金不能事后作为翻倍订单;如使用Crypto支付商品,仍须在建单时已有可靠的商品、宝箱和支付订单关联。

### A20 · 领取、打码与异常恢复

普通奖B或翻倍奖C均计彩金来源,不增加真实充值金额和充值次数。彩金入账、独立打码任务及成功领取记录必须一致完成;未领取资格不建任务。相同宝箱的并发点击或不同请求编号也只能发一份奖。

领取请求被受理时锁定金额、倍数及路径。失败或结果未知查询并恢复原请求,不另建奖励、不重新抽取、不释放给另一领取路径重复处理。受理后跨截止时间仍完成原申请,参与记录转异常核查时按E8、E9暂停入账;只有未受理领奖、无合法在途订单且无已支付翻倍权益的限时资格,才在到期后结束。

充值X与普通/翻倍彩金倍数相互独立。首充、原赠金及后续充值的旧任务照常存在,亏损、钱包归零或补助不清除旧任务。已入账彩金不因活动关闭或长期不投注作废,提现继续按该币种全部任务及资金限制判定。

| 普通领取 | 0 | 20 | 0 | 60 |
| 充值50后手动领翻倍 | 50 | 40 | 100 | 200 |

两条路径只能完成一条;翻倍总奖为40而非60,该充值订单不再送商品固定/比例彩金。表中充值与充值任务使用 USDT，彩金与彩金任务使用 USD；不包含此前尚未完成的任务，示例汇率、金额和比例不是默认配置。

## 4. 特殊情况

| E3 | 有限领取期限到达 | 无已受理领奖、无合法在途订单且无已支付翻倍权益的宝箱结束;已受理请求和合法关联订单继续处理;已支付翻倍资格保留 |
| E4 | 选择普通与翻倍的并发请求 | 同一宝箱只占用一条路径,另一请求返回当前状态;不能两边发钱 |
| E5 | 支付失败、超时、迟到回调 | 明确未付款终态才能释放;未知结果保留占用;有效支付及补单沿用原快照,不重复本金或宝箱权益 |
| E6 | 活动保存或关闭 | 只改变新首充参与,原参与的规则、观察期、宝箱、订单及任务保持原依据 |
| E7 | 标签计算迟到或后来摘除 | 初始判断按T0恢复;参与后普通标签变化不撤权,实时账户资金限制仍执行 |
| E8 | 投注撤单修正使原触发无效 | 参与记录转异常核查;未受理领奖的宝箱同时转异常核查并暂停领取,保留原随机结果及首次生成时间。关联单占用不释放;已受理但尚未入账的领奖暂停入账并保持处理中,不发放、不另建申请。核查状态不自动恢复或结束,已关联收款或已入账走资金异常核查,不静默扣钱 |
| E9 | 原首充发生已确认退款/拒付 | 未触发的参与记录及未受理领奖的宝箱转异常核查并暂停领取,不改认新首充;关联单占用不释放,已受理但尚未入账的领奖按E8暂停入账。核查状态不自动结束,已经收款的翻倍单或已受理/入账奖励走资金异常核查,不由活动直接回收彩金 |
| E10 | 本金或本次彩金倍数缺失 | 拦截对应入账并保留恢复依据,不得按0或当前新配置兜底;本金已到账而待领补助异常时不重做本金 |
| E11 | 币种停用或平台资金服务不可用 | 暂停不能执行的领取,显示原因;领取期限照常计算,不顺延。已有订单按资金规则处理 |
| E12 | 玩家封禁/资金限制 | 暂停新充值选择或领奖,保留依据,不代领;解除后仍在资格范围内可继续,个体限制不自动延长期限 |
| E13 | 资格金额过小或计算越界 | 宝箱记为精度后金额为零、玩家不可领取,不截断越界金额,记录原因;不可改用固定商品赠金伪装补助成功 |
| E14 | 查询空、加载失败、无权限 | 无记录显示空状态,查询失败可重试且保留筛选;无查看权限不返回数据;保存/领取中阻止重复动作 |

异常核查展示涉及的充值或投注修正、宝箱/订单状态和已有资金结果。已收款或已入账事项由有权限的财务按原账变核查及受控修正流程处理,本活动记录页只读,不提供任意改奖、重置机会或直接扣款按钮。

### 活动内部记录

筛选包括玩家 ID、首充/关联订单 ID、币种、版本 ID、状态代码、首充起始时间（ISO）和首充截止时间（ISO）,均为文本输入。状态包括观察亏损中、已达标、不符合首充条件、待选择领取方式、充值确认中、已付待领取、领取处理中、已领取、已到期、异常核查和精度后金额为零。

详情保留：首充P/T0和币种、标签命中依据、观察起止、亏损金额与原结算引用、触发时间、宝箱首次可展示时间与领取截止、基础比例/金额区间、原币基础额、奖励币种与B、锁定汇率及来源、随机M或档位、关联订单及互斥用途、领取路径、实际彩金及倍数、充值X、账变/任务引用、异常和恢复结果。截止字段在不限时显示“不限”,不得显示为0。记录只读,不能改随机结果、复活已结束机会或重发奖励。
