# 领取用户明细

在兑换码详情的“领取明细”区,运营可以查看这个码被谁领取、每次领了多少以及领取时间,区块标题下显示成功领取记录总数。明细与只读配置一起查看,对应4.1-R2和4.1-R5。

## 查询条件

| 条件 | 含义 |
|---|---|
| 玩家 | 玩家ID精确匹配,账号或昵称按包含匹配;点击搜索按钮或按回车后生效 |
| 领取时间 | 按操作员浏览器时区选择日期范围,选定后立即生效 |

结果分页显示,默认每页20条,只包含当前兑换码的成功领取记录。“刷新”按当前条件重新读取。

## 结果字段

| 字段 | 含义 |
|---|---|
| 玩家 | 领取用户的ID及账号 |
| 玩家昵称 | 领取用户昵称 |
| 领取金额及币种 | 本次实际发放金额,不能省略币种或把不同币种直接相加 |
| 当时USD金额 | 按领取时汇率折算的统计金额 |
| 当时汇率、汇率来源、汇率时间 | 折算USD使用的依据 |
| 领取时间 | 实际领取时间 |

## 操作与权限

这里仅供查询,不能撤销领取或修改已发金额。服务端按运营方、代理等可查看范围过滤并脱敏,不能通过修改查询条件越权。

没人领过时显示“暂无数据”,取数失败时允许重试。删除兑换码不删除历史领取事实,但删除后详情不可打开,本版不提供已删除码的明细入口,规则见[模块D86](../README.md#7-决策清单)。

主规则与权限见[兑换码管理](README.md),这里不重复维护金额算法或领取次数规则。
