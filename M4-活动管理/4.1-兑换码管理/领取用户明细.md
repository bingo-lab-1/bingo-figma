# 领取用户明细

在兑换码详情里,运营可以查看这个码被谁领取、每次领了多少以及领取时间。明细与只读配置一起查看,对应4.1-R2和4.1-R5。

## 查询条件

| 条件 | 含义 |
|---|---|
| 玩家 | 按玩家ID或昵称查询 |
| 领取时间 | 按运营时区选择范围 |

结果分页显示,查询只针对当前兑换码。

## 结果字段

| 字段 | 含义 |
|---|---|
| 玩家ID、昵称 | 领取用户 |
| 兑换码 | 本次使用的码 |
| 奖励金额及币种 | 本次实际发放金额,不能省略币种或把不同币种直接相加 |
| 领取时间 | 实际领取时间,标明运营时区 |
| 有效期 | 该码的到期时间 |
| 归属代理 | 玩家所属代理 |

## 操作与权限

这里仅供查询,不能撤销领取或修改已发金额。服务端按运营方、代理等可查看范围过滤并脱敏,不能通过修改查询条件越权。

没人领过时显示空记录,取数失败时允许重试。删除兑换码不删除历史领取事实,通过主列表“包含已删除”筛选仍可进入该码明细,规则见[模块D86](../README.md#7-决策清单)。

主规则与权限见[兑换码管理](README.md),这里不重复维护金额算法或领取次数规则。
