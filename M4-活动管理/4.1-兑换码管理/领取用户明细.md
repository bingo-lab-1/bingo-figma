# 领取用户明细(弹窗)

> 在兑换码列表点某个码的「详情」,领取明细与只读配置合并在同一个详情中,即 4.1-R2/R5。
> 看这个码谁领了、领了多少、什么时候领的。字段后的代码名是线上的,方便对照。

## 一、作用

帮运营看清三件事:**谁领了、领了多少、钱花在哪**。它只是看,不能在这里改数据,
主要用来对账和查异常(比如某个码被一群人集中领走)。

## 二、筛选字段

| 字段 | 控件 | 说明 |
|---|---|---|
| 玩家 | text | 按玩家 ID 或昵称查 |
| 领取时间 | daterange | 按运营时区 |

## 三、表格列

| 列 | 代码名 | 说明 |
|---|---|---|
| 玩家 ID | `uid` | 谁领的 |
| 昵称 | `nickname` | 玩家昵称 |
| 兑换码 | `redeem_code` | 领的是哪个码 |
| 奖励金额 | `reward_amount` | 这次领了多少,按玩家币种 |
| 领取时间 | `save_time` | 什么时候领的,按运营时区 |
| 有效期 | `lost_time` | 这个码什么时候作废 |
| 归属代理 | `agent_id` | 玩家属于哪个代理 |

## 四、行为与边界

- 只能看,分页;这里不能撤销、不能改金额(领取记录是留底的,发了就不能改)。
- 只给看自己该看的:按运营方 / 代理归属过滤(4.1-R5、E1)。
- 敏感信息由服务端打码。
- 没人领时显示空。
