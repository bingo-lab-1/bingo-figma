# 新增兑换码与只读详情

运营新增时填写下面的设置。创建后只能查看这些配置,不能编辑;详情同时显示领取记录。对应需求4.1-R1、4.1-R2、4.1-R5。

## 要填写什么

| 字段 | 含义与校验 |
|---|---|
| 生成数量 | 这次生成多少个不同的码;正整数,格式及单批上限见主文档A5 |
| 有效期 | 这个时间之后不能再领,必须晚于当前时间 |
| 状态 | 默认启用;停用后不能新领取 |
| 备注 | 运营内部说明,玩家不可见,可不填 |
| 奖励总金额 | **每个码**各自的标准币总预算,不是整批共用预算 |
| 最小、最大奖励金额 | 每次领取的合法范围,预算必须能在总次数内完整拆分 |
| 打码倍数 | 每次实际奖金所需的倍数;范围见主文档A3 |
| 总领取上限 | **每个码**最多可被领取几次,正整数 |
| 单人领取上限 | 同一个人对**同一个码**最多领几次,正整数 |
| 领取对象 | 用户标签／指定用户二选一，所选内容必填；无“所有用户”选项 |
| 用户标签 | 至少一个启用且计算完成的标签；命中任意一个即可；组合条件在标签内部定义 |
| 指定用户 ID | 仅一个当前运营方及操作员数据范围内的有效用户 ID；不支持昵称、账号、手机号或多个 ID |

奖励类型固定为彩金,不提供选择。奖金范围、随机拆分及跨币种规则统一见[主文档操作规则](README.md#4-操作规则),不在此维护第二套数值。

## 新增与查看的区别

新增时可填写并提交;任何字段不符合规则时,指出原因且不创建错误配置。创建完成后,这些规则全部只读,包括预算、次数、有效期及领取对象（标签／指定用户 ID）;需要调整就停用旧码并新建。启停和删除是列表独立操作,不是编辑规则。

[只读详情参考截图](截图/弹窗-查看兑换码组-只读.png)用于理解已有字段,不规定布局。领取明细见[领取用户明细](领取用户明细.md)。

总预算及单次金额区间均填写平台标准计价币种USD金额,不填写玩家钱包原币金额。实际兑换按主文档受理时汇率规则执行。

## KAN-241 验收补充（2026-09-21）

- 标签为空、停用标签、用户 ID 为空、不存在、后台账号、越权范围或多个 ID 均不能保存。
- 切换模式清除另一模式的输入；服务端同样只保存和执行当前模式，不能依赖前端隐藏字段保证互斥。
- 指定 A 后，A 满足其他约束可领，B 即使命中标签仍拒绝；标签模式满足任一标签可领，不要求指定 ID。
- 详情只读展示领取模式及标签／用户 ID；改变对象必须停用旧码并新建。
- 总预算、总次数、单人次数、有效期不被自动修改；并发、重试只产生对应一次领取的账变与打码任务。
