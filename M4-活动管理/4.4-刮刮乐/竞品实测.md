# 刮刮乐 · 竞品实测

本文是 `README.md` 第 4 段「关键参数与假设」里「竞品实测」一类依据的原始出处。
正文只写有哪些参数、什么语义、在哪配;**具体数值不进正文**,一律落在本文,
按 `../../00-公共约定/README.md` 的「规则数值放配置,不放文档」。

## 1. 数据来源与口径

| 项 | 取值 |
|---|---|
| 平台 | wild777(巴西站,币种 BRL) |
| 数据来源 | 数据中心为该平台建的分析库,由平台方后台逐日同步 |
| 用到的数据 | 赠送流水(赠送事由 = 刮刮乐)、充值订单(仅取成功到账的) |
| 窗口 | 2026-04-09 ~ 2026-08-31 |
| 总量 | 373,911 笔发放,合计 6,756,560.52 BRL |
| 取数日 | 2026-09-01 |

**两个时间口径**:充值订单有「下单时刻」与「到账时刻」两个时间,两者中位相差 46.8 秒
(最小 9.35 秒、最大 59 分 42 秒)。早期按到账时刻对齐会得出"赠送早于充值"的假象,
本文所有结论均双口径核对过。

**隔离单**:该笔充值前后 2 小时内该玩家没有其他成功充值。用于把一笔充值和一次发放
一一对应,排除连续充值造成的错配。下文凡标「隔离单」的表都用这个口径。

**触发率**:合格充值笔数中,在到账后 10 分钟内产生了一次刮刮乐发放的比例。

## 2. 结论摘要

| # | 结论 | 证据强度 |
|---|---|---|
| 1 | 充值到账瞬间自动发放,无玩家动作、无未领取态、无跨日延迟 | 强,见第 3 段 |
| 2 | 有硬性最低充值门槛(复充 15、首充 20),低于门槛一笔不发 | 强,见第 4 段 |
| 3 | 按充值金额分档,不同档位触发率与彩金区间不同 | 强,见第 5 段 |
| 4 | 同一档位下按**注册天数**分层,新玩家彩金显著高于老玩家 | 强,见第 6 段 |
| 5 | 首充与复充是两套独立配置,门槛与区间都不同 | 强,见第 7 段 |
| 6 | 每人每自然日发放次数封顶 10 次 | 强,见第 8 段 |
| 7 | 彩金在区间内均匀随机,两位小数 | 强,见第 9 段 |

## 3. 触发时机

隔离单 50,992 笔,发放时刻与**到账时刻**的偏差:

| 偏差 | 笔数 |
|---|---|
| 到账前 0 ~ 60 秒 | 44,247 |
| 到账后 0 ~ 5 秒 | 6,781 |
| 其余全部分桶 | 0 |

"到账前 0 ~ 60 秒"不是提前发放 —— 到账时刻是后台确认写入的时刻,比实际入账略晚,
两者差值正好落在下单到到账的 46.8 秒中位区间内。

同一批隔离单,发放时刻与**下单时刻**的偏差:

| 偏差 | 笔数 |
|---|---|
| 早于下单 | 3 |
| 0 ~ 1 分钟 | 33,928 |
| 1 ~ 5 分钟 | 16,685 |
| 5 ~ 30 分钟 | 355 |
| 30 分钟 ~ 3 小时 | 24 |
| 超过 3 小时 | 0 |

另:2026-08 全月 25,827 笔发放,**100% 发生在该玩家当天有成功充值的日子**,
没有任何一笔发生在无充值日。7 天内无充值的玩家发放数为 0。

**判读**:发放完全跟随到账事件,分布形态与到账延迟一致,没有人类反应时间该有的长尾。
这套机制里不存在"发一张卡等玩家来刮"的环节。

## 11. 触发概率

同一(档位 × 分层)格内触发率稳定,但普遍不是 100%:

- 15 元档复充,注册 30 天以上:2026-05 起逐月为 88.7% / 88.9% / 91.0% / 91.8%,四个月内浮动 3 个百分点
- 各档位复充触发率落在 69.4% ~ 97.8%
- 各分层触发率落在 86.3% ~ 98.1%

结合第 3 段"无玩家动作"的结论,这个缺口不可能是"发了没领",只能来自配置的概率。
但**绝对值不可分离**:观测到的触发率是「配置概率 × 该格玩家满足其余未知条件的比例」的合成值,
其余条件(风控排除、当日上限、我们看不到的标签)会把它压低。所以正文只把它作为
"确有概率配置"的证据,不把具体数值当作推荐取值。

## 13. 看不到的东西

以下项目在赠送流水里没有留痕,本文一律不做推断,正文对应参数标为假设:

| 项 | 为什么看不到 |
|---|---|
| 打码倍数 | 赠送流水只记金额,不记流水要求;是否有、几倍都不知道 |
| 后台配置本身 | 我们只拿到发放结果,所有"配置项"都是从结果反推的 |
| 活动开关与活动名称 | 全窗口内活动一直开着,没观察到关闭 |
| 玩家端是否有刮奖动画 | 钱与到账同刻入账;若有动画,也发生在钱到账之后,不影响金额 |
| 概率配置的绝对值 | 见第 11 段 |
| 单个玩家的标签 | 分层是按注册天数反推出来的,对方后台实际用什么标签表达未知 |
| 多币种下怎么配 | 该平台只有 BRL 一个币种,充值与彩金都是 BRL,看不出多币种时充值档位按哪把尺子判、彩金发哪个币种。我方"充值档位按标准计价判、彩金按活动配的奖励币种发"(README A4 / A16 / A23,D55)是我方设计,**本文不提供任何支持或反对的证据** |
