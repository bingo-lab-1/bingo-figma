# 4.6 · VIP配置

## 1. 活动介绍

运营在这里设置VIP等级、升级和保级条件、各级奖励以及每日出款上限。用户充值和投注达到要求后自动升级,并按所在等级享受权益。

用户同时达到充值和投注门槛才能升级。升入新等级后,获得一个完整日历月来完成保级要求。周奖励、月奖励、投注返现和升级奖励需要在规定时间内手动领取;投注返现按领取业务日成功充值判断全额资格；周、月、升级奖励仍按领取业务月累计成功充值判断。

用户标签只限制奖励领取,不影响升降级。关闭VIP活动后,暂停升降级和奖励发放,每日出款上限继续执行。

本页不提供单用户手工调级或多套VIP方案,本版也不提供等级迁移和归档。[VIP签到](../4.10-签到奖励/README.md)是独立活动,使用本页的等级信息。

本页说明后台配置、页内奖励记录查询和业务行为,不设计玩家等级页、进度条或出款页面。玩家端当前只提供升级奖励的领取入口,周奖励、月奖励和投注返现尚无领取入口。后台为桌面端,参考1440px、最小支持1280px,不做移动后台;后台简体中文,活动名及等级名按运营语言。日期按平台业务时区计算,页面展示时间按操作员浏览器时区。

升级、保级、日／月充值门槛和出款限额使用平台标准计价币种;奖金使用活动选择的奖励币种。两种金额不能直接当作同一币种比较或入账。

## 2. 运营配置

### 基础设置(A1至A8、A16)

| 配置项 | 含义和填写规则 |
|---|---|
| 活动开关(A1) | 首次保存配置后才可开启,有未保存修改时不可切换;关闭后停止VIP升降级判定及奖励发放,已发不追回;出款限额仍执行 |
| 周/月奖励独立开关（KAN-243） | 活动级开关，全等级生效，两者互不影响。关闭保留配置，立即暂停当前未领奖励；重新开启仅恢复尚未结束的原窗口，不补时、不补发，已发不追回。总开关关闭时子开关不能单独发奖。随整份配置保存后生效 |
| 升级奖励领取窗口（KAN-244） | “升级后领取日期”统一选择升级当日或升级次日,并填写 HH:mm 开始和结束，业务时区，前含后不含；同日已到结束时刻则移至次日同一时段 |
| 活动名称(A2) | 必填,1至40字符 |
| 领奖标签条件(A3) | 可不选;选多个时必须全部满足,即AND关系 |
| 渠道人群(A4) | 不单独配置渠道;先在用户标签中定义渠道条件,再选择该标签 |
| 统一打码倍数(A5) | 不小于0,最多4位小数,四类奖励及全部等级共用;每笔奖金独立产生打码要求,倍数为0时打码任务直接完成 |
| 投注返现领取窗口(A6) | 每天一个时段,首次配置预填00:00至23:59,领取上一自然日返现 |
| 周奖励领取窗口(A7) | 每周选择一天(1至7,1为周一)及一个时段,首次配置预填周一00:00至23:59,每个自然周可领一次 |
| 月奖励领取窗口(A8) | 每月选择1至28号及一个时段,首次配置预填1号00:00至23:59,每个自然月可领一次 |
| 奖励币种(A16) | 从平台已开通币种选择,必填;整个活动统一,不逐级或逐类配置 |

每个时段精确到分钟,开始必须早于结束,使用24小时制,不支持跨日,最晚结束时刻为23:59。渠道标签内部选择多个渠道时可满足任意一个,但本页多个标签之间仍要求全部满足。

### 每个等级的设置(A9至A13)

| 字段 | 含义和填写规则 |
|---|---|
| 等级序号(A9) | 系统按历史最大序号加一产生正整数,不可手填、永不复用 |
| 等级名称(A9) | 只用于显示,不影响排序;必填,去首尾空格、忽略大小写后不可重名,本版不限制最大长度 |
| VIP 等级图标(A25) | 可不填;上传 PNG、JPEG 或 WebP 图片,2 MB 以内,支持非正方形徽章 |
| 累计充值门槛（USD）(A10) | 达到该级所需累计充值,非负数,最多两位小数 |
| 累计有效投注门槛（USD）(A10) | 达到该级所需累计有效投注,非负数,最多两位小数;必须与充值同时达标 |
| 个人周期保级流水（USD）(A11) | 每个个人保级周期需要完成的有效投注,非负数,最多两位小数,不要求逐级增加 |
| 未保级降至(A12) | 除最低等级外必选,目标须为启用且序号更低的等级;最低等级显示“最低等级不再降级” |
| 允许新玩家升入(A13) | 等级启用状态,新增默认开启,可关闭;关闭后不再允许新用户升入。等级标题旁显示“允许升级进入”或“暂停升级进入” |
| 当日出款金额上限（USD）、当日出款次数上限 | 两项均必填,具体含义见A22至A24 |

高等级的充值、投注门槛均不能低于前一等级,停用等级也参与比较。活动开启时至少保留一个启用等级,开启活动时同样检查。等级名例如“Gold”和“ gold ”视为重名。

等级可以停用,已保存的等级不可删除,新等级只能追加在序列末尾。停用用户权益见“停用、迁移和归档”。

### 每级的四类奖励(A14)

| 奖励 | 基础奖金怎么计算 |
|---|---|
| 升级奖励 | 首次到达该启用等级的固定金额，非负数，精度不超过奖励币种，每用户每等级终身一次 |
| 周奖励 | 该级固定金额,非负数,精度不超过奖励币种 |
| 月奖励 | 该级固定金额,非负数,精度不超过奖励币种 |
| 投注返现(A18) | 上一自然日有效投注×该级返现比例;比例按0至1填写,最多4位小数,例如0.01表示1% |

周、月及升级奖励的固定金额字段为“基础奖励金额（奖励币种）”,投注返现的比例字段为“返现比例（0–1，例如 0.01=1%）”。投注返现设置“每日充值全额门槛（USD）”；周、月及升级奖励设置“本月充值全额门槛（USD）”。每类分别设置“未达标免费领取比例（0–100%）”。充值门槛为非负标准币金额,最多两位小数,免费比例为0至100（含端点）的整数；负数、大于100、小数或非数字均拒绝。

四类奖励的金额、充值门槛和免费比例都必填,新增等级时预填0。某级某类金额为0表示不提供这一类奖励,领取时按金额为0处理。

### 保存及配置提示

加载时可查看基础设置、等级及各级奖励。点击“保存全部配置”时整份检查金额、等级关系、时间、启用标签、币种及权限,不能部分生效。错误应定位到字段;修改可重试。配置版本已变化时拒绝保存并提示刷新。

等级配置及周、月奖励保存后立即生效;投注返现配置下一业务日00:00生效;升级奖励使用升级时冻结的配置。已发奖励、已受理出款不被新配置重算。

本页不因红包雨未补档而拒绝保存,也不作提醒。页面常驻说明次数或金额上限为0时禁止出款,保存时不另行确认。不规定这些提示的页面位置。

## 3. 参与和领奖规则

### 升级和保级(A10、A11、A17)

每次充值到账或平台原创游戏投注结算后,根据累计充值和累计有效投注判断是否升级;第三方游戏的有效投注计入累计,在下一次判定时生效。发生过降级的用户按下文重新升级规则使用新增金额。两项都达到才升级,可以一次跨多级,只进入符合条件的启用等级,跳过停用等级。**不读取用户标签来决定等级。**

有效投注取已结算投注的投注额,按扣款时的USD折算结果累计,按最终结算时间归期,不乘游戏折算比例;取消的投注不计入。保级看的是个人周期内的有效投注,不是充值额。

升入新等级的时刻就是保级周期起点,长度为一个完整日历月。例如9月12日15:00升级,到10月12日15:00检查保级。下一月没有相同日期时取该月最后一天,时刻不变;后续周期以上一次结算时刻继续计算。

周期结束时:

- 完成保级流水,保留等级,紧接着开始下一个完整日历月。
- 未完成且设置了降级目标,降到该级,从降级时刻开始目标等级的完整保级月。
- 最低等级没有降级目标,保持等级并开始下一周期。
- 目标已停用,本次不降级,保持等级并开始下一周期。

周期内再次升级,旧周期结束,从新的升级时刻重新获得完整保级月。存量有等级但没有保级周期的用户,系统补建一个完整保级月,不追溯扣减。升降级及保级结算都保存前后等级、周期起止、判定金额及原因。

### 奖励在规定时间内手动领取(A6至A8、A19、A21)

投注返现按上一自然日有效投注计算,周奖励每个自然周可领一次,月奖励每个自然月可领一次;周、月为固定金额,不统计上一周期数据。它们的周期与个人保级月不同。

用户需在所选领取时段内点击领取。超过窗口不补发,也不积累到下一期。同一期同一类奖励每人只能领一次。

月奖励日期只能选1至28号,不会出现当月缺日。领取时段包含开始时刻,不包含结束时刻;自然周从周一00:00开始。

### 升级奖励权益（KAN-244）

真实升级时，按当时配置冻结各个首次跨入且启用等级的奖励金额、充值门槛、免费比例、币种、打码倍数、参与标签及领取窗口。例如1级升到3级，分别生成2级和3级权益；停用等级不生成。每用户每等级仅生成一次，降级后重新升级、已领取或已过期均不重建，不追补功能上线前已达到的等级。

选择当日且升级发生在窗口内，领取起点为升级时刻；发生在窗口开始前，等待开始；到达或超过结束时刻，移动至次日同一时段。选择次日则固定下一业务日。错过原窗口过期，不延期或累计。升级在月末、次月领取时，以实际领取所在月份的充值判断全额资格。

领取为手动操作，领取非零部分即消费该等级权益，不补差；计算为零不创建资金账变或打码任务，不消费权益，窗口内满足充值后仍能领取。金额、资金账变、打码任务、领取记录在同一事务完成，失败全部回滚；结果未知重试恢复同一已成功结果，关闭或过期不撤销已成功结果。记录关联升级事件、等级、原窗口、配置版本、领取时月充值、基础金额、免费与实际比例、币种、倍数、账变和打码任务。

### 全额和免费部分(A3、A15、A18)

领取时检查活动开启、账号未封禁、全部参与标签都满足,再计算基础奖金。周、月为固定金额,返现以昨天有效投注计算。

全额资格使用实际领取时的成功入款：投注返现统计**领取业务日00:00至领取时刻**；周、月、升级奖励统计**领取所在自然月1日00:00至领取时刻**。均不使用奖励投注统计期或个人保级周期的充值。

- 返现按实际领取业务日 00:00 至领取时刻的累计成功入款判断；周／月／升级仍按领取自然月。达到对应门槛（含等于）领取基础奖金的100%。未成功到账的入款不计入。
- 未达到门槛,包括完全没充值:领取“基础奖金×免费百分比”。
- 免费比例为0:未达标时不可领取，不占名额。
- 免费比例为100:即使没有充值也可领取完整基础奖励；仍检查活动开关、账户、标签、窗口和去重。充值达标也只发100%，不叠加免费比例。

**领过免费部分,本期就不能再领或补差。** 后来充值达标也不补足。这与VIP签到的当日补差是不同规则。

例如:周奖金50 BRL、充值门槛100 USD(标准计价)、免费比例20%。本月充值只有80 USD时领10 BRL;达到100 USD后首次领取则领50 BRL。如果已领10 BRL,之后达标不再补40 BRL。

免费金额按奖金币种最小单位及钱包舍入规则处理。结果为0不创建账变或打码任务;不占用本期领取名额,窗口内充值达标后仍可领取。

### 领取时确定哪些奖励信息(A20)

已领取的奖金金额、等级、币种和打码倍数固定,之后升级、降级或改配置都不改变这笔结果。

投注返现按当日生效的规则版本及窗口开放时的用户等级确定比例、奖励币种、打码倍数、充值门槛和免费比例,窗口内升降级或修改配置不重算这份奖励。周、月奖励不提前锁定,领取时按当前配置和用户当前等级计算。全额资格在实际领取时判断：返现统计领取业务日，周／月统计领取业务月。领取时须已有VIP等级,不按注册时间另行限制。

### 暂停、降级和数据恢复

关闭活动期间不做升降级和保级判定,保级周期不暂停、不顺延;恢复开启后,已到期的周期按原起止时间内的有效投注补做结算,不补发关闭期间未开放的奖励。恢复时可按真实累计充值和投注判定升级,但仍执行以下降级后的重新升级规则。

保级降级时,记录该时刻累计充值和累计有效投注作为新起点。重新升到更高等级需要两项新增金额分别达到“目标等级门槛减本次降级后起始等级门槛”,差额小于0按0处理,且两项都必须有新增。后续再次升级仍沿用本次降级起点,直到又一次降级才重设,不能靠原有累计值立即升回。

有效投注数据缺失时保留原周期和应结算时刻,数据恢复后按时间顺序补做,保级成功时下一周期从原应结算时刻开始,降级时从实际判定时刻开始。已经发放的奖励不因补做结算被追回。

投注返现以上一自然日有效投注的USD合计乘返现比例,再按领取时奖励币种最新汇率换算,按钱包币种精度向下舍入。汇率缺失或超过2分钟未更新时拒绝领取,玩家可在窗口内重试;昨日投注存在未完成折算时同样拒绝,不按0或部分金额计算。

### 每日出款限额(A22、A23、A24)

每级设置当日最高次数及最高金额。次数为不小于0的整数;金额为不小于0、最多两位小数的标准计价金额。两项必填,没有“不限”选项,任一项为0就表示该级当天不可出款。

申请提交到服务端时,按用户当时VIP及最新限额检查。金额使用手续费前申请总额,按申请时汇率换算为标准币并保存,不是预计到账净额。两项都不能超:

- 当天已成功及仍占用的次数＋本次1笔,不超过次数上限。
- 当天已成功及仍占用的金额＋本笔标准币金额,不超过金额上限。

受理后立即占用次数和金额。待审核、审核中、放款中都继续占用;成功后计为已使用。审核拒绝、取消或明确失败,须在资金解除占用或归位后才释放。回执超时、结果未知时不释放。

所有额度始终归申请受理的业务日。昨天受理、今天成功,不再占今天额度;昨天的申请今天失败,只修正昨天的记录,不会增加今天额度。

升级、降级或修改限额不撤销原申请,不追回成功出款。下一笔按最新规则,但今天原有的成功和占用仍全部计入。若新上限已低于使用额,剩余展示为0。

例如当天已用1次、20 USD,升级后的上限为3次、100 USD,剩余为2次、80 USD。不能因为升级重新得到完整额度。并发申请也必须共同受限,不能每笔各自看旧额度而一起通过。

VIP活动关闭时以上限制照常执行。等级配置缺失或换算失败时拒绝受理,不按无限额或0金额放行。M4提供等级与限额,M5负责订单、占用和释放。

## 4. 特殊情况

### 停用、迁移和归档(A13)

本版只提供停用:等级停用后不再允许新用户升入,原用户保留等级、该级VIP奖励及出款限额。已保存的等级不可删除,序号不复用。

批量迁移用户和归档等级本版不提供。停用不补发、不追回历史奖励,不撤销已受理出款。

### 领取和出款遇到异常时

| 编号 | 情况 | 如何处理 |
|---|---|---|
| E1 | 无权限修改或启停 | 服务端拒绝;权限按操作区分 |
| E2 | 同人同期同类重复点击 | 不重复发奖、打码或占领取名额 |
| E3 | 领取窗口已关闭 | 按服务端时间拒绝,不使用玩家设备时间;开始时刻可领,结束时刻不可领 |
| E4 | 达标未领期间升降级 | 已领奖励不变;未领的投注返现使用窗口开放时的等级,周、月奖励按领取时等级 |
| E5 | 领取前标签发生变化 | 按领取时命中情况检查全部标签,不回溯已领 |
| E6 | 停用等级仍有用户 | 保留原等级权益,本版不提供迁移或归档 |
| E7 | 降级目标被停用 | 本次不降级,保持等级并开始下一周期 |

奖励领取在同一事务内完成,入账失败全部回滚,不算成功领取、不占该期名额,玩家可在窗口内重新领取,窗口结束后不再恢复。同一期已成功领取时,重复请求返回原结果,不再次发钱。

奖励判定所需的标准币金额缺失时本次拒绝领取,玩家可在窗口内重试,窗口结束后不补发。

空、加载、错误及无权限沿用公共要求;零出款限额需要明确说明,不规定折叠或布局样式。

### KAN-245 返现日入款与规则生效（2026-09-21）

- 返现基数保持“上一业务自然日已结算有效投注 × 等级返现比例”；全额资格独立使用领取业务日累计成功入款，标准计价 USD。平台业务时区决定跨日、跨月边界，与浏览器时区无关。
- 当天多笔入款累计达到门槛即全额；昨日或月内其他日期入款不计入当天资格；未成功到账不计入。正金额免费部分一经领取，当期不再补差；免费比例100允许零入款，但活动、窗口、账号、标签、币种与钱包限制仍生效。
- 规则切换持久化记录统计周期、配置版本、平台业务时区及精确生效时间。部署后首次服务启动，将已有配置按月统计的规则保留至当日窗口结束，日规则从下一业务日00:00生效；新建 VIP 配置从首次保存起采用日规则。
- 后续返现配置编辑于下一业务日00:00生效；当日已开放窗口继续使用当前版本。尚未生效的次日配置可再次保存替换，保存过程保留操作日志；已生效版本及成功领取记录不可重算。总开关仍立即暂停，重新打开不补时。
- 领取记录保存日／月统计周期、业务日期、时区、起止时间、实际入款、门槛、实际比例、采用等级、配置版本及返现规则 ID／生效时间，并与账变和打码任务关联。旧记录未保存的审计字段显示未保存，不用新规则猜测填充。
- 验收覆盖：昨日大额入款／今日零入款、多笔恰好达标、处理中入款、业务日及月末切换、浏览器异时区、部分领取后不补差、100%零入款、旧窗口冻结与新版本切换、周／月／升级仍按月统计。
