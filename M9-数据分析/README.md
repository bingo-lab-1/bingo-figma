# M9 · 数据分析

## 1. 定位与边界

运营通过数据中台比较获客成本和后续资金回收。本模块先维护同期群分析需求，承载位置为现有 Chartx 数据中台的“投放数据中心 → 同期群分析”；M9 是文档分类，不要求在 Bingo 后台复制一套菜单和报表。

Bingo 提供可追溯的渠道、注册和成功充提事实，中台接收这些事实形成分析数据，再提供查询。分析结果不改变钱包、订单、渠道归属或邀请关系。广告消耗的采集、导入由中台已有成本能力负责；本页面不编辑广告费，不执行广告投放、回传或同步任务。

现有中台的注册日、广告归因、D0–D60 矩阵、平均回收和渠道明细均在本文档范围内。Bingo 接入先开放注册日口径和 USD；其根用户关系及归属数据满足页面规则后，才开放广告归因。其他平台保留已经具备的两种口径及 USD/BRL 展示。

页面正文是实施和验收依据。UI 应尽可能与[现有同期群页面](https://dash.chartxcloud.com/marketing/cohort)相似，对齐整体布局、筛选区、汇总与矩阵层次、色块、图例和交互；重点沿用回收热力图、消耗强度和回本率色块的表达，具体要求及截图随页面正文维护。留存、LTV、渠道决策和其他分析页面保持各自职责，本次不扩写它们的需求。

## 2. 术语表

| 术语 | 定义 |
|---|---|
| 同期群 / 批次 | 按同一个归属日期归到一起的用户集合 |
| 注册日口径 | 每名用户按自己的注册日期和注册渠道归组 |
| 广告归因口径 | 用户沿邀请关系找到根用户，按根用户的注册日期和渠道归组；包含后续裂变用户 |
| Dn | 距批次日期 n 个自然日；D0 是批次当天 |
| 净回收金额 | 纳入统计的累计充值金额减累计提现金额，不等于经营净利润 |
| 回收率 / ROI | 净回收金额除以该批次日期的广告消耗；100% 是广告费回收线 |
| 完整数据截至日 | 当前平台参与分析的必要数据均已完成同步的自然日边界，不包含未结束的今天 |
| 预测 / 外推 | 用已完整观察批次的增长规律估算较新批次在后续天数的回收，仅用于平均回收行 |

## 3. 依赖关系

**上游依赖（我引用）**

- [M2 用户管理](../M2-用户管理/README.md)：用户唯一标识、注册业务时间、注册渠道、测试标记及更正事实。
- [M5 财务管理](../M5-财务管理/README.md)：成功充值、成功提现、冲正及原业务时点；Bingo 金额引用[标准计价](../M2-用户管理/2.1-用户列表/标准计价.md)，分析不另造换汇规则。
- [M7 代理管理](../M7-代理管理/README.md)：原始邀请绑定关系及其业务时点；归因不新增补绑、换绑或佣金规则。
- 渠道能力（本仓库范围外）：平台内稳定渠道 ID、名称、推广商及用户的获客归属。
- 中台成本和数据采集能力：按渠道、日期记录的广告消耗、币种依据、各数据源完整性与修正信息。
- 中台账号权限能力：平台访问范围和角色；Bingo 后台账号继续使用 M6，中台账号不自动继承 Bingo 管理权限。

**下游被依赖（谁引用我）**

- 投放运营、设计、开发与测试：使用同一份字段说明和验收口径。
- 中台渠道决策页面：可带平台、推广商、渠道进入同期群查看依据；决策模型和投放操作不归本模块。

## 4. 数据归属与读写边界

| 数据 | 归属与本模块使用方式 |
|---|---|
| 同期群分组、回收矩阵、汇总、预测和数据状态 | M9 维护分析定义；由中台分析能力计算和提供 |
| 用户及注册事实 | M2 拥有；经分析数据同步后只读消费 |
| 成功充提、账变、冲正和标准金额 | M5 拥有；中台只读消费，不重新判定支付成功或修改账务 |
| 邀请关系 | M7 拥有；中台只读原始关系，建立统计归属 |
| 渠道、推广商及广告成本 | 外部渠道和中台成本能力拥有；本页面只读筛选和汇总 |
| 数据完整性、同步批次及失败记录 | 各采集任务提供事实，中台归集状态；页面不能通过点击刷新宣称数据已同步 |

查询读取中台分析数据，不直连 Bingo 业务库执行重型汇总。数据接入方式和接口结构由技术设计维护；本仓库只规定必须提供的业务事实与可对账结果。

## 6. 权限点汇总

| 权限标识 | 能力 | 数据范围 |
|---|---|---|
| `analytics:cohort:view` | 查看筛选、矩阵、汇总和日期渠道明细 | 仅已授权的平台 |

该权限码是本仓库的需求标识。现有中台通过 `admin` / `ops` 角色与平台授权实现同一能力，不能据此宣称已有细粒度权限码。同期群不对只有单个推广商数据权限的合作方开放；推广商筛选不是权限隔离，日期明细可以展示该已授权平台的全部投流渠道。

无权限时服务端拒绝主表和明细查询，平台选项也不泄露未授权平台。平台级管理员身份不自动授予 Bingo 财务、用户修改或广告操作权限。
