# 运营分析总表 · 87 项指标字典

本表逐项对应原网页全部指标；编号、名称、顺序及分组取自 2026-09-28 登录页面返回的列元数据。日期 / 汇总是固定身份列，不占 87 项。本文只解释现有平台，不定义 Bingo 接入。

## 阅读与公共口径

- 每项分别给出业务解释、真实单位、页面格式、Wild 与 Aigobet 的现有计算；完整字段表达式及原始悬停提示见[指标来源映射](指标来源映射.csv)，原网页字段清单见[网页指标元数据](网页指标元数据.json)。
- D 为该日行日期，D0 为批次当日。Wild 指 Wild777 / 600pro，Aigobet 指 Lua365 / Rabbit7 / Tropa777。产品族公式源于所查源码；本次只现场读取 Wild777 和 Lua365 两个平台样本，不能当作其余平台逐笔对账结果。
- 常规除法分母为 0 或空则 null；现有 `_div` 把缺失分子当 0。字符串基础量、差值函数、固定 0 占位有不同缺项处理，精确逻辑见来源映射。页面 null 为“—”，不提供逐格缺失原因。比例不封顶 100%，负值不裁成 0。
- dec 统一加 $ / R$、保留两位小数；int 使用千分位、日均最多三位小数；pct 将比例乘 100、保留一位小数。M038/M040 真实单位不是钱，但现有网页仍加货币符号。USD/BRL 当前只改本表符号，不换数值。
- 总汇总 / 月汇总先合计基础量再套本项公式；日均先将基础量除以返回日数再套公式。比例不是每日百分比平均值；跨日人数合计不是整个期间去重用户数。M009–M012 的历史取期末，日均为空；M049 Aigobet 公式中的 int 截断是日均例外。
- 新用户通常以注册日判断，首充以首次充值日判断，二者不可混为一类；上游专列保留其来源定义，不凭中文名称补出未证实的人群过滤。Wild 成功充值取 order_status=5，提现主汇总取 order_status=4；Wild 注册 LTV 提现还加 order_result=1，且测试过滤按对应 SQL 执行。
- M024、M064、M067–M087 涉及后续观察，现有网页没有成熟度屏蔽。LTV 分子为注册批次净充值，分母为当天首充人数，不能称为同一注册人群的人均收入。Wild 原提示的 N+1 天与所查 SQL 的 N 天不一致，本文分别保留证据，未声称查明线上每个批次由哪一版任务计算。
