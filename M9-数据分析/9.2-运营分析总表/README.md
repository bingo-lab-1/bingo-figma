# 9.2 · 运营分析总表字段字典

## 1. 分类与底色

| 分类 | 表头底色 |
|---|---|
| 当日收支 | `#4285F5` |
| 总营收 | `#FAA626` |
| 当日新用户质量 | `#EB9999` |
| 当日资金流动 | `#008080` |
| 其他指标 | `#8C7AC2` |

分类与字段表头使用相同底色。浅色主题直接使用上表色值，深色主题按 35% 强度与页面背景混合。

数据格默认使用白色底色，隔行叠加浅灰。绿色热力按数值从低到高使用无色、10%、20%、30%、40% 的绿色透明度；红色热力按数值从高到低使用无色、10%、15%、25%、35% 的红色透明度。各列以当前日行最小值、最大值等分五档；空值、全列相同值、汇总行不加热力底色。

## 2. 字段定义

本表位于 Bingo 后台“报表管理 → 运营分析总表”，读取已发布的统计结果，一个平台每日一行。统计对象是 Bingo 玩家，不含后台账号和当前标记为测试的账号。金额统一为 USD，取业务发生时保存的 USD 计价；统计日按 GMT−3 切分。

日期 / 汇总：显示统计日期或总汇总、全盘日均、月汇总标签；表头灰色 `#CCCCCC`，数据格白色，不占以下 87 项指标。行序依次为总汇总、全盘日均、按月份倒序的月汇总、按日期倒序的日行。

汇总行中金额和人数相加，比率用相加后的分子、分母重新计算；历史充提差取区间最后一天的值，全盘日均不显示该列。留存与首充次日复充只汇总已到目标日的批次。

D 是统计日，D0 是批次当日。首充指首次成功充值，新充指注册当日充值。一级指统计日结束时没有有效邀请绑定，绑定在当日结束前已解除的用户也算一级。按相除计算的比例，分母为 0 或空时显示“—”。

成功充值与成功提现取有效账变：人工上分、赠金不算充值，已冲正的账变不计入。投注按下注时间归日，扣除取消和退款部分，已识别的测试投注不计入；派彩按最终结算时间归日。缺少 USD 计价时对应金额和比率留空，不按 0 计算，页面提示“存在缺少标准计价的业务记录，相关金额留空”；采用历史近似回填计价时提示“部分历史金额采用业务系统的近似回填计价”。

LTV 的分子为注册批次净充值，分母为当日首充人数，窗口未走完时只反映已经发生的数据。留存按指定目标日计算，未到目标日留空。活跃留存自活跃采集开始后才有数据，目标日早于采集起点时留空。

广告消耗尚未接入。今日消耗及依赖它的成本、ROAS、ROI、历史总营收、历史消耗、历史盈利率（M001、M004–M009、M011、M012、M014、M021–M023）统一留空显示“—”，不使用占位或模拟数据。

日期默认从 2026-04-01 到今天（GMT−3），快捷项为开盘至今、近 7/14/30/60 天，一次最多查询 1096 天；地址栏带入的起止日期颠倒时自动对调，晚于今天时收回到今天。市场、产品、推广商、渠道四个控件不参与查询，切换后数据不变。列筛选按账号保存在当前浏览器。

统计每 10 分钟重算最近 31 天，每天 GMT−3 03:15 重算全部历史。全部批次成功才发布新结果，失败时继续显示上次成功的数据并提示“最新统计未完成”，重算期间提示“统计更新中”。页面刷新只查询已发布结果，不触发重算。所选日期没有已生成的数据时显示“该日期范围暂无已生成的统计数据”，不补 0。
