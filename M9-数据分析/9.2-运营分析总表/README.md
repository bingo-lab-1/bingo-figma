# 9.2 · 运营分析总表字段字典

## 1. 分类与底色

| 分类 | 表头底色 |
|---|---|
| 当日收支 | `#4285F5` |
| 总营收 | `#FAA626` |
| 当日新用户质量 | `#EB9999` |
| 当日资金流动 | `#008080` |
| 其他指标 | `#8C7AC2` |

分类与字段表头使用相同底色，直接使用上表色值。

数据格默认使用白色底色，隔行叠加浅灰。绿色热力按数值从低到高使用无色、10%、20%、30%、40% 的绿色透明度；红色热力按数值从高到低使用无色、10%、15%、25%、35% 的红色透明度。各列以当前日行最小值、最大值等分五档；空值、全列相同值、汇总行不加热力底色。

## 2. 字段定义

日期 / 汇总：显示统计日期或总汇总、日均、月汇总标签；表头灰色 `#CCCCCC`，数据格白色，不占以下 87 项指标。

D 是统计日，D0 是批次当日。首充指首次成功充值，新充指注册当日充值，一级指无邀请上级。按相除计算的比例，分母为 0 或空时显示“—”。

LTV 的分子为注册批次净充值，分母为当日首充人数；留存按指定目标日计算。后续日期尚未到达时，仅反映已经发生的数据。

涉及消耗的成本、ROAS、ROI 及历史累计指标使用同一份消耗数据；使用占位消耗时，一并标注“模拟数据”。
