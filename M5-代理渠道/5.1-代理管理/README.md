# 5.1 · 代理管理

## 1. 用途
维护代理账号、层级关系、分佣配置。

## 2. 入口
菜单:代理渠道 → 代理 → 代理管理 · 跳入:用户详情「上级代理」

## 3. 字段清单

**筛选**:代理ID/账号 · 上级代理 · 层级 · 状态 · 注册时间
**表格列**:`序号 | 代理ID | 账号 | 上级 | 层级 | 下级人数 | 累计充值 | 累计佣金 | 状态 | 注册时间 | 操作`
**分佣配置**:分佣模式(RevShare/CPA/Hybrid)· 各口径比例 · 结算周期 · 最低提佣额 · 负余额结转开关

## 4. 需求清单

| ID | 需求 | 验收标准 | 权限码 | 人日 |
|---|---|---|---|---|
| 5.1-R1 | 代理列表 | 支持树形/平铺切换;显示层级、下级数、累计充值与佣金 | `agent:list:view` | 0.5 |
| 5.1-R2 | 代理详情 | 基本信息/下级列表/分佣配置/业绩四个 tab | `agent:list:view` | 0.5 |
| 5.1-R3 | 分佣配置 | 模式(RevShare/CPA/Hybrid)、各口径比例、结算周期、最低提佣、负余额结转开关 | `agent:config:edit` | 0.5 |
| 5.1-R4 | 启用/停用 | 二次确认;停用后不再产生新佣金,历史保留 | `agent:toggle` | 0.5 |

## 5. 状态清单
空 / 加载 / 错误 / 无权限 / 已停用(灰标)/ 有未结算佣金(提示)

## 6. 交互流程
**归属不可变**:代理-用户关系在注册时绑定,后台不提供改归属功能(改了历史佣金全乱)。

## 7. 涉及表
`Agent` `AgentUser` `AgentConfig`(owner)· 只读 `User`(M2) → `../表设计.prisma`

## 8. 关联页面
跳出:佣金结算(5.2)· 用户列表(M2.1)· 渠道管理(5.3)
