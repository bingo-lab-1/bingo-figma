# 5.3 · 渠道管理

## 1. 用途
维护流量渠道与推广链接,支撑归因与渠道报表。

## 2. 入口
菜单:代理渠道 → 渠道管理

## 3. 字段清单

**筛选**:渠道ID/名称 · 渠道类型 · 状态 · 创建时间
**渠道字段**:渠道名称* · 渠道编码* · 渠道类型(投放/自然/代理)· 推广员 · 落地域名 · 备注 · 状态
**表格列**:`序号 | 渠道编码 | 名称 | 类型 | 推广链接 | 注册数 | 首充数 | 累计充值 | 状态 | 创建时间 | 操作`

**推广链接**:自动生成,含渠道参数,支持复制与二维码

## 4. 需求清单

| ID | 需求 | 验收标准 | 权限码 | 人日 |
|---|---|---|---|---|
| 5.3-R1 | 渠道列表 | 显示编码/类型/注册数/首充数/累计充值 | `channel:list:view` | 0.5 |
| 5.3-R2 | 渠道 CRUD | 名称/编码/类型/推广员/落地域名可增删改;编码唯一 | `channel:edit` | 0.5 |
| 5.3-R3 | 推广链接生成 | 自动生成带渠道参数的链接,支持复制与二维码 | `channel:edit` | 0.5 |
| 5.3-R4 | 停用渠道 | 二次确认;停用后链接失效,已注册用户归属保留不变 | `channel:toggle` | 0.5 |

## 5. 状态清单
空 / 加载 / 错误 / 无权限 / 已停用(灰标,链接失效但历史归属保留)

## 6. 交互流程
**归因不可变**:用户注册时绑定渠道,之后不可改。停用渠道只影响新注册。

## 7. 涉及表
`Channel` `Promoter`(owner)· 只读 `Domain`(M8) → `../表设计.prisma`

## 8. 关联页面
跳出:代理管理(5.1)· 三方上报(5.4)· 渠道报表(M1.4)· 用户列表(M2.1,按渠道筛选)
