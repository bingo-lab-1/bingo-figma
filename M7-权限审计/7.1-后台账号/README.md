# 7.1 · 后台账号

## 1. 用途
管理运营人员的后台账号。**注意:这是 `Account`,不是玩家 `User`。**

## 2. 入口
菜单:权限审计 → 后台账号

## 3. 字段清单

**筛选**:账号 · 账号类型 · 角色 · 是否测试账号 · 状态 · 创建时间 · 最后登录时间

**账号字段**
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 账号 | text | ✅ | 唯一 |
| 密码 | password | ✅ | 新建时必填 |
| 角色 | multi-select | ✅ | 可多角色 |
| 账号类型 | select | ✅ | 平台运营 / 代理 / 客服 |
| **是否测试账号** | switch | — | ❌ 字段待新增,测试流水不进报表 |
| 备注 | textarea | — | |
| 状态 | switch | ✅ | 启用/禁用 |

**表格列**:`序号 | 账号 | 角色 | 类型 | 测试账号 | 状态 | 创建时间 | 最后登录 | 操作`

## 4. 需求清单

| ID | 需求 | 验收标准 | 权限码 | 人日 |
|---|---|---|---|---|
| 7.1-R1 | 账号列表与筛选 | 账号/类型/角色/测试标记/状态/时间筛选生效 | `system:account:view` | 0.5 |
| 7.1-R2 | 账号 CRUD | 账号唯一;可配多角色;写 `OperationLog` | `system:account:edit` | 0.5 |
| 7.1-R3 | 测试账号标记 | 新增 `isTestAccount` 字段;标记后其操作流水不进 M1 报表 | `system:account:edit` | 0.5 |
| 7.1-R4 | 安全约束 | 不允许删除/禁用当前登录账号;最后一个超管不可删 | `system:account:edit` | 0.5 |

## 5. 状态清单
空 / 加载 / 错误 / 无权限 / 已禁用(灰标)/ 测试账号(黄标)/ 不可删除(当前登录账号)

## 6. 交互流程
不允许删除/禁用自己;最后一个超管账号不可删。
