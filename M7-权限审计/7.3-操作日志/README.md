# 7.3 · 操作日志

## 1. 用途
记录所有后台写操作。**合规底线 —— 财务与活动配置的改动必须可追溯。**

## 2. 入口
菜单:权限审计 → 操作日志 · 跳入:各页面「操作记录」

## 3. 字段清单

**筛选**:操作者 · 模块 · 接口路径 · 接口描述 · 请求参数关键字 · 操作结果 · IP · 时间范围

**表格列**:`序号 | 时间 | 操作者 | 模块 | 接口描述 | 目标对象 | 结果 | IP | 耗时 | 操作`

**详情**:完整请求参数 · 变更前后 diff · UA · 响应码

> **必须记录的最小集**:操作者 / 时间 / 模块 / 接口 / 目标对象ID / 请求参数 / 变更前后 / IP / 结果

## 4. 需求清单

| ID | 需求 | 验收标准 | 权限码 | 人日 |
|---|---|---|---|---|
| 7.3-R1 | 日志列表与筛选 | 操作者/模块/路径/接口描述/参数关键字/结果/IP/时间筛选生效 | `system:log:view` | 0.5 |
| 7.3-R2 | 日志详情 | 展示完整请求参数与变更前后 diff;敏感字段脱敏 | `system:log:view` | 0.5 |

## 5. 状态清单
空 / 加载 / 错误 / 无权限 / 参数过大(折叠展开)

## 6. 交互流程
纯查询页。高频写入表,查询走时间范围索引。
