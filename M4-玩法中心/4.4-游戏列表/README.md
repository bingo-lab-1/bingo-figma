# 4.4 · 游戏列表与品牌

## 1. 用途
管理自研游戏与第三方厂商游戏的上下架、分类、基础属性。

## 2. 入口
菜单:玩法中心 → 游戏 → 游戏列表

## 3. 字段清单

**厂商(GamePlatform)**:厂商名称* · 厂商编码* · 接入方式 · 状态 · 排序
**游戏(SubGame)**:游戏名称* · 游戏编码* · 所属厂商* · 游戏类型(GameType)· 图标 · 是否热门 · 状态 · 排序 · RTP · 支持币种

**表格列**:`序号 | 图标 | 游戏名 | 编码 | 厂商 | 类型 | RTP | 热门 | 状态 | 排序 | 操作`

**自研游戏(8 款)**:dice / crash / limbo / plinko / roulette / mines / baccarat / blackjack

## 4. 需求清单

| ID | 需求 | 验收标准 | 权限码 | 人日 |
|---|---|---|---|---|
| 4.4-R1 | 厂商与游戏两级列表 | 左选厂商右显其游戏;分页正确 | `game:list:view` | 0.5 |
| 4.4-R2 | 游戏 CRUD | 名称/编码/类型/图标/RTP/支持币种/排序可增删改;编码唯一 | `game:list:edit` | 0.5 |
| 4.4-R3 | 厂商 CRUD | 名称/编码/接入方式/状态/排序可增删改 | `game:platform:edit` | 0.5 |
| 4.4-R4 | 上下架 | 二次确认显示当前在线玩家数;有进行中的局时阻断下架 | `game:list:toggle` | 0.5 |

## 5. 状态清单
空 / 加载 / 错误 / 无权限 / 已下架(灰标)/ 厂商维护中

## 6. 交互流程
下架前检查是否有进行中的局;厂商维护时批量禁用其下游戏。
