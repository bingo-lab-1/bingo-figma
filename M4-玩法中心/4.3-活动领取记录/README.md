# 4.3 · 活动领取记录

## 1. 用途
所有活动的发放流水。**对账与 ROI 核算的唯一数据源。**
统一一张表,替代竞品「每活动一张记录表」的做法。

## 2. 入口
菜单:玩法中心 → 活动 → 活动领取记录 · 跳入:用户详情「活动领取」· 活动配置「查看记录」

## 3. 字段清单

**筛选**:活动编码 · 活动分类 · 用户ID/账号 · 币种 · 金额区间 · 领取时间 · 渠道

**表格列**:`序号 | 领取时间 | 活动编码 | 活动名称 | 用户ID | 币种 | 发放金额 | 打码要求 | 打码状态 | 触发上下文 | 关联账变`

> **触发上下文**(`context` JSON):记录发放时的充值额/亏损额/VIP等级等,便于事后追溯"为什么发了这笔"

## 4. 需求清单

| ID | 需求 | 验收标准 | 权限码 | 人日 |
|---|---|---|---|---|
| 4.3-R1 | 领取流水列表 | 按领取时间倒序;分页与总数准确 | `game:claim:view` | 0.5 |
| 4.3-R2 | 7 项筛选 | 活动编码/分类/用户/币种/金额/时间/渠道均生效 | `game:claim:view` | 1 |
| 4.3-R3 | 汇总卡 | 显示所选范围的总发放额/领取人数/笔数 | `game:claim:view` | 0.5 |
| 4.3-R4 | 触发上下文展示 | 展开显示 `context` 快照(充值额/亏损额/VIP等),可追溯发放原因 | `game:claim:view` | 1 |
| 4.3-R5 | 关联跳转 | 点击关联账变跳 M2.2,点击打码状态跳 M3.7 | 继承目标页权限 | 0.5 |
| 4.3-R6 | 导出 | 按当前筛选导出;写日志 | `game:claim:export` | 0.5 |
