# 4.1 · 活动引擎配置

## 1. 用途
用一套通用配置表达所有活动。**目标:新增活动仅靠配置,不改 schema、不发版。**

## 2. 入口
菜单:玩法中心 → 活动 → 活动引擎配置

## 3. 字段清单

**① 基础**:活动编码* · 分类* · 名称*(≤20)· 侧边栏简称(≤10)· 启用开关
**② 资格圈人**:运营商/渠道 · 代理 · 用户标签 · VIP 区间(min/max)· 注册时间范围
**③ 时间周期**:重置类型(终身一次/每日/每周)· 是否循环 · 冷却天数 · 活动周期 · 重置时间 · 起止时间
**④ 奖励结构**(`rewardKind` 四态)
| 类型 | 表单形态 | 典型活动 |
|---|---|---|
| `TIER` 档位 | 表格:门槛→比例→打码倍数 | 账号首充 |
| `MATRIX` 矩阵 | 表格:VIP区间×金额区间×系数 | 红包雨 |
| `CALENDAR` 日历 | 表格:天→奖励→打码→存款/投注要求 | 每日签到 |
| `MILESTONE` 里程碑 | 表格:条件→要求→免费奖励/付费奖励 | 通行证 |

**⑤ 打码与限制**:打码倍数 · 每日领取次数 · 累计领取上限 · 最小/最高充值 · 强制最小充值开关
**⑥ 展示位**:Banner / 悬浮窗 / 侧边栏(引用 M6 的 ID)· 说明开关 · 参与说明 · 倒计时

## 5. 状态清单
空 / 加载 / 错误 / 无权限 / 草稿(未配全,进度条<100%)/ 已启用(部分字段锁定)/ 已过期
