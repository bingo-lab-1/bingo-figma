# 10.1 · 平台管理

## 1. 用途

运营在这里维护游戏平台资料。平台是子游戏的归属，新增子游戏时必须选择一个平台。

页面面向桌面端，界面为简体中文。名称固定填写英文、中文两种，都必填；列表显示简体中文内容；按中文或英文名称都能查到。

玩家端当前不读取本页字段。平台开关、维护开关、最低准入、宣传语、图标和排序只保存并在后台展示，不限制玩家进入游戏。系统预置的 Bingo 自营平台是玩家端自营游戏列表的来源，新增平台下的子游戏不进入该列表。

本页不提供批量操作、导入导出和修改历史查询。

## 2. 配置项

| 配置项 | 含义和填写规则 |
|---|---|
| 展示名称 | 文本，英文、中文都必填，不能只含空格 |
| 平台名称 | 文本，英文、中文都必填，不能只含空格 |
| 宣传语 | 文本，按语言选填 |
| 维护开关 | 开关，新增默认关闭 |
| 平台开关 | 开关，新增默认开启 |
| 图标 | 图片，必传 1 张 |
| 最低准入 | 非负数字，不带币种，整数部分最多 12 位，保留 8 位小数；留空按 0 保存 |
| 排序 | 非负整数，最大 2147483647；留空按 0 保存。列表不按此字段排序 |

列表按创建时间倒序，默认每页 20 条。

| 列表内容 | 规则 |
|---|---|
| 筛选：平台名称 | 输入后点“查询”生效，按包含关系匹配中文或英文平台名称，任一语言包含即返回；“清空筛选”清空条件并回到第 1 页 |
| 展示字段 | 平台ID、展示名称、平台名称、维护开关、平台开关、最低准入、宣传语、操作。开关显示“已开启”或“已关闭” |

筛选区默认展开全部条件。切换为选择模式后只显示已添加的条件，可用“添加筛选”增减；模式和已添加条件按后台账号保存在当前浏览器。没有已填写的条件时“清空筛选”不可用。

## 3. 操作规则

### 新增与编辑

点“添加平台”或行内“编辑”打开弹窗，保存成功后提示“保存成功”，关闭弹窗并刷新列表，修改立即生效。提交时缺多语言必填项，页面切到第一个出错的语言页签。

### 删除

行内“删除”需要二次确认。平台下没有子游戏，也没有玩家第三方钱包时才会被删除，删除不可撤销。

## 4. 特殊情况

| 情况 | 如何处理 |
|---|---|
| 必填项缺失或格式不符 | 不提交，在字段下提示；多语言字段出错时对应语言页签标红 |
| 保存失败 | 提示“保存失败”，弹窗和已填内容保留，可重试 |
| 删除仍有子游戏的平台 | 平台保留。确认弹窗关闭，列表刷新后该平台仍在，界面没有失败提示 |
| 删除已有玩家第三方钱包的平台 | 服务端拒绝，提示“操作失败，请检查输入或稍后重试”，平台保留，确认弹窗不关闭 |
| 无对应权限 | 按钮仍显示，提交后服务端拒绝并提示错误，数据不变 |
| 列表读取失败 | 显示错误信息和重试入口 |

## 5. 验收场景

| 需求编号 | 场景与操作 | 预期结果 |
|---|---|---|
| 10.1-R1 | 持有 `game:platform:create` 的账号填全各语言展示名称和平台名称，上传图标后保存 | 列表新增该平台，平台开关为已开启，维护开关为已关闭 |
| 10.1-R2 | 某一语言的平台名称留空后保存 | 不提交，切到该语言页签并提示“请输入平台名称” |
| 10.1-R3 | 未上传图标，或最低准入填负数，或排序填小数后保存 | 不提交，在对应字段提示错误 |
| 10.1-R4 | 分别用中文名称片段和只存在于英文名称的片段查询 | 两次都返回该平台 |
| 10.1-R5 | 删除没有子游戏和玩家钱包的平台 | 平台被删除，列表不再显示 |
| 10.1-R6 | 删除仍有子游戏的平台 | 平台保留，列表刷新后仍显示，子游戏不受影响 |
| 10.1-R7 | 关闭 Bingo 自营平台的平台开关，或开启维护开关 | 后台显示新状态，玩家端自营游戏列表和进入游戏不受影响 |
| 10.1-R8 | 没有 `game:platform:edit` 的账号提交编辑 | 服务端拒绝，平台资料不变 |
