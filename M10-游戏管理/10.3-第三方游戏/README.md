# 10.3 · 第三方游戏

## 1. 用途

运营在这里管理第三方供应商和游戏：启用供应商、同步目录、上架下架、调整展示顺序，并维护分类标签和游戏素材。页面标题为“第三方游戏管理”。新增“大盘 RTP”页签，按厂商维护普通用户的当前 RTP 和供应商同步状态。

当前通过聚合商 TopGames 接入，只支持 Slot 类型和 USD 钱包，连接配置只接受 dev 商户。连接未配置时，页面提示“供应商接口尚未配置，配置后可读取供应商并同步游戏目录。”，不能读取供应商或同步目录。

玩家端列表同时要求：第三方游戏已开启（环境开关，不在本页配置）、游戏已上架、所属供应商已启用、游戏属于 Slot。维护中的游戏仍显示，卡片标注 Under maintenance（中文界面“维护中”），不能启动。列表按展示排序升序，再按厂商和游戏名称排列。玩家启动游戏时，系统另外核对账号未封禁且 USD 钱包可用。

页面面向桌面端并兼容手机宽度，界面为简体中文，游戏名称沿用供应商目录的英文名称。

本版不提供：启动域名编辑（启停供应商时沿用原值）、手动注单核对、Call 沙盒测试、删除游戏、跨页批量操作。

## 2. 配置项

### 供应商

| 配置项 | 含义和填写规则 |
|---|---|
| 启用状态 | 启用或禁用，未启用过的供应商默认禁用。点击立即保存，影响玩家列表和启动。左侧供应商列表每行提供查看游戏、启用或禁用、设置三个操作，“设置”打开展示名称和图片的弹窗 |
| 展示名称 | 必填，最多 100 字符，未设置时取供应商名称。只在后台展示 |
| 供应商图片 | 选填，PNG、JPEG 或 WebP，最大 2 MB。只在后台展示 |
| 供应商顺序 | 点“修改供应商排序”后拖动调整，至少 2 家供应商时可用。玩家端按此顺序排列供应商，未排序的排在最后 |

### 大盘 RTP

| 配置项 | 含义和填写规则 |
|---|---|
| 厂商 RTP | 30–99 的整数；未配置时显示未配置，不猜测默认值 |
| 保存版本 | 乐观锁校验，过期版本拒绝覆盖 |
| 同步状态 | 区分配置已保存、待同步、已确认和核对中；接口受理不等于已生效 |

修改大盘仅同步未受控的用户／厂商范围，不覆盖已有养杀任务的快照。用户进入游戏时也确保当前厂商大盘同步。已有任务结束且无下一任务时通过单用户设置接口恢复最新大盘，不能用全用户重设接口覆盖其他任务。需要独立权限 `game:topgames:rtp:view/edit`；仅有大盘查看权限可访问此页签，不因此获得目录权限。实际供应商写入默认受能力验证门禁保护。养杀任务与标签规则见[点控策略](../../未落地需求/点控策略.md)。

### 分类与标签

分类与标签只用于后台筛选和整理，玩家端不展示。

| 配置项 | 含义和填写规则 |
|---|---|
| 分类 | 最多 100 个，名称 1～100 字符，忽略大小写不可重名。系统预置“未分类”“老虎机”，“未分类”必须保留 |
| 标签 | 最多 200 个，名称 1～100 字符，忽略大小写不可重名 |

### 游戏

| 配置项 | 含义和填写规则 |
|---|---|
| 上架状态 | 未上架或已上架，同步进来的游戏默认未上架 |
| 展示排序 | 十进制整数 0～1000000，默认 0，越小越靠前 |
| 游戏分类 | 单选，默认未分类 |
| 游戏标签 | 多选，最多 20 个 |
| 自定义封面 | 选填，PNG、JPEG 或 WebP，最大 2 MB，建议宽高比 110:148（如 440 × 592 px）。未设置时用第三方封面，都没有时玩家卡片显示游戏名称 |
| 自定义图标 | 选填，PNG、JPEG 或 WebP，最大 2 MB，宽高必须 1:1（如 512 × 512 px），边长不超过 4096 px，不支持动图。未设置时用第三方原图，玩家端当前不读取 |

### 筛选与列表

| 列表内容 | 规则 |
|---|---|
| 游戏范围 | “全部游戏”（默认）或“已上架游戏” |
| 筛选 | 游戏名称或编码（包含匹配，不区分大小写）、供应商、分类、标签、上架状态（未上架、已上架）、维护状态（正常、维护中）。点“查询”后同时生效；左侧供应商列表可按名称或代码搜索，点选供应商立即生效；“已上架游戏”下上架状态固定为已上架 |
| 展示字段 | 游戏（图标、名称、编码、自定义封面或图标标记）、供应商、分类与标签、上架状态、维护状态、展示排序、操作。操作列为上架或下架、编辑（分类与标签）、封面、图标 |
| 分页 | 默认每页 20 条，可选 10、20、50 |
| 排序 | “全部游戏”已上架在前再按名称；“已上架游戏”按展示排序、厂商、名称 |

筛选区默认展开全部条件。切换为选择模式后只显示已添加的条件，可用“添加筛选”增减；模式和已添加条件按后台账号保存在当前浏览器。没有已填写的条件时“清空筛选”不可用。

## 3. 操作规则

### 查看目录

- 未选供应商的“全部游戏”：查看已同步到平台的游戏，页面提示“查看全部已同步游戏目录”。
- 选了供应商的“全部游戏”：直接读取供应商最新目录，并合并平台已保存的状态，读取不写入平台，页面提示“读取供应商最新目录；维护中的游戏暂不可上架”。未同步的游戏排序列显示“同步或上架后可调整”。
- “已上架游戏”：只看平台已上架的游戏。

### 同步游戏目录

需要 `game:topgames:import`。选了供应商时只同步该供应商，未选时逐家同步全部供应商。全部成功时提示读取的游戏总数，有失败时汇总成功和失败家数。

同步按供应商目录更新名称、厂商、缩略图和维护状态。目录里新增的游戏默认未上架；目录里已消失的游戏标记为维护中，不删除。上架状态、展示排序、分类标签和自定义素材保持不变。

### 启用与禁用供应商

点击立即保存。禁用后，该供应商的游戏退出玩家列表且不能启动，已上架状态保留，后台标注“供应商已禁用”。重新启用后恢复。

### 上架与下架

- 单款上架：游戏须存在于供应商最新目录、属于 Slot、不在维护中，排序在允许范围内。后台界面要求先启用供应商；服务端受理时若供应商未启用，会在同一次保存里启用它。
- 批量上架：只能选当前页，每批 1～100 款；界面自动排除已上架、维护中或供应商已禁用的游戏。服务端逐款核对供应商目录，有一款不满足时整批不上架；受理时若供应商未启用，会在同一次保存里启用它。批量上架沿用游戏原排序。
- 下架：立即退出玩家列表且不能启动，单款和批量都不要求供应商状态。批量下架时有一款不在平台目录则整批不下架。

### 调整展示排序

点击排序值修改，只有已保存到平台的游戏可以调整，值未变化时不提交。保存成功后提示新值；该游戏不在当前页时可“查看游戏”定位，再“返回列表”恢复原筛选和页码。

### 分类、封面和图标

未同步的游戏也可以设置，只要它在供应商目录里；封面和图标保存时会把游戏写入平台，状态为未上架。清除自定义图片后恢复第三方图片。图标由服务端再次校验来源、大小、格式和 1:1 比例。

### 保存与留痕

本页的配置保存、同步、上架下架、排序、分类和素材修改都写入操作日志，保留修改前后的内容。配置、目录设置、供应商顺序和游戏分类都带版本号，保存时版本已变化则拒绝，不覆盖他人修改。

## 4. 特殊情况

| 情况 | 如何处理 |
|---|---|
| 启停或上架失败，或结果未成功确认 | 显示“请先读取最新配置”，暂停其他上架及左侧供应商的切换、启停、设置和排序，点“读取最新配置”后恢复 |
| 配置已被其他管理员修改 | 拒绝保存，提示刷新后重试，原数据不变 |
| 供应商排序保存失败 | 草稿保留，可重试，或“放弃草稿并读取最新排序” |
| 同一供应商 30 秒内重复同步 | 该供应商同步失败，计入失败家数，可稍后重新同步 |
| 同步中途失败 | 该供应商本次不写入，其他供应商继续 |
| 上架时游戏维护中或类型不支持 | 拒绝，提示“游戏维护中或类型暂不支持，无法上架”；批量上架时提示具体游戏和“本批未上架” |
| 游戏已不在供应商目录 | 拒绝，提示“供应商目录中不存在该游戏，请刷新后重试”；批量上架时提示缺失的游戏和“本批未上架” |
| 删除已被游戏使用的分类或标签 | 拒绝，提示“已有游戏使用该分类或标签，不能删除”，配置不变 |
| 图标不是 1:1、超过 2 MB、边长超过 4096 px、是动图或来源不是本站上传目录 | 拒绝，原图标不变，弹窗保留修改 |
| 只读账号（无 `game:topgames:edit`） | 可查看，勾选列隐藏，启停、排序、分类、封面、图标、上架下架全部不可用 |
| 账号只有 `game:topgames:edit`，没有通用上传权限 | 图片上传被拒绝，提示保存未成功确认；其余操作不受影响 |
| 部分数据读取失败 | 保留当前页面，提示“部分数据读取失败，已保留当前页面。”，可重新读取 |
| 游戏列表读取失败（含读取供应商目录失败） | 列表显示错误和“重试”，恢复前上架下架、排序、分类、封面、图标不可用 |
| 无符合条件的游戏 | 显示“没有符合条件的游戏”和“清除筛选” |

## 5. 验收场景

| 需求编号 | 场景与操作 | 预期结果 |
|---|---|---|
| 10.3-R1 | 连接未配置时打开页面 | 显示未配置提示，“同步游戏目录”不可用 |
| 10.3-R2 | 选中一家供应商执行同步，目录里有新游戏，并有一款已上架游戏从目录消失 | 新游戏为未上架；消失的游戏标记维护中，上架状态和排序不变 |
| 10.3-R3 | 启用供应商，上架一款未维护的 Slot 游戏并设排序值 | 后台显示已上架，玩家端列表按排序值显示该游戏 |
| 10.3-R4 | 维护中的游戏点击上架 | 按钮不可用，提示维护中的游戏暂不可上架 |
| 10.3-R5 | 已上架游戏进入维护 | 玩家端卡片标注 Under maintenance（中文界面“维护中”），不能启动 |
| 10.3-R6 | 禁用有已上架游戏的供应商 | 玩家端列表不再显示其游戏且不能启动，后台标注“供应商已禁用”；重新启用后恢复 |
| 10.3-R7 | 批量上架时其中一款已不在供应商目录 | 整批不上架，提示缺失的游戏，原状态不变 |
| 10.3-R8 | 排序值输入 1000001 或小数 | 不提交，提示“请输入 0–1000000 的十进制整数” |
| 10.3-R9 | 两名管理员基于同一版本保存配置 | 后保存者被拒绝，提示刷新后重试，先保存的内容保留 |
| 10.3-R10 | 删除已有游戏使用的标签，再删除未被使用的标签 | 前者拒绝且配置不变，后者保存成功 |
| 10.3-R11 | 上传非 1:1 图标 | 前端不提交；绕过前端时服务端拒绝 |
| 10.3-R12 | 设置自定义封面后清除 | 设置后玩家卡片用自定义封面，清除后恢复第三方封面 |
| 10.3-R13 | 只有 `game:topgames:view` 的账号打开页面 | 可查询，所有写操作不可用；直接提交写操作时服务端拒绝 |
