# 10.5 · 热门管理

## 1. 用途

运营在这里查看被标记为热门 1 或热门 2 的子游戏。本页只读，热门标记在 [10.2 子游戏管理](../10.2-子游戏管理/README.md) 修改。

页面面向桌面端，界面为简体中文，游戏名称、平台和类型显示繁体中文内容。玩家端当前不读取热门标记，本页结果不代表玩家端的展示内容。

## 2. 查询条件

| 条件 | 含义和填写规则 |
|---|---|
| 热门页签 | 热门1（默认）或热门2，切换后立即生效 |
| 所属平台 | 单选，留空不限 |
| 游戏类型 | 单选，留空不限 |
| 游戏名称 | 按包含关系匹配繁体中文名称，留空不限 |

平台、类型和名称点“查询”后同时生效，“清空筛选”清空并回到第 1 页。

筛选区默认展开全部条件。切换为选择模式后只显示已添加的条件，可用“添加筛选”增减；模式和已添加条件按后台账号保存在当前浏览器。没有已填写的条件时“清空筛选”不可用。

## 3. 结果字段

| 字段 | 含义 |
|---|---|
| 排序 | 子游戏的排序值。列表不按此字段排列 |
| 游戏ID | 子游戏 ID |
| 游戏类型 | 类型名称，缺失显示“-” |
| 所属平台 | 平台展示名称，为空时用平台名称，缺失显示“-” |
| 游戏名称 | 子游戏名称 |
| 游戏开关 | 已开启或已关闭 |

## 4. 操作规则

列表按创建时间倒序，默认每页 20 条。本页没有新增、编辑、删除、导出和排序调整，读取失败时显示错误信息和重试入口。

本页入口由 `game:hot:view` 控制，列表数据需要 `game:sub-game:view`，筛选项分别需要 `game:platform:view`、`game:type:view`。缺少这些读取权限时页面能打开，但对应数据读取失败或选项为空。

## 5. 验收场景

| 需求编号 | 场景与操作 | 预期结果 |
|---|---|---|
| 10.5-R1 | 打开页面 | 默认显示热门1页签，只列出热门1已开启的子游戏 |
| 10.5-R2 | 切到热门2页签 | 只列出热门2已开启的子游戏；两个标记都开启的子游戏在两个页签都出现 |
| 10.5-R3 | 组合选择平台、类型并输入繁体中文名称片段后查询 | 只返回同时满足条件的子游戏 |
| 10.5-R4 | 在 10.2 关闭某子游戏的热门1后回到本页 | 该子游戏不再出现在热门1页签 |
| 10.5-R5 | 账号只有 `game:hot:view` | 页面可打开，列表读取失败并显示错误，不泄露子游戏数据 |
| 10.5-R6 | 账号没有 `game:hot:view` | 菜单不显示，直接访问进入无权限页 |

## 6. 相关资料

- 入口：游戏管理 → 热门管理。
- 权限：页面入口 `game:hot:view`；列表 `game:sub-game:view`；筛选项 `game:platform:view`、`game:type:view`。
- 数据归属：热门标记属于子游戏，由 [10.2](../10.2-子游戏管理/README.md) 维护，本页只读。
