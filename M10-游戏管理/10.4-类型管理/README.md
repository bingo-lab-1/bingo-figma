# 10.4 · 类型管理

## 1. 用途

运营在这里维护游戏类型字典。新增或编辑子游戏时必须选择一个类型。

页面面向桌面端，界面为简体中文。类型名称按已启用语言分别填写，列表显示繁体中文内容。

玩家端当前不读取类型。开关和排序只保存并在后台展示；关闭类型不影响已绑定的子游戏，也不影响玩家进入游戏。本页不提供批量操作、导入导出和修改历史查询。

## 2. 配置项

| 配置项 | 含义和填写规则 |
|---|---|
| 类型名称 | 文本，每个已启用语言必填，不能只含空格 |
| 排序 | 非负整数，必填，最大 2147483647，默认 0。列表不按此字段排序 |
| 是否开启 | 开关，新增默认开启 |
| 图标 | 图片，必传 1 张 |

列表按创建时间倒序，默认每页 20 条。

| 列表内容 | 规则 |
|---|---|
| 筛选 | 类型名称按包含关系匹配繁体中文名称；开关可选已开启、已关闭。点“查询”后同时生效，“清空筛选”清空并回到第 1 页 |
| 展示字段 | 类型ID、类型名称、开关、图标、排序、操作 |

筛选区默认展开全部条件。切换为选择模式后只显示已添加的条件，可用“添加筛选”增减；模式和已添加条件按后台账号保存在当前浏览器。没有已填写的条件时“清空筛选”不可用。

## 3. 操作规则

### 新增与编辑

点“添加类型”或行内“编辑”打开弹窗，保存成功后提示“保存成功”，关闭弹窗并刷新列表，修改立即生效。提交时缺名称，页面切到第一个出错的语言页签。

### 删除

行内“删除”需要二次确认。类型下没有子游戏时才能删除，删除不可撤销。

## 4. 特殊情况

| 情况 | 如何处理 |
|---|---|
| 必填项缺失或格式不符 | 不提交，在字段下提示；名称出错时对应语言页签标红 |
| 删除仍有子游戏的类型 | 服务端拒绝，提示“操作失败，请检查输入或稍后重试”，类型保留，确认弹窗不关闭 |
| 关闭仍有子游戏的类型 | 允许保存，子游戏保持绑定，[10.2](../10.2-子游戏管理/README.md) 的类型下拉仍可选择 |
| 保存失败 | 提示“保存失败”，弹窗和已填内容保留，可重试 |
| 无对应权限 | 按钮仍显示，提交后服务端拒绝并提示错误，数据不变 |
| 列表读取失败 | 显示错误信息和重试入口 |

## 5. 验收场景

| 需求编号 | 场景与操作 | 预期结果 |
|---|---|---|
| 10.4-R1 | 填全各语言名称、排序并上传图标后保存 | 列表新增该类型，开关为已开启 |
| 10.4-R2 | 某语言名称留空，或未上传图标后保存 | 不提交，在对应字段提示 |
| 10.4-R3 | 排序留空或填负数后保存 | 不提交，提示排序格式错误 |
| 10.4-R4 | 开关筛选选“已关闭”后查询 | 只返回已关闭的类型 |
| 10.4-R5 | 按繁体中文名称片段查询 | 返回名称包含该片段的类型 |
| 10.4-R6 | 关闭有子游戏的类型 | 保存成功，子游戏和玩家端不变 |
| 10.4-R7 | 删除没有子游戏的类型 | 类型被删除，列表不再显示 |
| 10.4-R8 | 删除仍有子游戏的类型 | 服务端拒绝，类型和子游戏不变 |
| 10.4-R9 | 没有 `game:type:delete` 的账号确认删除 | 服务端拒绝，类型不变 |

## 6. 相关资料

- 入口与关联页面：游戏管理 → 类型管理。类型绑定在 [10.2 子游戏管理](../10.2-子游戏管理/README.md) 维护。
- 权限：查看 `game:type:view`，新增 `game:type:create`，编辑 `game:type:edit`，删除 `game:type:delete`。上传图标和读取语言列表由新增、编辑权限带出。
- 数据与责任：类型字典归 M10，语言列表由内容管理提供。
- 共用规则：[权限模型](../../M6-账号管理/6.2-角色管理/权限模型.md)。
