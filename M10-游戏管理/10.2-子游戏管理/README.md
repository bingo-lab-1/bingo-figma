# 10.2 · 子游戏管理

## 1. 用途

运营在这里维护子游戏：名称、归属平台与类型、玩家进入路径、开关、Banner 和氛围颜色。

本页决定玩家端能看到哪些自营游戏。Casino 和玩家首页 Casino Games 均读取 Bingo 自营平台下游戏开关已开启的子游戏；玩家打开游戏页时，系统按路径核对游戏开关。

页面面向桌面端，界面为简体中文。子游戏名称固定填写英文、中文两种，都必填；列表显示简体中文内容；按中文或英文名称都能查到；玩家端按当前界面语言显示。

热门 1、热门 2、公司 ID 和游戏平台 ID 只保存，玩家端不读取。本页不提供批量操作、导入导出和修改历史查询。

## 2. 配置项

| 配置项 | 含义和填写规则 |
|---|---|
| 子游戏名称 | 文本，英文、中文都必填，不能只含空格 |
| 游戏平台 | 必选，选项来自 [10.1](../10.1-平台管理/README.md) |
| 游戏类型 | 必选，选项来自 [10.4](../10.4-类型管理/README.md)，已关闭的类型也可选 |
| 公司 ID | 文本必填，保存时去首尾空格 |
| 子游戏路径 | 文本必填，保存时去首尾空格。玩家点击卡片时跳转到此路径，系统不校验重复 |
| 游戏平台 ID | 文本选填 |
| 排序 | 非负整数，最大 2147483647；留空按 0 保存。玩家列表按排序升序，相同时后创建的在前 |
| 游戏开关 | 开关，新增默认开启；弹窗中显示为“平台开关”。关闭后的处理见[对玩家的影响](#对玩家的影响) |
| 维护开关 | 开关，新增默认关闭。开启后游戏仍在列表中并显示“维护中”，不能开新局 |
| 热门 1、热门 2 | 两个独立开关，新增默认关闭，在 [10.5](../10.5-热门管理/README.md) 查询 |
| Banner | 图片选填，最多 3 张。玩家卡片使用第一张，列表“宣传图”也显示第一张 |
| 氛围颜色 | 颜色，默认 `#1677ff`，提供 8 个预设色，也可自选。用作玩家卡片的底部渐变色 |

列表按创建时间倒序，默认每页 20 条，不按“排序”排列。

| 列表内容 | 规则 |
|---|---|
| 筛选 | 所属平台、游戏类型单选；游戏名称按包含关系匹配中文或英文名称，任一语言包含即返回。点“查询”后同时生效，“清空筛选”清空并回到第 1 页 |
| 展示字段 | 排序、平台名称、游戏ID、游戏名称、游戏类型、热门1、热门2、维护开关、氛围颜色、游戏开关、宣传图、操作。热门1、热门2显示“是”或“否”；氛围颜色、宣传图未设置时显示“-” |

筛选区默认展开全部条件。切换为选择模式后只显示已添加的条件，可用“添加筛选”增减；模式和已添加条件按后台账号保存在当前浏览器。没有已填写的条件时“清空筛选”不可用。

## 3. 操作规则

### 新增与编辑

点“添加子游戏”或行内“编辑”打开弹窗，保存成功后提示“保存成功”，关闭弹窗并刷新列表，修改立即生效。提交时缺多语言名称，页面切到第一个出错的语言页签。

### 对玩家的影响

- 游戏开关关闭后，子游戏退出玩家端列表，玩家直接打开该游戏页看到 404 页面，页面文字为 Something Went Wrong，提供 Go Home 按钮。Crypto Futures 和德州扑克的侧边栏入口随开关隐藏。
- 游戏开关关闭后不能开新局。关闭时已经在进行的，按游戏处理：

  | 游戏 | 关闭时已经在进行的 |
  |---|---|
  | Mines、Blackjack、Crash | 这一局作废，投注原路退回：本金出的回本金，彩金出的回彩金，打码进度不变。已经翻开格子、已经起飞的局同样只退投注，不按当前倍数派彩。Blackjack 的加倍、分牌和保险随主注一起退回 |
  | 德州扑克 | 正在进行的一手打完，之后不再发牌 |
  | Crypto Futures | 不能开新仓，已有仓位仍可管理和平仓 |
  | 其余自营游戏 | 下注即结算，没有进行中的局 |

- 退回的时点：玩家继续操作这一局时立即退回，并提示游戏已关闭；玩家不再操作时，Mines、Blackjack 约 1 分钟内退回，Crash 约 1 秒内退回。Crash 排队等下一局的注单一并作废，不扣款。退回后玩家的投注记录显示“已退款”，账变记录原因为“投注退款”。
- 维护开关开启后不能开新局，进行中的局可以打完，不退回投注。
- 所属平台的平台开关、维护开关对其下每个子游戏同样生效：任一处关闭即按关闭处理，任一处开启维护即按维护处理。
- 关闭游戏开关时的确认弹窗按上表说明进行中的局如何处理。
- 玩家打开的路径没有对应子游戏时，系统逐级按上级路径查找；都找不到时视为未开放，显示 404 页面。
- 只有 Bingo 自营平台下的子游戏进入玩家端列表。其他平台下的子游戏不进入列表，但路径匹配的游戏页仍按游戏开关判断。

### 删除

行内“删除”需要二次确认，子游戏立即彻底删除，不可撤销。删除后玩家端按路径不存在处理。删除不等于关闭：进行中的局不会退回，仍可打完。需要退回时先关闭游戏开关，等进行中的局退回后再删除。

## 4. 特殊情况

| 情况 | 如何处理 |
|---|---|
| 必填项缺失或格式不符 | 不提交，在字段下提示；名称出错时对应语言页签标红 |
| 账号没有 `game:platform:view` 或 `game:type:view` | 筛选和弹窗的平台、类型下拉没有选项，无法完成新增；列表仍显示已有数据 |
| 两个子游戏使用同一路径 | 系统不拦截。运营须保持路径唯一，否则游戏页按其中一条记录判断开关 |
| 关闭后很快又重新开启 | 还没退回的局继续有效，可以打完 |
| 读取开关失败 | 不退回任何投注，待下一次读取成功再判断；Crash 排队等下一局的注单仍作废 |
| 某一局的投注退回失败 | 该局保持原状并自动重试，不影响其他局；Blackjack 一局的多笔投注要么全部退回，要么都不退 |
| 保存失败 | 提示“保存失败”，弹窗和已填内容保留，可重试 |
| 无对应权限 | 按钮仍显示，提交后服务端拒绝并提示错误，数据不变 |
| 列表读取失败 | 显示错误信息和重试入口 |

## 5. 验收场景

| 需求编号 | 场景与操作 | 预期结果 |
|---|---|---|
| 10.2-R1 | 在 Bingo 自营平台下新增子游戏，填全必填项并保留游戏开关开启 | 列表新增该记录，玩家端自营游戏列表出现该游戏 |
| 10.2-R2 | 在其他平台下新增子游戏 | 后台列表显示，玩家端自营游戏列表不显示 |
| 10.2-R3 | 关闭已上线子游戏的游戏开关 | 玩家端列表不再显示，直接打开该游戏页显示 404 页面 |
| 10.2-R4 | 开启子游戏的维护开关 | 玩家端列表仍显示该游戏并标“维护中”，不能开新局，进行中的局可以打完 |
| 10.2-R5 | 修改排序值后查看玩家端列表 | 玩家列表按排序升序；后台列表仍按创建时间倒序 |
| 10.2-R6 | 公司 ID、子游戏路径或某语言名称留空后保存 | 不提交，在对应字段提示 |
| 10.2-R7 | 上传第 4 张 Banner | 上传数量限制在 3 张 |
| 10.2-R8 | 分别按中文、英文名称片段，与所属平台和游戏类型组合查询 | 两次都只返回同时满足条件的子游戏 |
| 10.2-R9 | 删除子游戏 | 记录消失，玩家端列表不再显示，打开原路径显示 404 页面 |
| 10.2-R10 | 没有 `game:sub-game:edit` 的账号提交编辑 | 服务端拒绝，子游戏不变 |
| 10.2-R11 | Mines 一局用彩金投注 1 USD 并已翻开一格，此时关闭游戏开关，玩家点兑现 | 提示游戏已关闭；1 USD 回到彩金，本金和打码进度不变；投注记录显示“已退款”，没有派彩 |
| 10.2-R12 | Blackjack 一局含主注和保险两笔投注，关闭游戏开关后玩家不再操作 | 约 1 分钟内两笔投注全部退回，各退一次 |
| 10.2-R13 | Crash 一局飞行中有未兑现的投注，另有排队等下一局的注单，此时关闭游戏开关 | 约 1 秒内未兑现的投注退回，排队注单作废且未扣款；此前已兑现、已爆掉的注单不变；之后手动兑现提示游戏已关闭 |
| 10.2-R14 | 游戏在维护中，或热门标记变化 | 进行中的局不退回 |

## 6. 相关资料

- 入口与关联页面：游戏管理 → 子游戏管理。平台见 [10.1](../10.1-平台管理/README.md)，类型见 [10.4](../10.4-类型管理/README.md)，热门标记查询见 [10.5](../10.5-热门管理/README.md)。
