# M10 · 游戏管理

## 1. 定位与边界

**做什么**：维护后台游戏目录。自营游戏侧管理平台、类型和子游戏，并查看子游戏的热门标记；第三方游戏侧管理供应商启用、目录同步、游戏上架、展示排序、分类标签和封面图标。

**不做什么**
- 不做玩法、赔率、注单结算和有效投注（玩法，**本仓库范围外**）；投注查询归 [2.3 投注明细](../M2-会员管理/2.3-投注明细/README.md)。
- 不做第三方游戏的钱包回调与资金入账。第三方投注和派彩进入统一 USD 账本，资金语义归 [资金模型](../M2-会员管理/2.1-会员列表/资金模型.md)。
- 不做第三方注单对账界面。对账由系统后台定时执行，本模块页面不提供入口。
- 不配置投注折算比例。本模块五个页面都没有这项配置。
- 不做游戏统计。菜单中的“游戏统计”是占位页，没有业务内容，只有系统角色能打开，因此不登记页面。

**铁律**
- **权限判定在服务端**。10.1、10.2、10.4 不按权限隐藏按钮，无权限操作由服务端拒绝。
- **保存成功不等于玩家可见**。自营游戏里，玩家端只读取 Bingo 自营平台下的子游戏；每个配置项是否影响玩家，以页面配置项的说明为准。

## 2. 术语表

| 术语 | 定义 | 代码标识 |
|---|---|---|
| 游戏平台 | 子游戏的归属平台，也是玩家第三方平台钱包引用的对象 | 游戏平台 |
| Bingo 自营平台 | 系统预置的平台，平台 ID 固定。玩家端首页和 Casino 的自营游戏列表只读取它下面的子游戏 | 游戏平台（预置） |
| 子游戏 | 平台下的一款游戏，带路径、Banner 和游戏开关 | 子游戏 |
| 游戏开关 | 子游戏是否对玩家开放。列表显示“游戏开关”，编辑弹窗显示“平台开关”，是同一字段 | 子游戏.开关 |
| 游戏类型 | 子游戏的分类字典 | 游戏类型 |
| 热门 1、热门 2 | 子游戏上的两个独立标记，当前只供 10.5 查询 | 子游戏.热门标记 |
| 第三方供应商 | 聚合商 TopGames 下的游戏厂商，用供应商代码识别 | 供应商代码 |
| 上架 | 第三方游戏进入平台目录。玩家可见还要求所属供应商已启用 | 第三方游戏.上架状态 |
| 展示排序 | 第三方游戏的排序值，0～1000000，越小越靠前 | 第三方游戏.排序 |
| 同步游戏目录 | 把供应商当前目录写入平台，不改变上架状态和展示排序 | — |

**下游被依赖（谁引用我）** ← 改目录结构前先看这行
