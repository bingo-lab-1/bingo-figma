# 6.1 · 站内信

## 1. 用途
向玩家发送站内消息(公告、活动通知、个人消息)。

## 2. 入口
菜单:运营管理 → 站内信 · 跳入:用户详情「发送消息」

## 3. 字段清单

**筛选**:标题 · 消息类型 · 发送状态 · 发送时间
**消息字段**
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 标题 | text(多语言) | 是 | |
| 正文 | 富文本(多语言) | 是 | |
| 消息类型 | select | 是 | 公告 / 活动 / 个人 |
| 接收对象 | radio | 是 | 全体 / 按标签 / 指定用户 |
| 用户标签 | multi-select | — | 按标签时必填 |
| 指定用户 | textarea | — | 指定时必填,一行一个ID |
| 发送时间 | datetime | — | 空=立即 |
| 附带奖励 | — | — | 否 · 是否支持待定 |

**表格列**:`序号 | 标题 | 类型 | 接收对象 | 触达人数 | 已读率 | 状态 | 发送时间 | 操作`

## 4. 需求清单

| ID | 需求 | 验收标准 | 权限码 | 人日 |
|---|---|---|---|---|
| 6.1-R1 | 消息列表 | 显示标题/类型/接收对象/触达人数/已读率/状态 | `ops:notification:view` | 0.5 |
| 6.1-R2 | 消息编辑 | 标题与正文支持多语言;类型必选 | `ops:notification:edit` | 0.5 |
| 6.1-R3 | 接收对象选择 | 全体/按标签/指定用户三选一;选标签时联动 M2.5 | `ops:notification:edit` | 0.5 |
| 6.1-R4 | 发送与定时 | 二次确认显示触达人数;定时任务按设定时间发送 | `ops:notification:send` | 0.5 |

## 5. 状态清单
空 / 加载 / 错误 / 无权限 / 草稿 / 待发送(定时)/ 发送中 / 已发送(只读)/ 已撤回

## 6. 交互流程
草稿 → 待发送 → 发送中 → 已发送。全体消息异步分发,显示进度。

## 7. 涉及表
站内信(owner)· 多语言(owner)· 只读 用户标签(M2)

## 8. 关联页面
跳出:用户标签(M2.5)· 多语言(6.6)
