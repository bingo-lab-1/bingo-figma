# M6 · 运营管理

## 1. 定位与边界

**做什么**:面向玩家的内容位与消息触达。

**不做什么**
- ❌ 不含活动逻辑 —— 展示位只**引用**活动 ID,活动规则在 M4
- ❌ 不做用户分层 —— 定向用 M2 的 `UserTag`,本模块不自建标签
- ❌ 不做客服工单系统(仅意见反馈收集)

**铁律**:**活动与展示解耦** —— 展示位引用活动 ID,不复制活动逻辑。

## 2. 术语表

| 术语 | 定义 | 代码标识 |
|---|---|---|
| 展示位 | 首页 Banner / 悬浮窗 / 侧边栏 | `Banner` |
| 弹窗 | 覆盖式提示,有触发策略 | `Popup` |
| 频控 | 同一用户弹窗次数限制 | `frequency` |
| 次留弹窗 | 次日留存召回弹窗 | — |
| 兑换码 | 可核销的奖励码 | `RedeemCode` |

## 3. 依赖关系

**上游依赖(我引用)**
- `M2-用户管理`:`UserTag` `VipLevel`(弹窗/推送定向)
- `M4-玩法中心`:`Activity.id`(展示位跳转目标,**元数据引用**)

**下游被依赖(谁引用我)**
- `M4-玩法中心`:活动配置引用 `bannerId` / `floatWindowId` / `sidebarId`
