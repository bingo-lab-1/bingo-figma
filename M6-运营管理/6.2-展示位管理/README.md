# 6.2 · 展示位管理

## 1. 用途
管理首页 Banner、悬浮窗、侧边栏等展示位。**活动与展示解耦的落点。**

## 2. 入口
菜单:运营管理 → 展示位 → 展示位管理 · 跳入:活动配置「前往 Banner 配置」

## 3. 字段清单

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 展示位 | select | 是 | 首页Banner / 悬浮窗 / 侧边栏 |
| 标题 | text(多语言) | 是 | |
| 图片 | upload(多语言) | 是 | 尺寸随展示位 |
| 跳转类型 | select | 是 | 活动 / 游戏 / 外链 / 无 |
| **跳转目标** | select/text | — | 活动时选 活动标识(引用 M4) |
| 排序 | number | 是 | |
| 启用 | switch | 已有 | |
| 生效时间 | daterange | — | 空=长期 |

**列表列**:`排序 | 缩略图 | 标题 | 跳转类型 | 目标 | 启用 | 生效时间 | 操作`

## 4. 需求清单

| ID | 需求 | 验收标准 | 权限码 | 人日 |
|---|---|---|---|---|
| 6.2-R1 | 按位置分 tab | 首页Banner/悬浮窗/侧边栏三个 tab,各自独立列表 | `ops:banner:view` | 0.5 |
| 6.2-R2 | 展示位 CRUD | 标题与图片支持多语言;尺寸按位置校验 | `ops:banner:edit` | 1.5 |
| 6.2-R3 | 跳转配置 | 类型选活动时下拉列出启用中的活动并存其 ID | `ops:banner:edit` | 1 |
| 6.2-R4 | 拖拽排序 | 拖拽即时保存;同位置排序值唯一 | `ops:banner:edit` | 1 |
| 6.2-R5 | 生效时间 | 未到时间不展示;过期自动下线 | `ops:banner:edit` | 0.5 |
| 6.2-R6 | 引用有效性告警 | 引用的活动已下线时列表标黄警告;删除前检查被引用 | `ops:banner:edit` | 1 |
| 6.2-R7 | 预览 | 编辑时可预览各语言在对应位置的效果 | `ops:banner:view` | 0.5 |

## 5. 状态清单
空(该位置无内容)/ 加载 / 错误 / 无权限 / 未生效(未到时间)/ 已过期 / **引用的活动已下线(警告)**

## 6. 交互流程
选择「跳转类型=活动」时,下拉列出启用中的活动;**活动下线时展示位需给出警告**(引用有效性)。

## 7. 涉及表
展示位(owner,新增)· 素材(owner)· 只读 活动(M4,仅引用来源标识)

## 8. 关联页面
跳出:活动引擎(M4.1)· 素材中心(6.3)· 弹窗策略(6.4)
