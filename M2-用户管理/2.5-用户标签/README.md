# 2.5 · 用户标签

## 1. 用途
维护标签体系并给玩家打标。**标签是活动圈人和风控定向的基础设施。**

## 2. 入口
菜单:用户管理 → 用户标签 · 跳入:用户详情「标签」

## 3. 字段清单

**标签字段**
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 标签名称 | text | 是 | |
| 标签分组 | select | — | 运营/风控/VIP |
| 颜色 | color | — | 列表展示用 |
| 描述 | textarea | — | **说明这个标签什么时候打** |
| 是否自动打标 | switch | — | 待办 · 规则引擎待定 |

**标签列表列**:`标签名 | 分组 | 用户数 | 描述 | 创建人 | 创建时间 | 操作`

## 4. 需求清单

| ID | 需求 | 验收标准 | 权限码 | 人日 |
|---|---|---|---|---|
| 2.5-R1 | 标签 CRUD | 名称/分组/颜色/描述可增删改;名称唯一 | `user:tag:manage` | 1 |
| 2.5-R2 | 标签下用户列表 | 选中标签右侧显示其用户,分页正确 | `user:tag:view` | 0.5 |
| 2.5-R3 | 打标/移除 | 单个用户增删标签即时生效 | `user:tag:edit` | 0.5 |
| 2.5-R4 | 删除保护 | 删除前提示影响用户数,并列出引用它的活动/弹窗,有引用则阻断 | `user:tag:manage` | 0.5 |

## 5. 状态清单
空(无标签)/ 加载 / 错误 / 无权限 / 标签下无用户 / 批量选中

## 6. 交互流程
纯 CRUD。删除标签前必须提示影响的用户数和引用它的活动。

## 7. 涉及表
`Tag` `UserTag`(owner)→ `../表设计.prisma`

## 8. 关联页面
跳出:用户列表(2.1)· 活动引擎(M4.1,标签用于圈人)· 弹窗策略(M6.4)
