# 2.1 · 用户列表与详情

<a id="1-背景与目标"></a>

## 1. 用途

客服、运营和财务通过这张列表查找会员,查看账号、标签及充提汇总,再打开详情处理具体问题。网站中的页面名称为“会员列表”。

列表提供查询、分页、查看详情和设置测试账号。详情里的资料修改、钱包和打码操作统一见[用户详情弹窗](用户详情弹窗.md)。本文按当前网页整理,观察结果和实现差异见[网站核对记录](../../.artifacts/user-list-prd-2026-09-11/README.md)。

适用于简体中文桌面后台。会员账号、用户名等内容按原文展示。列表金额以 USD 展示,时间按浏览器本地时区展示及生成查询边界;顶部时区选项不代表本列表会随之换算。

<a id="4-关键参数与规则"></a>

## 2. 查询条件

提供以下 13 组条件。各组之间共同生效;用户维度只选一种,时间维度也只选一种。

| 条件 | 填写与查询规则 |
|---|---|
| 用户 | 选择会员 ID、会员账号或用户名,默认会员 ID;关键词去首尾空格后精确匹配,留空不限 |
| 渠道 | 可搜索、可清空的单选框,显示渠道名称;留空不限渠道 |
| 在线状态 | 全部、在线、离线,默认全部;判定见 A5 |
| 提现绑定手机 | 按输入手机号精确匹配,去首尾空格;当前实际查询的是会员档案的手机号,不另查提现账号中的手机 |
| VIP 等级 | 输入等级 ID,留空不限;这里不是输入等级序号或选择等级名称的下拉框 |
| 用户标签 ID | 输入一个或多个标签 ID,多个用英文逗号分隔,分别去除首尾空格;命中其中任一标签即可,留空不限 |
| 账号状态 | 全部、正常、封禁,默认全部 |
| 注册 IP | 去首尾空格后精确匹配注册 IP 记录 |
| 注册平台 | 全部、网页、PWA、APK,默认全部;按该会员最早登录记录中的客户端类型筛选 |
| 是否充值 | 全部、是、否,默认全部;按资金汇总中的充值次数大于 0 或等于 0 判断 |
| 充值金额下限（USD） | 累计充值金额大于或等于输入值;可只填下限 |
| 充值金额上限（USD） | 累计充值金额小于或等于输入值;可只填上限 |
| 时间 | 选择不限、注册时间、最后登录时间、首充时间、最后存款时间或最后投注时间,搭配一个日期范围;默认见 A1 |

金额条件始终查询累计充值汇总。日期条件筛选会员的相应时间,不会把列表的充值总额改成这段期间内的充值额。

例如,选择“注册时间为本月”并填写“充值金额下限 1000”,查到的是本月注册且累计充值达到 1000 USD 的会员。

### 默认范围与分页

| 编号 | 规则 |
|---|---|
| A1 | 未指定查询条件时,按注册时间查询:从当前日期前 90 天的零点到今天结束,包含首尾两天;不是不限时间 |
| A2 | 默认第 1 页、每页 20 条;可选 10、20、50 条 |
| A3 | 进入页面自动查询。修改条件后需点击“查询”才应用,按回车不提交 |
| A5 | 查询时,在线标记为在线或最后在线时间在最近 5 分钟内的会员算在线;离线需在线标记为否,且最后在线为空或早于该窗口。列表展示本次查询结果,不持续刷新各行 |

例如,浏览器本地日期为 2026-09-11 时,默认查询 2026-06-13 00:00 至 2026-09-11 23:59:59.999。

### 日期选择与时间含义

日期面板展示两个月。点击第一个日期开始选择,第二个日期完成范围并收起;反向选择时按先后排列。没有快捷日期预设或独立的确定、取消、清除页脚。需要完整两端才作为一个日期范围查询。

| 时间维度 | 查询的事实 |
|---|---|
| 注册时间 | 会员注册时间 |
| 最后登录时间 | 会员最后在线时间,与同名结果列一致;不是单次登录事件的时间 |
| 首充时间 | 充值到账类账变的最早时间 |
| 最后存款时间 | 充值到账类账变的最晚时间 |
| 最后投注时间 | 会员投注记录的最晚创建时间 |

日期查询包含起始日零点和结束日最后一刻。“不限”选项的切换问题已在核对记录中记录;不限制时间的查询链接可以执行相应查询。

## 3. 结果字段

每行一个会员,固定按注册时间倒序展示。共 19 列,操作列固定在右侧,表格可以横向滚动。

| 字段 | 含义与展示 |
|---|---|
| 会员 ID | 会员的字符串标识;详情入口要求见下文 R4,当前 ID 点击差异见核对记录 |
| 会员账号 | 会员保存的账号;测试账号在旁边显示“测试”标记 |
| 用户名 | 会员保存的用户名,与会员账号分别展示 |
| 邮箱 | 会员保存的邮箱 |
| 真实姓名 | 会员保存的真实姓名,缺失显示“-” |
| 手机号 | 会员档案的手机号,缺失显示“-” |
| 推广渠道 | 渠道名称,缺失显示“-” |
| 会员标签 | 当前关联的标签;最多直接显示两个,其余用“+N”折叠,浮层可查看全部 |
| 账号状态 | 正常或封禁 |
| 在线状态 | 在线或离线,按 A5 展示 |
| VIP 等级 | 根据等级 ID 展示等级名称,没有可展示等级时显示“-” |
| 注册时间 | 浏览器本地时间,格式为年-月-日 时:分:秒 |
| 充值次数 | 资金服务保存的累计充值次数,缺失按 0 展示 |
| 充值总额 | 资金服务保存的累计 USD 充值金额 |
| 提现次数 | 资金服务保存的累计提现次数,缺失按 0 展示 |
| 提现总额 | 资金服务保存的累计 USD 提现金额 |
| 充提差总额 | 充值总额减提现总额 |
| 最后登录时间 | 实际展示会员最后在线时间,缺失显示“-” |
| 操作 | 设为测试账号或取消测试账号、详情 |

充值总额、提现总额、充提差总额使用千分位、两位小数并标注 USD,缺失按 0 展示。三个表头提供含义说明,列表没有全表金额合计。

### 充提金额如何理解

列表直接读取资金服务的汇总,不在查询时另做换汇或逐笔重算。

- 充值汇总包含充值到账,也包含人工加款中勾选“计入充值”的记录;未勾选的人工加款不因加款本身进入该汇总。
- 提现金额使用资金服务累计的扣款金额,不等同于用户链上净到账金额。各出款渠道的入账时点由资金链路负责。
- 缺少汇率的金额由资金服务补算。在已核对的入账链路中,次数可以先增加、金额稍后补入;当前列表没有单独显示汇总待补算状态,不能将显示的总额当作全部历史金额已完整换算的证明。
- 资金撤销可能调整相应次数与金额。充值次数不代表所有历史充值尝试次数。

来源构成、账变和标准计价的共用含义见[资金模型](资金模型.md)与[标准计价](标准计价.md);具体源码及本次未执行的对账范围见核对记录。

## 4. 操作规则

### 查询、重置与翻页

进入页面时按链接中的条件查询;没有条件时使用 A1–A3。编辑筛选框只改变输入,点击“查询”后才更新结果,并回到第一页,保留每页条数。

“重置筛选条件”清空其他筛选,恢复“会员 ID”和默认注册日期范围,回到第一页,保留每页条数。收起筛选会隐藏整组输入框,不会清除已经应用的条件;再次展开后可继续编辑。

翻页保留已应用的查询条件。改变每页条数回到第一页。列表底部显示当前记录范围、总记录数、每页条数、上一页、下一页和页码;无记录时不显示分页栏,没有输入页码跳转框。

本页提供固定列和排序,没有列显隐、拖动重排、表头排序、多选或批量处理。

### 分享查询与在线人数入口

已应用的筛选和分页保存在链接中,打开该链接可以恢复查询。未点击查询的输入不属于已分享条件。详情中的会员标识用于指定弹窗对象,不会自动变成列表的会员 ID 筛选。

顶栏“在线人数”提供在线会员查询快捷入口,使用在线且不限时间的条件,其余条件与分页恢复默认。浏览器前进、后退及同页快捷导航时,筛选框与实际查询条件的同步限制见核对记录。

<a id="21-r4--用户详情弹窗"></a>

### 查看详情(R4)

点击同行“详情”,打开对应会员,默认进入账号概览。关闭后保留列表查询条件和分页。分享链接也可直接打开该会员详情。

会员 ID 同样作为详情入口是用户已确认的要求;网页当前点击未打开,已列为入口差异。完整标签页、操作表单与验收只在[用户详情弹窗](用户详情弹窗.md)维护,主列表不再复制。

### 设置测试账号(R18)

普通会员显示“设为测试账号”,测试会员显示“取消测试账号”。点击后打开对应表单,填写修改原因并确认。原因去首尾空格后不能为空,不提供批量设置。

提交期间禁止重复确认,确定和取消按钮不可用。成功后显示设置或取消成功,刷新列表并关闭表单;失败显示错误并保留表单。

仅真正改变标识时记录操作人、原因及修改前后值。该操作不直接修改余额、VIP、封禁状态或历史订单。本列表仍展示测试账号,不据此承诺所有报表都会自动排除。

操作结果不明时先刷新核对当前标识及操作记录,再决定下一步,不能仅因提示失败就认定标识未改变。

<a id="21-r5--导出"></a>

### 列设置与导出编号

R3 保留为原列设置编号,R5 保留为原导出编号。当前列表不提供这两项操作,不再描述列设置保存、导出任务、站内信通知或下载链接。A4 的原固定查询时限及 A6、A7 的导出参数不作为本页当前功能或实测保证,编号保留且不挪作其他规则。

### 查询和操作遇到异常

| 编号 | 情况 | 处理或边界 |
|---|---|---|
| E1 | 正在查询或查询失败 | 加载时显示占位;请求失败显示“用户列表加载失败”及重试,保留查询条件。当前没有可配置的固定查询响应时限 |
| E2 | 原导出超量场景 | 当前不提供导出,保留原编号 |
| E3 | 访问权限或数据范围不足 | 权限要求引用公共权限模型;当前列表及测试账号接口的授权核对边界见证据,本次未用低权限或跨渠道账号验证隔离 |
| E4 | 详情对象不存在或主资料没有返回 | 详情不能操作旧会员资料,按[详情特殊情况](用户详情弹窗.md#4-特殊情况)处理 |
| E5 | 详情打开后资料状态发生变化 | 具体编辑项的版本检查归详情正文,不将其扩展为列表所有操作的并发保护 |
| E6 | 账号资料与密码展示 | 本列表展示已有账号资料,没有独立的脱敏解锁入口;密码不在列表展示,详情密码规则见详情正文 |
| E7 | 会员为测试账号 | 在会员账号旁显示“测试”,行操作变为取消测试账号;仍参与本列表查询 |
| E8 | 标签 ID 已无匹配会员 | 显示本次查询的空结果;没有“标签已删除”的专门提示,不能仅凭空结果判断标签是否存在 |
| E9 | 用户名含特殊字符 | 保留原文展示,不将用户内容作为网页脚本执行 |

无匹配记录显示“暂无数据”和“调整筛选条件后再试”,保留筛选操作。空值、零和缺少整条汇总记录是不同来源;是否充值为“否”的筛选不保证包含缺少资金汇总记录的会员。

金额下限大于上限时,当前页面提交查询并得到空结果,没有区间错误提示。负值、无效 IP、过大页码等输入的实现边界见核对记录;不把这些缺少校验的表现写成业务规则。
