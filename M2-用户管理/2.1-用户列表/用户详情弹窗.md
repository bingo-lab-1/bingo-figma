# 用户详情弹窗

> 本文是 `2.1-用户列表` 的组成部分,不是独立页面(没有自己的菜单项)。
> 页面级的筛选、列表、导出等需求见同目录 `README.md`。

## 1. 定位

运营点开一个玩家后,**在一个弹窗里看完这个人的全部情况**,不用在多个页面之间跳。

**谁在用**
| 角色 | 在这里做什么 |
|---|---|
| 客服 | 玩家说"钱没到账",查他的充值记录和资产变动 |
| 风控 | 看关联账户数量,判断是不是一个人开了多个号 |
| 运营 | 看首充漏斗,判断这个人值不值得投放资源 |
| 财务 | 核对三分账余额与充提差 |

**不做什么**
- 不改余额(人工上下分跳 M3.5)
- 不做跨玩家查询(那是各独立页面的事,见第 5 段)

## 2. 展开方式

**弹窗**,不是抽屉,不是新页面。列表停留在弹窗背后,关闭后回到原筛选结果与滚动位置。

| 入口 | 位置 |
|---|---|
| 用户ID | 表格「用户ID」单元格,蓝色可点文本 |
| 分享链接 | 打开即直接停在该玩家的详情上 |

> 用户ID 旁边有**复制按钮**,点它只复制 ID,**不打开弹窗**。
> 勾选框与「设为测试账号」按钮同样不触发弹窗,避免误点。

## 3. 常驻信息区(不随 tab 切换)

弹窗顶部固定展示,切到任何 tab 都能看到:

| 字段 | 可否修改 | 说明 |
|---|---|---|
| VIP等级 | 否 | |
| 用户ID | 否 | |
| 用户账号 | **可改** | 手机号 |
| 用户提现绑定手机 | **可改** | 与登录账号可能不同 |
| 绑定邮箱 | **可改** | |
| 账号状态 | 否 | 正常 / 封禁 |
| 用户标签 | 否 | 自动打标,见第 6 段 |
| **打码量** | **可新增** | 后台可给玩家追加打码要求 |
| **总 RTP** | 否 | 含当日 RTP,用于识别异常赢率 |
| 备注 | **可改** | 运营自由填写 |

> 修改账号、手机、邮箱、备注,以及新增打码量,**都要留痕**(见 E-2)。

## 4. 十个 Tab 的内容

### 4.1 用户详情
玩家的身份与来源。

**注册**:注册IP(**带同 IP 账号数**)· 注册域名 · 注册时间 · 注册设备 · **注册设备ID** · 渠道来源(含运营商编号与代理ID)· 注册平台 · 注册浏览器标识
**登录**:登录IP(**带同 IP 账号数**)· 登录域名 · 登录时间 · 登录设备 · 登录设备ID · **登录活跃天数**

### 4.2 账户详情
钱的全貌。**注意是三分账,不是两分账。**

| 分组 | 内容 |
|---|---|
| 余额 | 钱包总余额 · **真金余额**(可看明细)· **彩金余额**(可看明细)· **佣金余额**(可看明细) |
| 盈亏 | 今日输赢 / 历史输赢 |
| 存取款 | 总充值(含笔数)· **充提差** · 首充时间 · 总流水 · 总提现(区分"已提现 / 提现中")· **冻结资金**(带解冻按钮) |

> **佣金余额**是第三个独立钱包,给代理用的。冻结资金可在此直接解冻。

### 4.3 风控数据
判断是不是同一个人开了多个号。

| 维度 | 当前用户数据 | 关联账户数量 |
|---|---|---|
| 登录设备 | 该玩家用过几个设备 | 同一设备下有几个账号 |
| 登录IP | 该玩家用过几个 IP | 同一 IP 下有几个账号 |
| 注册设备 | — | 同一设备注册了几个账号 |
| 注册IP | — | 同一 IP 注册了几个账号 |

**判定时间窗可配置**(见 A-1):以玩家最后登录时间为中心,前后各取该时长内的记录来统计。

### 4.4 订单数据
单注明细,可筛选(局号 / 游戏类型)。

**汇总**:参与次数 · 流水金额 · 游戏盈亏
**列**:序号 · 局号 · 游戏类型 · 品牌 · 子游戏名称 · 接入厂商 · 类型 · 投注金额 · 派彩金额 · **赠送金额** · **取消金额** · 会员盈亏 · 订单状态 · 投注时间

### 4.5 提款记录
可筛选(提现订单号 / 时间 / 状态)。

**汇总**:成功提现次数 · **成功提现真金** · **成功提现彩金**(分开统计)
**列**:序号 · **锁定** · 订单号 · **提现真金金额** · **彩金金额** · 提现信息(姓名 / 内容 / **CPF**)· 首次提现 · 手续费 · 实际到账 · 付款通道 · 提现方式 · 订单状态 · 操作人员 · 备注 · 操作
**时间**:注册时间 · 申请时间 · 提交时间 · 完成时间(四个时间戳)

> **真金与彩金分开记录、分开统计**——这是提现风控的基础。

### 4.6 充值记录
可筛选(订单号 / 状态 / 通道单号 / 支付通道)。

**汇总**:成功充值次数 · 成功充值金额
**列**:序号 · 订单号 · **通道单号** · 支付金额 · **获得金额** · **赠送金额** · 订单状态 · 支付通道 · 是否首充 · 时间 · 操作

> 支付金额与获得金额分开——充值活动的赠送体现在「赠送金额」。

### 4.7 资产变动
所有余额变动的流水,可按**变动原因多选**筛选。

**汇总**:三个总额 + **失败金额**
**列**:序号 · ID · 变动时间 · **变动原因** · **变更方式** · 状态 · 变动前金额 · 变动金额 · 变动后金额

> 「变动原因」是那套账变类型枚举(竞品有 159 种)。**变动前/后金额都记**,便于对账。

### 4.8 投注记录
**按游戏聚合**的统计,不是单注明细(单注在 4.4)。可筛选游戏类型 / 厂商 / 品牌。

**列**:序号 · 游戏类型 · 厂商 · 游戏品牌 · 游戏ID · 游戏名称 · 总注单量 · 总投注金额 · 返奖金额 · 用户输赢 · **占单量** · **投注金额占比** · **RTP**

> 用来看这个玩家主要玩什么、在哪款游戏上赢得异常。

### 4.9 资产走势
余额随时间变化的图表,可筛选游戏类型 / 品牌 / 厂商 / 时间。

### 4.10 状态监控
**首充漏斗分析**,四组字段:

| 组 | 字段 |
|---|---|
| 基础信息 | 用户ID · 注册时间 · 注册日期 · 渠道(运营商ID)· 广告计划(代理ID)· 设备ID |
| 首充相关 | 首充时间 · 首充日期 · 首充金额 · **注册到首充(分钟)** · 注册当日首充 · 首充后首投时间 · **首充到首投(秒)** · 首充后是否投注 |
| 首充当日 D0 | 投注局数 · 总投注额 · 总派彩额 · 玩家投注盈亏 · 充值次数 · 充值金额 · **是否二充** · 提现金额 · **收盘现金余额** · **收盘 Bonus 余额** · 收盘总余额 |
| 首充次日 D1 | 是否登录 · 首次登录时间 · **回归现金余额** · 回归 Bonus 余额 · 回归总余额 · 是否投注 · **是否复充** |

> **这一 tab 更像报表而非玩家档案。** 是否保留在弹窗内、还是移到 M1 数据中心,见第 7 段待定项。

## 5. 与独立页面的分工

弹窗 tab 与 M2 其他页面**数据同源但查询轴不同**,不是重复:

| 弹窗 tab | 对应独立页面 | 区别 |
|---|---|---|
| 4.7 资产变动 | 2.2 钱包账变 | 弹窗**以人为轴**(这个人的流水);独立页**以事件为轴**(按账变类型跨玩家查) |
| 4.4 订单数据 | 2.3 投注明细 | 同上,独立页可按游戏/厂商跨玩家查 |
| 4.5 / 4.6 | M3.2 / M3.1 | 独立页面用于审核与对账 |

**列定义以独立页面为准**,弹窗只展示其子集 + 最近若干条(见 A-2)。

## 6. 用户标签(自动打标,非手工)

标签由系统按规则自动打上,**运营不逐个手打**。实测一个玩家同时挂十几个标签,按语义分组:

| 组 | 示例 |
|---|---|
| 行为分层 | 普通玩家 · 重度游戏 · 低活跃 · 中登录 |
| 生命周期 | 新用户 · 老用户 · 注册天数(小于等于7)· 注册大于1天用户 |
| 充值分层 | 首充 · 二充 · 三充及以上 · 低频复充 · 最低首充 |
| 付费能力 | 付费用户(累计充值大于30 / 大于50)· 付费用户(充值次数>=2) |
| 投注特征 | 小额投注 · 低额单笔 · 小额盈利 |
| 提现 | 提现用户(首笔提现) |
| 风险 | 快杀10雷 |
| 等级 | VIP等级(V1) |

> 标签**在列表页也占一整列**,是运营识别玩家的主要手段。
> 打标规则的定义与维护属于 2.5,本弹窗只展示。

## 9. 异常与边界

| # | 场景 | 触发条件 | 预期处理 |
|---|---|---|---|
| E-1 | 越权查看 | 改链接里的玩家标识,或绕过界面直接取数 | **每次取数都要在服务端判权限**并拒绝;把入口藏起来不算防线 |
| E-2 | 修改未留痕 | 改账号/手机/邮箱/备注,或新增打码量 | **全部必须留痕**,记录操作人、改动前后值 |
| E-3 | 单个 tab 失败 | 某个 tab 加载失败或超时 | **只有该 tab 显示重试**,其余 tab 照常可用 |
| E-4 | 玩家不存在或已注销 | 打开一条旧的分享链接 | 弹窗内提示,不出现系统错误页 |
| E-5 | 并发状态变更 | 弹窗打开期间该玩家被他人封禁 | 提交修改时提示状态已变更,不静默覆盖 |
| E-6 | 敏感字段泄露 | 手机号、CPF、收款账号的展示 | **数据发出前就要脱敏**;查看完整值需独立权限且单独留痕 |
| E-7 | 冻结资金误解冻 | 在 4.2 点「解冻」 | 二次确认 + 原因必填 + 留痕;金额级解冻规则见 M3.6 |
