## 1. 用途与入口

运营、客服和财务在这里查看一个会员的账号、资金、收款账号和登录情况,并完成相应的资料修改及资金操作。所有查询都限定为当前会员。

用户列表中的会员 ID 和同行“详情”使用同一个详情弹窗。默认打开“账号概览”,标题显示“会员详情 - 会员账号”,账号为空时改用用户名。关闭后回到原列表,保留其查询条件和位置。带有会员标识的分享链接可以直接打开对应详情。

有代理资料的会员可以在“代理详情”的邀请用户列表中继续打开下级会员。关闭下级详情返回上一层会员,关闭最外层详情才回到用户列表。

弹窗面向桌面后台,使用简体中文。会员信息与标签页位于同一个滚动区域。金额结合币种阅读,不将不同原币直接作为同一种钱相加。日期展示的实际规则见第 6 部分。

## 2. 查看哪些信息

<a id="3-常驻信息区不随-tab-切换"></a>

### 会员信息

切换标签页不会更换当前会员的信息。此区显示以下字段:

| 字段 | 含义与操作 |
|---|---|
| 会员 ID、会员账号、用户名 | 识别当前会员;本区只读 |
| VIP 等级 | 当前等级;在“账号概览”中修改 |
| 账号状态 | 正常或封禁;有封禁截止时间时一并展示,提供“修改” |
| 手机号、绑定邮箱、真实姓名 | 展示会员已保存的信息;本区只读 |
| 会员标签 | 展示标签名称,没有人工添加或移除标签的操作 |
| 测试账号 | 显示是或否 |
| 打码量 | 展示汇总值及各币种“还差多少”的标签;判断某币种的情况使用分币种值,顶部数值不是标准币换算金额 |
| 在线状态、最后在线 | 显示在线或离线,以及最后在线时间 |
| 备注 | 展示运营备注,提供“修改” |

会员信息区不提供修改邮箱、真实姓名、人工挂标或新增打码量的按钮。新增打码量在“打码任务”中操作。

<a id="4-十个-tab-的内容"></a>

### 标签页组成

固定提供 12 个标签页。有代理资料时,在“账号概览”后增加“代理详情”,共 13 个。完整顺序如下:

| 标签页 | 在这里解决什么问题 |
|---|---|
| 账号概览 | 查看账号、注册、登录、资金安全和充提汇总,修改账号资料 |
| 代理详情 | 查看推广信息、邀请用户和佣金记录;仅有代理资料时展示 |
| 钱包 | 按币种查看余额、来源构成、冻结、打码和提现资格,修改余额 |
| 打码任务 | 查询任务,新增打码量或清除一条进行中的任务 |
| 第三方钱包 | 查看游戏平台钱包余额,将平台余额全部转回本金钱包 |
| 法币账号 | 查询、新增或修改法币收款账号 |
| 虚拟币账号 | 查询、新增或修改币种、链和钱包地址 |
| 提现账号 | 只读查询提现账号资料 |
| 充值记录 | 查询充值到账对应的资金流水 |
| 提款记录 | 查询提现扣款对应的资金流水 |
| 资产变动 | 查询当前会员的各类资金和打码变动 |
| 登录设备 | 查询登录记录及其 IP、客户端、浏览器和系统 |
| 风控数据 | 查看设备、IP 的使用值和关联账号 |

### 账号概览

| 区块 | 字段 |
|---|---|
| 账号概览 | 会员账号、用户名、账号状态、显示用户名、密码、手机号、邮箱验证、上级代理、代理佣金、推广渠道、VIP 等级、会员标签、注册来源、注册时间 |
| 注册信息 | 注册 IP、注册地区、注册域名、注册设备 ID、注册平台;有统计数据时显示同 IP、同设备的关联账号数量 |
| 登录信息 | 最后登录 IP、最后登录域名、最后登录时间、登录设备类型、登录浏览器、登录系统、最后在线时间、在线状态 |
| 资金安全 | 提现密码设置时间、提现密码错误次数、提现密码锁定至 |
| 投注与充提 | 下注次数、下注总额（USD）、充值次数、充值总额、提现次数、提现总额、充提差额 |

“用户名”和“显示用户名”是两个不同字段,本页都保留;前者只读,后者可修改。密码始终显示遮罩,不展示原密码。邮箱验证显示已验证或未验证。

下注总额使用标准币 USD,显示两位小数。充提差额为展示的充值总额减提现总额,显示两位小数;这些汇总不代替各币种钱包余额。其余汇总读取各自提供方的数据,不按当前钱包余额反算。

### 代理详情

代理信息显示推广码、邀请人数和备注。点击推广码可复制。下方包含“邀请用户”和“佣金记录”,默认展示邀请用户。

| 内部标签 | 筛选 | 结果字段 |
|---|---|---|
| 邀请用户 | 用户 ID | 用户 ID、会员账号、邮箱、注册 IP、设备码、充值次数、充值金额、提现金额、投注次数、投注金额、佣金金额、邀请时间、注册时间 |
| 佣金记录 | 推荐人、关联投注 | 推荐人、类型、佣金金额、返佣比例、产生时间、可领取时间、状态、创建时间 |

两个列表均固定当前代理,默认每页 20 条。邀请用户的充值、提现、投注和佣金金额按 USD 展示。邀请用户的 ID 用于复制,点击会员账号打开该会员的下一层详情。佣金列表用于查看记录,没有领取、改金额或重新计算佣金的操作。

### 钱包

每行一个币种钱包,一次展示当前会员的全部钱包。

| 字段 | 含义 |
|---|---|
| 币种 | 钱包原币 |
| 总余额 | 当前钱包总余额 |
| 本金构成、彩金构成 | 余额的来源构成,不作为两个可独立提现的钱包 |
| 冻结资金、可用余额 | 分别读取钱包提供的冻结与可用金额 |
| 待打码 | 当前币种剩余打码量 |
| 钱包状态 | 正常、受限或已关闭 |
| 提现资格 | 当前钱包返回的可提现或禁提结果 |
| 货币状态 | 启用或禁用 |
| 操作 | “修改余额”,打开当前币种的加款或扣款表单 |

金额显示八位小数并使用千分位。上方展示“打码与提现资格”提示;实际是否能提交提现还需按钱包及财务规则判断,不能只凭提示标签放行。

### 打码任务

只提供状态筛选:全部状态、进行中、已完成、已到期、已清除。选择后自动查询,可重置或收起筛选区。

每行显示币种、来源、分户、需打码、剩余打码、倍数、状态、创建时间和操作。来源包含充值、彩金、代理佣金领取、人工和历史迁移;分户显示本金或彩金。打码量显示八位小数,倍数按记录值展示。

上方提供“新增打码量”;进行中的任务提供“清除”,其他状态没有清除动作。列表不展示来源单号、完成时间、清除时间或清除原因详情。“已到期”作为历史状态查询,不表示本页新增了自动到期规则。

### 第三方钱包

每行显示平台、货币和余额。平台展示名称,没有名称时显示平台 ID;余额按原币显示八位小数。没有筛选条件或跨币种金额合计。

提供“全部转回本金钱包”。没有平台钱包数据或正在转回时按钮不可用;不提供逐个平台转回。

<a id="42-账户详情"></a>

### 法币账号、虚拟币账号和提现账号

三类账号分别维护,不能将一个标签页的可编辑范围套用到另一个。

| 标签页 | 结果字段 | 操作 |
|---|---|---|
| 法币账号 | 姓名、账号、类型、是否默认、修改人、修改时间、操作 | 新增账号、修改;没有删除 |
| 虚拟币账号 | 币种、链、钱包地址、是否默认、修改人、修改时间、操作 | 新增账号、修改;没有删除 |
| 提现账号 | ID、账号名称、币种、链、地址、状态、备注、创建时间、更新时间 | 只读,没有新增、修改、删除或启停 |

法币类型包含 CASHapp、PayPal。虚拟币账号及提现账号的长地址可查看完整值。是否默认显示是或否;提现账号状态显示启用或禁用。修改人优先显示姓名,缺姓名时显示其 ID。法币账号一次展示全部记录。

<a id="46-充值记录"></a>
<a id="45-提款记录"></a>

### 充值记录与提款记录

两个标签展示资金账变。充值记录固定为“充值到账”,提款记录固定为“提现扣款”;均自动限定当前会员,不提供修改会员或账变类型的筛选。

| 查询条件 | 使用方式 |
|---|---|
| 币种 | 输入币种代码,字母转为大写;留空不限币种 |
| 关联单据 ID | 按资金流水关联的单据查询 |
| 日期 | 独立选择开始和结束日期,允许只填一端;按所选日期包含当天的记录 |

修改条件后点击“查询”生效。重置清空上述条件,仍保留当前会员与固定账变类型。默认每页 20 条,可选 20、50、100 条;查询、重置和改变每页条数均回到第一页。

两个列表共用十列:序号、账变时间、账变类型、币种、变动金额、变动前余额、变动后余额、标准计费 / 汇率、关联单据、备注。

变动前、变动金额和变动后分别展示总额、本金、彩金和打码量,使用该条账变当时的数据。金额显示八位小数;未记录打码量显示“—”,不当作零。标准计费显示最新标准币折算金额、精确或近似标识、汇率等式（1 原币对应多少标准币）、汇率时点及来源;有多个版本时显示版本数量。缺少折算结果显示“待补算”。

提款记录上方按币种提示未完成打码及剩余量。这两个标签没有订单审核、补单、订单详情跳转、独立赠送金额列、期间金额合计或导出功能。充值赠送的资金结果在“资产变动”按对应来源查询。

<a id="47-资产变动"></a>

### 资产变动

查询当前会员的全部账变。筛选为变动原因、关联单据、日期范围;变动原因单选,默认全部原因。条件变化后自动查询,不另点查询按钮;重置清空条件并回到第一页。

变动原因使用资金账本提供的类型:充值到账、彩金发放、投注扣款、投注返奖、投注退款、佣金入账、VIP 奖励、平台转出、平台转入、提现扣款、提现退款、人工加款、人工扣款、打码量变动、入账冲正、出账冲正、充值拒付。无法识别的历史值保留原值。

十列依次为序号、变动原因、币种、时间、变动前余额、变动金额、USD 标准金额、变动后余额、关联单据、备注。前额、变化和后额同样区分总额、本金、彩金及打码量;本金、彩金是资金来源,打码量不计入余额。

USD 标准金额只展示最新折算金额或“待补算”,不展开充值、提款表中的汇率详情。默认每页 10 条,可选 10、20、50 条。没有币种筛选、汇总、单据跳转、详情、导出或修改操作。

### 登录设备

按 IP 地址、客户端类型、浏览器和操作系统查询当前会员的登录记录。输入变化后自动查询并回到第一页,可重置、收起筛选。

列表显示 ID、IP 地址、客户端类型、浏览器、操作系统、登录时间。首次每页 10 条,每页条数选择提供 20、50、100。这里只查看登录记录,没有踢出会话或封禁设备的独立按钮。

### 风控数据

展示登录设备、注册设备、登录 IP、注册 IP 四个维度。上方显示设备窗口、IP 窗口、配置版本和时区。

每个可用维度显示使用值数量及关联账号数量。点击使用值数量,打开仅含“值”的明细;点击关联账号数量,显示用户 ID、账号、邮箱、注册时间。数量为零仍可打开,显示无数据。关联账号明细本身不再打开下一层会员详情。

维度不可用时显示具体原因,例如设备码不可用;数据不完整时显示相应标记。维度出错时提供重试入口,点击后重新查询整组风控统计。

**A-1 · 风控统计窗口**:设备和 IP 的窗口及判定方式引用[8.1 风控参数](../../M8-系统设置/8.1-风控参数/README.md),本页展示返回的实际配置值,不在这里另配一套。

## 3. 操作规则

### 打开、切换和关闭

首次打开加载当前会员资料,默认展示账号概览。切换标签页加载相应查询;所有请求都使用当前会员,不能混入上一位会员的记录。

关闭资料修改或账号编辑表单,返回原会员详情;取消不保存输入。修改成功后刷新对应信息并关闭编辑表单。关闭会员详情时只移除当前详情标识,保留列表其他查询条件。

### 修改账号资料与查看修改记录

| 修改项 | 入口与填写要求 |
|---|---|
| 会员账号 | 账号概览;3 至 30 位英文、数字或下划线;保存时去首尾空格、转小写并检查唯一性 |
| 显示用户名 | 账号概览;填写新的显示用户名 |
| 手机号 | 账号概览;填写新的手机号 |
| VIP 等级 | 账号概览;从等级下拉选择 |
| 备注 | 会员信息;允许清空备注 |
| 密码 | 账号概览;选择登录密码或取款密码,填写新密码、确认密码及修改原因 |

上述页面表单均要求填写修改原因。密码至少 6 位,两次输入必须一致。除备注外,普通资料的新值不能为空。保存中禁止重复提交;失败显示错误并保留表单供修改。

资料和密码修改表单都有“修改记录”标签,按当前会员和修改项查询。每页 5 条,显示操作人、修改前、修改后、修改原因、操作时间。密码历史只显示密码类型及是否已设置,不显示密码明文。重置取款密码同时更新密码设置时间、清零密码错误次数并解除密码锁定。

### 修改账号状态

会员信息与账号概览的“账号状态 → 修改”共用同一操作。正常账号打开封禁表单,预填当前会员 ID;封禁账号查询生效封禁后打开解封表单。

封禁限制、到期时间、踢出当前登录、封禁原因及解封原因按[封禁列表](../2.4-封禁列表/README.md)执行。未找到生效封禁记录时提示刷新后重试,并刷新会员资料。

### 修改钱包余额

在钱包行点击“修改余额”,表单固定所选钱包币种。操作类型默认为加款,可以切换为扣款。金额必须为有限正数。

加款填写金额、打码倍数、是否计入充值及备注;“是否计入充值”默认关闭,备注可空,打码倍数为空时按表单的 0 处理。倍数必须为有限非负数。扣款不填写打码倍数和计入充值选项。此表单没有本金、彩金分户选择,本次调整进入本金构成。

“是否计入充值”控制本次加款是否计入充值统计,不表示另建正常充值订单或自动满足所有活动条件。大于 0 的倍数用于本次加款的打码任务;0 倍不增加打码义务。

成功后提示加款或扣款成功,刷新钱包及打码汇总;失败显示错误,保留表单。这里的操作是当前币种的加减金额,不是将余额直接覆盖成输入值。当前表单与通用资金规范的实现差异见核对记录。

### 新增或清除打码任务

新增时选择当前会员的币种钱包,填写打码量和原因。输入的是绝对值,不会增加余额,允许超过当前余额;没有可选钱包时不能打开新增操作。打码量必须大于 0,页面拒绝缺少金额或原因的提交。

清除针对一条进行中的任务。确认表单显示币种和剩余打码量,填写原因后点击“确认清除”。不提供批量清除或清空所有任务。清除只解除该任务的义务,其他打码任务、冻结及风险限制照常生效。

任务创建或清除成功后刷新任务及分币种汇总。重复清除不再次生效;无本金任务与逐条清除的业务含义引用[资金模型 R17](资金模型.md#21-r17--人工打码干预)。页面校验与服务端校验的核对结果见核对记录。

### 新增或修改收款账号

法币账号填写姓名、账号、类型和是否默认。虚拟币账号填写币种、链、钱包地址和是否默认;币种下拉提供加密币种,链选项为 TRC20、ERC20、BEP20、SOL、BTC、Polygon、Arbitrum。历史账号保留其已有链值。

两类账号新增时默认开关关闭。修改时增加必填的修改原因,并带出原值;保存成功刷新对应列表。法币账号的姓名、账号必填;虚拟币账号的币种、链、地址必填,地址不能只填空格。

提现账号标签只读,不使用上述新增或修改表单。

### 将第三方钱包余额转回

点击“全部转回本金钱包”后再次确认,确认内容说明将当前会员所有平台余额转回本金钱包。成功后提示并刷新平台钱包,失败显示转回失败。弹窗不选择单个平台或自填转回金额。

## 4. 特殊情况

| 编号 | 情况 | 处理要求 |
|---|---|---|
| E-1 | 没有相应访问或操作权限 | 按账号可访问的数据与操作范围授权。风控数据另检查查看权限,无权时显示“无权查看风控数据”;各写接口授权的源码核对范围见核对记录 |
| E-2 | 修改资料、余额或打码任务 | 使用当前会员与所选对象,保存相应操作记录;资料修改和打码干预的原因按表单要求填写 |
| E-3 | 某一查询失败 | 在该查询支持的错误区域显示失败及重试;失败不能解释为没有记录,也不能把上一会员的数据当成本会员结果 |
| E-4 | 会员资料仍在加载或没有可展示资料 | 不显示可执行的旧会员表单。主资料查询的异常呈现限制见核对记录 |
| E-5 | 修改会员账号、显示用户名、手机号、VIP 等级或备注期间,封禁状态已改变 | 按提交时的封禁状态版本校验,不一致则拒绝并提示刷新;密码和资金表单不使用这一版本参数,它也不保护其他资料字段的并发修改 |
| E-6 | 查看密码及修改历史 | 原密码和新密码明文不进入详情或修改历史;资料的访问范围按账号权限控制 |

旧 E-7 对应的“冻结资金解冻”按钮不在当前弹窗中提供,编号保留且不挪作其他需求。账号状态中的解封按封禁记录处理,不能解释为修改钱包冻结金额。

普通列表无记录时显示空状态,保留可用的筛选或新增操作。风控使用值明细无记录显示“暂无数据”,关联账号明细显示“无关联账号”。缺少普通展示值使用字段自身的空值表现;缺少账变打码记录显示“—”,与数值零区分。

打码任务、第三方钱包、虚拟币账号和提现账号的分页控件默认选择每页 20 条,可选 20、50、100 条;这四处当前的分页接入限制见核对记录。钱包与法币账号一次展示全部记录,其他查询按各标签说明分页。

资金操作的结果和列表刷新是两件事。创建已成功而刷新失败时,先重新查询原结果,不能因为列表没刷新就再次发起同一笔资金或打码操作。网页已发现的提示与分页限制见核对记录,不作为资金规则。
