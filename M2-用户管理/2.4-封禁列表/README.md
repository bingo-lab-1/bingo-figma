# 2.4 · 封禁列表

## 1. 用途

运营和客服通过本页查询用户的封禁历史，了解封禁限制、原因、期限和操作人，并办理封禁或解封。

本文按现有后台页面归档。页面面向桌面端，使用简体中文；入口为“会员管理 → 封禁列表”。封禁、到期和解封时间均按查看者浏览器的本地时区显示。

每行是一条封禁记录。解封后保留原记录；用户再次被封禁时新增一条记录。本页处理用户限制和封禁记录，不调整钱包余额、资金来源构成或打码量。

## 2. 查询与处理信息

### 查询条件

直接打开页面时，文本和日期条件为空，状态为“全部”。填写后点击“查询”才应用；多个条件同时填写时，结果须同时满足这些条件。

| 条件 | 含义和填写规则 |
|---|---|
| 用户ID | 输入完整用户 ID，去除首尾空格后精确匹配；留空不限定用户 |
| 会员账号 | 输入完整账号，去除首尾空格后精确匹配；不按账号片段查询，也不自动转换大小写 |
| 用户昵称 | 输入完整昵称，去除首尾空格后精确匹配；留空不限定昵称 |
| 状态 | 单选：全部、封禁中、已解封；按封禁记录的状态筛选 |
| 封禁时间 | 选择开始与结束日期，包含首日零点至末日最后一刻；按封禁发生时间查询，不按到期时间或解封时间查询 |

日期范围选择完成后仍需点击“查询”。页面不提供按封禁限制、操作人或渠道单独筛选的输入项。

### 结果字段

列表有以下 13 列。没有匹配记录时展示空状态，不展示表头和分页栏。

| 字段 | 含义和展示规则 |
|---|---|
| 用户ID | 本条封禁记录所属的用户 ID |
| 会员账号 | 对应用户的账号；没有值时显示“-” |
| 用户昵称 | 对应用户的昵称；没有值时显示“-” |
| 封禁限制 | 显示本次选择的限制，可同时显示资金冻结、游戏冻结、登录冻结 |
| 封禁原因 | 发起本次封禁时填写的原因；长文本省略展示，悬停可查看完整内容 |
| 封禁时间 | 本次封禁记录的发生时间，显示到秒 |
| 到期时间 | 本次设置的到期时间，显示到秒；没有设置时显示“永久” |
| 状态 | 记录生效时显示“封禁中”，已解除时显示“已解封” |
| 封禁操作人 | 发起封禁的后台账号，优先显示名字，其次账号；缺失时显示“-” |
| 解封时间 | 本条记录被解除的时间，显示到秒；没有值时显示“-” |
| 解封原因 | 办理解封时填写的原因；没有值时显示“-”；长文本可悬停查看 |
| 解封操作人 | 办理解封的后台账号，优先显示名字，其次账号；缺失时显示“-” |
| 操作 | 封禁中提供“解封”和“详情”；已解封只提供“详情” |

会员账号和昵称读取对应用户资料；封禁原因、限制和操作时间属于本条历史记录。列表不展示余额或币种。

### 封禁用户

点击顶部“封禁用户”，打开同名弹窗。

| 填写项 | 含义和规则 |
|---|---|
| 用户ID | 必填，输入要处理的完整用户 ID，提交时去除首尾空格 |
| 封禁限制 | 至少选择一项；可多选资金冻结、游戏冻结、登录冻结；默认只勾选登录冻结 |
| 到期时间（留空表示永久） | 选填，选择日期、小时和分钟；留空记录为永久 |
| 踢出当前登录 | 默认开启，允许关闭；决定本次是否清除该用户的当前登录会话 |
| 封禁原因 | 必填，提交时去除首尾空格，不能只填写空格 |

同一封禁弹窗也供用户详情使用。从用户详情打开时，用户 ID 已填入且不可编辑；从本页顶部打开时，由操作人填写用户 ID。

### 解封用户

点击某条封禁中记录的“解封”，打开“解封用户”。只需填写“解封原因”，该项必填，提交时去除首尾空格。操作对象是所点击的封禁记录，不在弹窗中切换用户。

## 3. 处理规则

### 查询和查看详情

首次进入自动加载列表。点击“查询”应用条件并回到第 1 页；“重置筛选条件”清空全部条件并回到第 1 页，两者均保留当前每页条数。

“收起筛选”只隐藏输入区，不清空条件或改变结果；展开后可以继续编辑。点击行内“详情”打开对应的[用户详情](../2.1-用户列表/用户详情弹窗.md)，本页不另建一套用户资料。

记录按封禁时间从新到旧排列；封禁时间相同时，按记录创建时间从新到旧排列。页面不提供点击列头修改排序的操作。

默认每页 10 条，可切换为 20 条或 50 条。切换条数回到第 1 页；翻页沿用已应用条件和每页条数。分页栏显示当前条数范围和总数，第一页不能向前翻，最后一页不能向后翻。

### 办理封禁

1. 填写用户 ID、限制、原因，并选择期限和是否踢出当前登录。
2. 点击“确定”。必填信息不完整时，留在弹窗内提示补齐，不提交处理。
3. 服务检查用户存在，且没有生效中的封禁记录。同一用户有生效记录时，拒绝再次创建封禁。
4. 创建封禁记录，保存限制、原因、期限和操作人；同时将用户标记为封禁。开启“踢出当前登录”时，清除该用户的登录会话并将其在线状态置为离线。
5. 处理成功后提示“封禁成功”，关闭弹窗并重新查询列表；封禁操作同时写入操作日志。

提交期间，“确定”和“取消”按钮禁用，“确定”显示“提交中…”。填写但未提交时，点击“取消”关闭弹窗，不产生封禁记录。

### 办理解封

1. 在封禁中记录上点击“解封”，填写原因并点击“确定”。
2. 服务检查该记录存在且仍处于封禁中，将其改为已解封，记录解封原因、时间和操作人，并写入操作日志。
3. 该用户没有其他生效封禁时，清除用户的封禁标记和到期时间。原封禁记录保留，不删除历史原因或限制。
4. 成功后提示“解封成功”，关闭弹窗并重新查询列表。在“封禁中”条件下，这条记录不再出现；切换“已解封”或“全部”可查到它。

解封提交期间同样禁用确定、取消按钮。解封不恢复此前被清除的登录会话，也不调整用户资金。

### 期限和限制的记录边界

“到期时间”记录本次设置的期限，“状态”读取封禁记录当前是否仍生效。列表不会仅因到期时间已过而自行改成“已解封”，也不会自行补写解封时间、原因或操作人。

资金冻结、游戏冻结、登录冻结是本次保存的限制项，可以组合。它们在玩家登录、资金和游戏操作中的拦截由对应业务处理；本页不另行定义钱包扣减、打码或提现规则。

本页不提供修改既有封禁记录、删除记录、批量封禁、批量解封或导出操作。

## 4. 特殊情况

| 情况 | 如何处理 |
|---|---|
| 查询无匹配记录 | 显示“暂无数据”和“调整筛选条件后再试。”，保留条件供修改 |
| 列表请求失败 | 显示“封禁记录加载失败”和“重试”；重试沿用已应用的条件和分页，失败不表示用户没有封禁记录 |
| 封禁缺少用户 ID、原因或未选限制 | 提示“请填写用户 ID、封禁限制和封禁原因”，不发送封禁请求 |
| 解封原因为空或只有空格 | 提示“请输入解封原因”，不发送解封请求 |
| 用户不存在，或已有生效封禁 | 服务拒绝封禁，本页提示“封禁失败”，保留弹窗及填写内容 |
| 封禁限制为空、包含“正常”或重复值 | 服务拒绝请求；“正常”不作为弹窗中的可选限制 |
| 解封记录不存在、已经解封，或提交时状态已变化 | 服务拒绝重复处理，本页提示“解封失败”，保留弹窗；重新查询后按最新状态处理 |
| 提交失败或未收到成功响应 | 提示“封禁失败”或“解封失败”，保留填写内容并恢复按钮；重新查询记录核对实际状态，不能仅凭失败提示认定后台未处理 |

## 5. 验收场景

| 需求编号 | 场景与操作 | 预期结果 |
|---|---|---|
| 2.4-R1 | 不带条件进入页面 | 自动加载，文本和日期条件为空，状态为全部；无记录时显示空状态 |
| 2.4-R2 | 输入带首尾空格的完整账号，并选择封禁中后查询 | 去除首尾空格后精确匹配账号，只返回该账号仍生效的封禁记录 |
| 2.4-R2 | 用账号片段查询，或同时输入账号与昵称 | 片段不作为模糊匹配；填写多个条件时必须同时满足 |
| 2.4-R3 | 选择封禁日期范围后查询 | 按浏览器本地时区包含首日零点至末日最后一刻，依据封禁时间筛选 |
| 2.4-R4 | 查看多页记录，切换每页条数，再查询和重置 | 默认 10 条，可选 20、50 条；切换条数、查询和重置均回第 1 页，查询和重置保留页长 |
| 2.4-R5 | 查看封禁中和已解封记录 | 按 13 列展示；缺失解封信息显示“-”，未设期限显示永久；只有封禁中记录提供解封 |
| 2.4-R6 | 打开封禁用户弹窗，再从用户详情打开相同弹窗 | 默认登录冻结、踢出开启；本页入口可填写用户 ID，用户详情入口预填且只读 |
| 2.4-R7 | 缺少必填信息时确定，或填写完整后取消 | 缺少必填信息时提示且不提交；取消不创建封禁记录 |
| 2.4-R8 | 对没有生效封禁的用户提交有效封禁 | 保存记录和操作人、标记用户封禁；按踢出选项处理会话，成功后刷新列表 |
| 2.4-R8 | 对同一生效封禁用户再次提交 | 拒绝再次创建生效记录，页面提示失败并保留弹窗 |
| 2.4-R9 | 填写原因解封，再查看已解封记录 | 保存解封原因、时间和操作人，保留原封禁信息；没有其他生效封禁时清除用户封禁标记 |
| 2.4-R9 | 重复提交解封或并发解封同一记录 | 不重复执行，后到的无效请求被拒绝，重新查询可见实际记录状态 |
| 2.4-R10 | 查看到期时间已过但状态仍生效的记录 | 仍按记录显示封禁中，不由列表推算或补写解封结果 |
| 2.4-R11 | 查询失败后重试，或封禁、解封提交未获成功响应 | 查询可按原条件重试；提交失败保留内容，重新查询核对实际状态 |
| 2.4-R12 | 查看行内详情和页面可用操作 | 详情打开对应用户；本页不提供既有记录编辑、删除、批量操作或导出 |

## 6. 相关资料

- 入口与关联查询：会员管理 → 封禁列表；用户资料和共用封禁入口见[用户详情](../2.1-用户列表/用户详情弹窗.md)。
- 权限归属：封禁、解封沿用模块登记的 `user:ban`；用户详情归属 `user:detail:view`。功能权限和账号数据范围引用[权限模型](../../M6-账号管理/6.2-角色列表/权限模型.md)。
- 数据与责任：M2 维护用户封禁状态、封禁历史和操作人记录；登录会话由账号能力管理。资金事实由财务维护，本页不改余额。
- 共用规则：余额、资金来源、有效投注和打码义务引用[资金模型](../2.1-用户列表/资金模型.md)，本页的限制选项不替代这些规则。
