# 2.2 · 钱包与账变

## 1. 用途
查询玩家余额构成与全部账变流水。**只读展示,不做资金操作。**

## 2. 入口
菜单:用户管理 → 钱包账变 · 跳入:用户详情「钱包」tab

## 3. 字段清单

**筛选**:用户ID/账号 · 账变类型(枚举)· 币种 · 账变时间 · 关联单据号

**余额概览(四分账)** ← 当前缺失,需补
| 项 | 字段 | 说明 |
|---|---|---|
| 真金 | `balance` | 可直接提现 |
| 彩金 | `bonusBalance` | 需打码达标 |
| **冻结** | `frozenBalance` | 缺失 · 字段待新增 |
| **待打码** | `WagerRequirement` 汇总 | 缺失 · 表待新增 |

**表格列**:`序号 | 时间 | 账变类型 | 币种 | 变动金额 | 变动前余额 | 变动后余额 | 账户(真金/彩金) | 关联单据 | 备注`

## 4. 需求清单

| ID | 需求 | 验收标准 | 权限码 | 人日 |
|---|---|---|---|---|
| 2.2-R1 | 余额概览四分账 | 显示真金/彩金/冻结/待打码四项,合计与明细一致 | `user:wallet:view` | 1 |
| 2.2-R2 | 账变流水列表 | 按时间倒序;显示变动前后余额 | `user:wallet:view` | 1 |
| 2.2-R3 | 按账变类型筛选 | 枚举下拉可选;组合时间范围生效 | `user:wallet:view` | 0.5 |
| 2.2-R4 | 关联单据跳转 | 点击单据号跳对应充值/提现订单详情 | 继承目标页权限 | 0.5 |

## 5. 状态清单
空 / 加载 / 错误 / 无权限 / 未选择用户(引导选择)

## 6. 交互流程
纯查询页。点击关联单据 → 跳对应订单详情。

## 7. 涉及表
**全部只读**(owner 为 M3):`Wallet` `Transaction` `WagerRequirement` `FreezeRecord`
本模块不拥有任何表 → 见 `../../M3-财务管理/表设计.prisma`

## 8. 关联页面
跳出:充值订单(M3.1)· 提现订单(M3.2)· 打码核销(M3.7)· 冻结解冻(M3.6)
