# 12.1 · 首页看板

## 1. 用途

运营和管理人员在这里看平台经营概况：注册、充值、投注、输赢四张指标卡，分时趋势，以及自营游戏的下注人数分布。需要明细时从指标卡跳到对应查询页。网站中的菜单名称为“首页”。

页面面向桌面端，界面为简体中文。金额均为 USD 标准计价，人数和笔数为计数；指标卡金额保留 2 位小数，数字前显示 R$ 符号。指标卡的今日、昨日、本周、本月按服务端时间计算；分时图的起止日期按查看者浏览器时间计算。

本页只读。本页不提供导出、自定义指标和跨渠道对比。

## 2. 查询条件

切换条件后立即刷新，没有“查询”按钮。

| 条件 | 含义和填写规则 |
|---|---|
| 日期范围 | 单选：今日（默认）、昨日、本周、本月、全部。只影响指标卡 |
| 渠道 | 单选：全部渠道（默认）或推广渠道，已停用的渠道也可选。同时影响指标卡、分时数据和下注人数分布 |
| 分时时间范围 | 选择起止日期，默认今日；快捷项：今日、昨日、近 7 天、本周、本月。只影响分时数据 |
| 分时数据类型 | 单选，默认注册用户；可选注册用户、充值金额、充值笔数、提现金额、提现笔数、投注金额、投注笔数、派彩金额、平台盈亏 |

指标卡的本周从周一零点算到次日零点，本月从 1 号零点算到次日零点。分时快捷项“本周”和输赢卡下钻的“本周”从周日开始。

## 3. 结果字段

### 指标卡

卡片标题随日期范围变化，如“今日注册”“本周充值”。选择渠道时，只统计当前绑定该渠道的会员。

| 字段 | 含义 |
|---|---|
| 注册 | 期内创建的账号数，不排除游客和测试账号 |
| 充值 | 期内充值入账的 USD 标准金额合计，尚未换算的记录不计入 |
| 投注 | 期内投注扣款的 USD 标准金额合计，含自营和第三方游戏，取绝对值 |
| 输赢 | 投注金额减派彩金额。正数平台赢，显示绿色；负数平台输，显示红色 |

### 分时数据

每 10 分钟一个点，横轴显示时分，悬停显示月日时分。已结束的时段读取预先汇总的结果，当前未结束的时段实时计算为最后一个点。汇总完成后不再回算：之后才完成换算的账变不进入该时段金额；选择渠道时，已结束时段按汇总当时绑定该渠道的会员统计。

| 数据类型 | 含义 |
|---|---|
| 注册用户 | 时段内创建的账号数 |
| 充值金额、提现金额 | 时段内充值入账、提现扣款的 USD 标准金额，取绝对值 |
| 充值笔数、提现笔数 | 时段内对应账变的笔数，含尚未换算的记录 |
| 投注金额、派彩金额 | 时段内投注扣款、投注派彩的 USD 标准金额 |
| 投注笔数 | 时段内已完成换算的投注扣款笔数 |
| 平台盈亏 | 投注金额减派彩金额，正数平台赢 |

### 游戏下注人数分布

只统计 8 款自营游戏，不含第三方游戏，范围为全部历史，不受日期条件影响。

| 字段 | 含义 |
|---|---|
| 游戏 | 游戏代码，如 dice、crash，按下注人数降序 |
| 下注人数 | 该游戏的去重下注人数 |
| 占比 | 悬停显示该游戏人数除以总下注人数。一人玩多款时各项之和可超过 100%；扇区标签按各项人数之和计算 |
| 总下注人数 | 全部自营游戏的去重人数 |

## 4. 操作规则

点击指标卡数字跳转明细：

| 卡片 | 跳转 | 带入条件 |
|---|---|---|
| 注册 | 会员列表 | 渠道。日期范围不带入，列表按默认注册时间范围（近 90 天）显示 |
| 充值 | 账变记录 | 原因为充值入账。日期范围和渠道不带入 |
| 投注 | 账变记录 | 原因为投注扣款。日期范围和渠道不带入 |
| 输赢 | 投注明细 | 日期范围，选“全部”时不带日期；不带渠道 |

目标页按各自权限校验，无权限时进入无权限页。投注明细只列自营游戏，输赢卡含第三方游戏，两边合计不要求一致。

读取失败时弹出错误提示，指标卡显示 0，图表为空；不能据此判断实际为 0，须刷新确认。时段内没有业务数据时该点为 0；所选范围内没有汇总结果时图表为空。

持有 `dashboard:view` 的账号进入后台时默认落在本页，没有该权限时落在第一个有权限的页面。账号没有推广渠道查看或维护权限时，渠道下拉只有“全部渠道”，页面弹出错误提示，其他统计不受影响。

## 5. 验收场景

| 需求编号 | 场景与操作 | 预期结果 |
|---|---|---|
| 12.1-R1 | 打开页面 | 日期范围为今日，渠道为全部渠道，分时图显示今日注册用户 |
| 12.1-R2 | 切换日期范围为昨日 | 四张卡标题和数值切到昨日，分时图和下注分布不变 |
| 12.1-R3 | 选择一个渠道 | 指标卡和下注分布只统计当前绑定该渠道的会员；分时图当前时段按当前绑定统计，已结束时段按汇总当时的绑定统计 |
| 12.1-R4 | 有一笔充值尚未换算成 USD | 该笔不计入充值金额，计入充值笔数 |
| 12.1-R5 | 投注 100、派彩 130（均为 USD 标准金额） | 投注显示 R$ 100.00，输赢显示 R$ -30.00 且为红色 |
| 12.1-R6 | 分时范围包含当前时段 | 图表最后一个点为当前时段的实时值 |
| 12.1-R7 | 切换分时数据类型为提现金额 | 图表切换，悬停显示数据类型名称和金额 |
| 12.1-R8 | 同一玩家投注过两款自营游戏 | 两款各计 1 人，总下注人数计 1 人 |
| 12.1-R9 | 点击充值卡数字 | 进入账变记录，已带充值入账条件；当前不提供带入日期和渠道 |
| 12.1-R10 | 账号没有 `dashboard:view` | 菜单不显示，统计查询被服务端拒绝 |
