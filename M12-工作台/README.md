# M12 · 工作台

## 1. 定位与边界

**做什么**：后台日常入口。运营在首页看经营概况和分时趋势，客服在工作台处理玩家文字咨询。

**不做什么**
- 不做经营报表与导出。同期群和运营分析总表归 [M9 数据分析](../M9-数据分析/README.md)，明细查询归 [2.1 用户列表](../M2-用户管理/2.1-用户列表/README.md)、[2.2 账变记录](../M2-用户管理/2.2-账变记录/README.md) 和 [2.3 投注明细](../M2-用户管理/2.3-投注明细/README.md)。
- 不修改账务、用户或投注数据。首页只读。
- 不做工单、会话分配、转接、关闭、快捷回复、附件和会话搜索。客服只处理文字消息。

**铁律**
- **首页只读**，金额口径复用 [标准计价](../M2-用户管理/2.1-用户列表/标准计价.md)，不另定汇率。
- **客服消息只追加**，没有编辑和删除入口；同一条消息重试不产生第二条。

## 2. 术语表

| 术语 | 定义 | 代码标识 |
|---|---|---|
| 指标卡 | 首页四张汇总卡：注册、充值、投注、输赢 | 首页统计 |
| 分时数据 | 按 10 分钟分桶的趋势数据，已结束的分桶预先汇总，当前分桶实时计算 | 分时汇总 |
| 平台输赢 | 投注金额减派彩金额。正数表示平台赢 | 平台盈亏 |
| 会话 | 一名玩家与客服的唯一一条对话线，玩家首次发消息时创建 | 客服会话 |
| 已读进度 | 客服方或玩家方已读到的消息序号。全部客服共用一个客服方进度 | 已读序号 |
| 未确认送达 | 回复已提交但没有收到服务端确认，可以重试原消息 | — |

## 3. 依赖关系

- M5 财务管理：钱包账变与 USD 标准计价换算。

**下游被依赖（谁引用我）** ← 改会话或分时口径前先看这行
- 玩家端：读取客服回复、会话未读数和已读状态。
- 首页指标卡下钻到 2.1、2.2、2.3，只传查询条件，不写入这些页面的数据。
