# 12.2 · 客服工作台

## 1. 用途

客服在这里查看玩家从客服入口发来的文字咨询并回复。每名玩家只有一条会话，玩家首次发消息时创建，后续消息都进入同一会话。

页面面向桌面端，界面为简体中文，消息内容按原文显示。消息时间使用查看者浏览器时间。

本版只支持文字。不提供会话搜索、分配、转接、关闭、快捷回复、附件、消息编辑和删除。多名客服可同时处理同一会话。

## 2. 查询与处理信息

| 信息 | 含义和规则 |
|---|---|
| 会话列表 | 玩家会话，按最后消息时间倒序，每次加载 50 条，可“加载更多会话”。页头“刷新会话”和列表上方“刷新”都重新读取会话。页头显示“玩家文字咨询 · 共 N 个会话” |
| 玩家名称、UID | 玩家昵称和用户 ID |
| 未读数 | 玩家发来且客服方未读的消息数，大于 0 时显示“N 未读” |
| 最后消息、时间 | 会话最新一条消息的内容和时间，没有时显示“暂无消息” |
| 聊天记录 | 打开时显示最新 50 条，可“加载更早消息”每次再取 50 条。每条显示发送者名称、客服或玩家、时间。离开底部时可点“查看最新消息”回到最新 |
| 回复内容 | 文字必填，去首尾空格后 1～2000 字符，输入框显示已输入字数 |

没有选中会话时提示“选择左侧会话，查看消息并回复玩家。”。选中的会话记录在页面地址里，刷新后保持。

## 3. 处理规则

### 接收消息

玩家发送消息后，会话列表和当前会话实时更新。实时连接之外，页面每 30 秒、窗口重新获得焦点、网络恢复和连接重建时都补查一次，缺失的消息按序号补齐。页面不可见时暂停接收和补查，恢复可见后补查。

### 回复

持有回复权限的客服在当前会话输入文字，点“发送回复”或按 Ctrl / ⌘ + Enter 发送。回复以当前后台账号名称发出，玩家端未读数加 1。

提交后消息先显示“发送中…”，收到服务端确认后进入聊天记录。每次发送带唯一消息编号，同一编号重复到达时返回原消息，不产生第二条。

### 已读

聊天记录中的消息进入可视区域后，系统把客服方已读进度推进到该消息，未读数按剩余的玩家消息重算。已读进度只前进不后退，全部客服共用，一名客服读过后其他客服也不再显示未读。

### 权限

只有 `support:chat:view` 的账号显示“仅查看”，输入框禁用并提示“当前账号没有回复权限”；两项权限都有时显示“可回复”。标记已读只需要查看权限。实时推送每次下发前重新校验后台账号和权限，账号被限制或权限被移除后停止推送。

## 4. 特殊情况

| 情况 | 如何处理 |
|---|---|
| 回复未收到确认 | 消息保留并显示“未确认送达”，可“重试原消息”。重试沿用原消息编号，已送达时不重复 |
| 刷新页面时有未确认回复 | 回复在当前浏览器会话内保留，恢复后显示“未确认送达”，可继续重试 |
| 回复超过 2000 字符或全是空格 | 输入框限制 2000 字符；空内容不能发送，服务端同样拒绝 |
| 同一消息编号提交不同内容 | 服务端拒绝，不写入新消息 |
| 实时连接中断 | 显示“实时更新暂不可用，连接恢复后会自动补查。”，可“重新连接”；当前会话显示“实时消息连接暂不可用，恢复连接后会自动补查。”，可“补查消息” |
| 消息同步失败 | 提示“消息同步失败，请重试补查。发送失败的回复可单独重试。”，可“补查消息”，已加载的消息保留 |
| 更早消息加载失败 | 提示“历史消息加载失败，请重试加载更早消息。”，已加载的消息保留，可再次“加载更早消息” |
| 已读同步失败 | 提示“已读状态未同步。”，可“重试已读” |
| 会话列表加载失败 | 提示“会话加载失败，请重试。已加载的会话仍可查看。” |
| 地址里的会话不存在 | 消息同步失败，页面显示“玩家咨询”和“UID —”，不能成功回复 |
| 地址里的会话存在但不在已加载的列表中 | 消息正常加载，可以回复；加载到列表前页面显示“玩家咨询”和“UID —” |
| 暂无会话 | 列表显示“暂无玩家咨询” |

## 5. 验收场景

| 需求编号 | 场景与操作 | 预期结果 |
|---|---|---|
| 12.2-R1 | 玩家首次发送消息 | 新会话出现在列表顶部，未读数 1，内容与玩家发送一致 |
| 12.2-R2 | 同一玩家再次发送消息 | 仍是同一会话，未读数增加，会话回到顶部 |
| 12.2-R3 | 客服打开会话，未读消息进入可视区域 | 未读数清零，其他客服的列表同步清零 |
| 12.2-R4 | 持有回复权限的客服发送文字 | 消息进入聊天记录，发送者为当前账号，玩家端收到且未读数加 1 |
| 12.2-R5 | 回复请求超时后点“重试原消息”，原请求实际已写入 | 聊天记录只有一条该消息，“未确认送达”消失 |
| 12.2-R6 | 只有 `support:chat:view` 的账号打开会话 | 显示“仅查看”，能看消息和标记已读，不能发送；直接提交回复时服务端拒绝 |
| 12.2-R7 | 回复全空格或超过 2000 字符 | 不写入消息 |
| 12.2-R8 | 两名客服同时回复同一会话 | 两条消息都写入，序号连续不重复，两边显示顺序一致 |
| 12.2-R9 | 实时连接中断期间玩家发送消息，连接恢复 | 页面自动补查，消息按序号补齐 |
| 12.2-R10 | 没有 `support:chat:view` 的账号访问 | 菜单不显示，查询和实时推送被拒绝 |
