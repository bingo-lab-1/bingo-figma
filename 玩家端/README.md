# 玩家端 · 账户与个人服务

## 1. 定位与边界

本目录定义游戏端玩家本人可见的信息、操作与状态。当前覆盖Account首页及其二级页面、首页活动入口、在线客服、游戏大厅和活动中心,采用单一USD钱包。

资金、VIP、活动、代理规则继续分别由原业务模块维护。这里补充玩家操作流程与展示要求,不复制后台菜单,不把后台权限、风险标签、人工资金操作暴露给玩家。视觉布局与组件在Figma维护。

## 2. 术语

| 术语 | 本目录含义 |
|---|---|
| Account | 登录玩家的个人中心,连接资金、记录、统计、资料和客服 |
| 钱包 | 本期唯一USD钱包,本金、彩金、佣金是资金来源 |
| 活动中心 | 底部导航Promotions进入的页面,集中常用活动入口、充值入口和VIP升级奖励 |

## 3. 依赖关系

上游依赖:M2提供玩家档案及账户限制事实;M5提供钱包、充提订单及资金结果;M4提供VIP与个人活动权益;M7提供直属邀请关系与佣金;M10提供第三方游戏目录与供应商配置;M11提供首页活动入口与通知内容;M12提供客服侧处理。玩法提供个人投注和局结算事实;玩家账户服务提供登录与密码流程;支付服务提供支付跳转及支付状态。后三类服务的实现不在本仓库。

下游被依赖:游戏端导航、Account及相关二级页面的设计、开发和验收。M2、M4、M5、M7的依赖索引反向列出Account,规则变化须检查对应展示与操作。

## 4. 数据归属

玩家端页面只维护界面导航、筛选与展示状态,不另建余额、等级、奖励资格或佣金事实。所有提交交由所属业务服务执行,服务端按当前玩家鉴权。资料结果归玩家账户服务及M2,资金结果归M5,VIP与活动权益归M4,邀请关系与佣金归M7。

后台存在相似字段不等于已经具备玩家自助能力。缺少必需数据或受理能力时显示不可用,不得用占位成功状态替代交付。

## 6. 访问与操作边界

只允许玩家访问本人数据与订单。邀请佣金仅提供本人的汇总及直属昵称、绑定日期,不开放下级账户详情。修改链接或订单号不能访问其他玩家;登录失效后停止展示个人数据。玩家操作不使用M6后台角色权限码,也不继承运营可执行的补单、调级、清除打码或改余额能力。
