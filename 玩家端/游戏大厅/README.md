# 游戏大厅 · 首页与供应商游戏

## 1. 用途

当前主分支首页包含自营内容、推荐组件、投注表和供应商标识；供应商游戏目录位于 `/game-providers` 和 `/casino/provider-games`，Casino 首页还嵌入精简目录。没有新版首页按供应商分区的 Hot Games 布局。

第三方游戏使用 USD 钱包。客户端界面提供 en/tc；供应商游戏原名不强制翻译。首页静态推荐及 Live Wins 组件不能作为真实供应商中奖统计的依据。

## 2. 查询条件

| 条件 | 当前行为 |
|---|---|
| 会话 | 客户端仅在已登录时发起 ProviderGames 查询；未登录显示登录资格提示，精简目录隐藏 |
| 搜索 | 完整目录按游戏名和供应商名在已返回列表内匹配，不区分大小写 |
| 供应商筛选 | 当前组件没有单独的供应商筛选页签 |
| 精简目录 | Casino 中最多展示返回结果的前五个游戏 |

## 3. 结果字段

| 字段 | 含义 |
|---|---|
| 名称、供应商 | 目录返回值 |
| 缩略图 | 使用目录 thumbnail，缺图时显示名称占位；当前为 4:3 展示 |
| 维护状态 | 显示 Under maintenance，移除 Open game 链接 |
| 游戏启动页 | 名称、USD 标识、启动按钮、供应商 iframe、全屏和新窗口操作 |
| 最近供应商局 | 游戏页下方查询本人第三方局，显示游戏、原始状态和 USD 下注/派彩等信息 |

## 4. 操作规则

打开游戏路由后，玩家点击 Start game 才请求启动。请求最多等待 15 秒；失败统一显示检查账号权限及 USD 钱包后重试的提示，未按服务端每个稳定错误码映射专用文案。启动成功在沙箱 iframe 中打开，也可切到新窗口；切换账号时卸载旧 iframe 并终止原启动请求。

服务端核对第三方总开关、账号状态、上架、供应商启用及维护、USD 币种和钱包等条件，并限制同一账号 5 秒内重复启动。客户端链接或启动按钮不替代服务端资格检查。

游戏页立即、每 15 秒、窗口重新获得焦点或恢复可见时刷新本人钱包，页面隐藏期间跳过刷新。当前主分支没有新版供应商余额不足消息弹窗和 30 秒抑制交互。

完整目录提供加载、无结果及普通错误重试；401/403 显示资格提示。Casino 精简目录在未登录、空列表或无数据时不显示。主分支首页未使用该目录组件，不能把首页供应商标识当作实时游戏目录。

## 5. 验收场景

| 需求编号 | 场景与操作 | 预期结果 |
|---|---|---|
| 游戏大厅-R1 | 无会话打开供应商目录 | 客户端不查询目录，显示登录资格提示；精简区隐藏 |
| 游戏大厅-R2 | 游戏下架、供应商停用后直接请求启动 | 服务端按资格拒绝 |
| 游戏大厅-R3 | 目录游戏维护中 | 显示维护文字，没有 Open game 链接 |
| 游戏大厅-R4 | 无有效 USD 钱包等导致启动失败 | 显示通用失败文案，可重新启动 |
| 游戏大厅-R5 | 同一账号 5 秒内重复启动 | 后端频率限制生效 |
| 游戏大厅-R6 | 搜索游戏名、供应商名或无结果 | 在当前目录内匹配，无结果显示空状态 |
| 游戏大厅-R7 | 进入游戏页后隐藏再恢复窗口 | 钱包刷新跳过隐藏状态，恢复时再查；没有专用余额不足弹窗 |
| 游戏大厅-R8 | 目录发生普通网络错误 | 完整页提示失败和 Retry |
| 游戏大厅-R9 | Casino 精简目录超过五个结果 | 只展示前五个，View all 进入 `/game-providers` |
| 游戏大厅-R10 | 切换账号或 Casino 精简目录为空 | 旧游戏卸载；空精简区隐藏 |
