# 游戏大厅 · 首页大厅与第三方游戏目录

## 1. 用途

玩家在首页和Slots目录页浏览第三方游戏、按供应商查找并启动游戏。玩法规则、供应商结算不在本页。后台上架和排序见[第三方游戏](../../M10-游戏管理/10.3-第三方游戏/README.md)。

游戏目录不需要登录即可浏览，启动游戏需要登录会话。自动建号的游客有登录会话，可以启动。第三方游戏只使用USD钱包，只有Slot类型。界面支持英文和简体中文，游戏名称沿用供应商目录的名称，启动供应商游戏时语言固定为英文。

首页依次展示实时中奖条（LIVE WINS）、转盘Banner、快捷入口（Daily、7 Days、Spin、VIP、Support）、供应商导航（首项HOT）和Hot Games（右侧为[首页活动入口](../首页活动入口/README.md)）、邀请Banner（Refer a Friend、Affiliate Chest）、供应商分区、最近投注和供应商Logo墙。转盘Banner进入幸运转盘，邀请Banner进入邀请宝箱。实时中奖条和Logo墙是固定展示内容，不代表真实中奖记录或已开放供应商。首页不展示自营游戏列表，自营游戏在Casino页查看。Slots目录页顶部固定展示迎新Banner，VIEW REWARD进入Welcome gift活动页。

## 2. 查询条件

| 条件 | 含义和填写规则 |
|---|---|
| 供应商 | 首页点击供应商导航滚动到该供应商分区；Slots目录页按供应商页签切换，地址可带入供应商，无效值回到Hot Games |
| 搜索 | 目录搜索仅Slots目录页提供，输入框提示Search games or providers，按游戏名称或供应商名称匹配，不区分大小写，在当前页签内过滤。已登录玩家页头的搜索按钮打开Explore Games弹窗，弹窗只列固定的平台原创游戏，不读取第三方目录，也不按输入内容过滤 |

## 3. 结果字段

| 字段 | 含义 |
|---|---|
| 游戏范围 | 已上架、所属供应商已启用的Slot游戏 |
| 游戏排序 | 按后台展示排序，再按厂商和游戏名称排列 |
| 供应商排序 | 按后台供应商顺序，未排序的排在最后 |
| 供应商名称 | JILI、PG、PP、NetEnt统一显示简称，其他沿用供应商名称 |
| 封面 | 优先使用后台自定义封面，其次供应商封面，都没有时显示游戏名称 |
| 维护状态 | 维护中的游戏仍显示，卡片标注Under maintenance，不能点击 |
| Hot Games | 全部可见游戏；首页最多显示6个，提供View All进入Slots目录页 |
| 供应商分区 | 首页按供应商分区展示该供应商的前3个游戏，提供View All进入Slots目录页并选中该供应商；目录加载失败时不显示 |
| Casino页第三方游戏区 | 按供应商页签切换，最多显示6个，提供View All进入Slots目录页；目录为空或加载失败时不显示该区 |
| 最近投注 | 已登录时按时间倒序显示本人最近8条投注的游戏、币种和净输赢，表头为Game、Win，包含自营游戏和已结算的第三方游戏，每5秒刷新；页面不可见时暂停。没有记录时提示No bet records yet；加载失败时提示Bet records could not be loaded.并提供Try again。没有登录会话时提示登录 |

## 4. 操作规则

**启动。** 点击游戏卡片进入游戏页，服务端依次核对：第三方游戏已开启、账号未封禁、游戏已上架且供应商已启用且未维护、USD钱包和币种可用。同一账号5秒内只能启动一次。通过后在页内打开供应商游戏。没有登录会话时提示Log in to play并提供登录按钮，不启动。

**启动失败。** 15秒内没有结果、任一核对不通过或供应商未返回可用的游戏地址时，提示暂时无法启动，请确认账号已开通并有可用的USD钱包后重新载入。

**余额。** 游戏页顶部提供Deposit，打开充值弹窗，不离开游戏。游戏进行中每15秒、窗口重新获得焦点或页面恢复可见时刷新余额，页面不可见时暂停。供应商通知余额不足时弹出Insufficient balance，全屏时先退出全屏，可选择Deposit或Continue browsing；同一游戏30秒内只提示一次，提示关闭后重新计时，同一事件不重复提示，充值弹窗已打开时不再提示。

**加载状态。** 目录加载中显示Loading games…；加载失败提示Games are temporarily unavailable.并提供Retry，供应商导航只保留HOT；第三方游戏未开启时按加载失败处理；目录为空或搜索无结果时显示No games available.。

账号切换时关闭原游戏，按新账号重新启动。

## 5. 验收场景

| 需求编号 | 场景与操作 | 预期结果 |
|---|---|---|
| 游戏大厅-R1 | 未登录访客打开首页和Slots目录页 | 可浏览目录；最近投注提示登录；点击游戏提示登录，不启动 |
| 游戏大厅-R2 | 游戏未上架、供应商未启用，或非Slot类型 | 不出现在目录中，直接打开游戏地址也不能启动 |
| 游戏大厅-R3 | 游戏处于维护中 | 卡片标注Under maintenance，不能点击，服务端也拒绝启动 |
| 游戏大厅-R4 | 已封禁账号，或USD钱包不可用时启动 | 启动失败并提示，不进入游戏 |
| 游戏大厅-R5 | 5秒内连续启动 | 第二次被拒绝，提示暂时无法启动 |
| 游戏大厅-R6 | Slots目录页带无效供应商打开，或搜索无结果 | 前者回到Hot Games；后者显示No games available，不报错 |
| 游戏大厅-R7 | 玩家余额不足时下注，30秒内再次触发 | 弹出Insufficient balance一次；不重复弹出，同一事件不重复提示 |
| 游戏大厅-R8 | 第三方游戏未开启，或目录加载失败 | 提示暂时不可用并可重试，首页其他内容正常 |
| 游戏大厅-R9 | 首页某供应商的可见游戏超过3个，点击该分区的View All | 分区只显示前3个；进入Slots目录页并选中该供应商 |
| 游戏大厅-R10 | 打开Casino页时目录为空或加载失败 | 不显示第三方游戏区，Casino页其他内容正常 |

## 6. 相关资料
