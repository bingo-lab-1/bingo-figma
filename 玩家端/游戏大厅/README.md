# 游戏大厅 · 首页大厅与第三方游戏目录

## 1. 用途

玩家在首页和Slots目录页浏览第三方游戏、按供应商查找并启动游戏。玩法规则、供应商结算不在本页。后台上架和排序见[第三方游戏](../../M10-游戏管理/10.3-第三方游戏/README.md)。

游戏目录不需要登录即可浏览，启动游戏需要登录会话。自动建号的游客有登录会话，可以启动。第三方游戏只使用USD钱包，只有Slot类型。界面支持英文和繁体中文，游戏名称沿用供应商目录的名称。

首页依次展示实时中奖条、转盘Banner、快捷入口（Daily、7 Days、Spin、VIP、Support）、第三方游戏区、邀请Banner、最近投注和供应商Logo墙。实时中奖条和Logo墙是固定展示内容，不代表真实中奖记录或已开放供应商。

## 2. 查询条件

| 条件 | 含义和填写规则 |
|---|---|
| 供应商 | 首页点击供应商导航滚动到该供应商分区；Slots目录页按供应商页签切换，地址可带入供应商，无效值回到Hot Games |
| 搜索 | 仅Slots目录页提供，按游戏名称或供应商名称匹配，不区分大小写，在当前页签内过滤 |

## 3. 结果字段

| 字段 | 含义 |
|---|---|
| 游戏范围 | 已上架、所属供应商已启用的Slot游戏 |
| 游戏排序 | 按后台展示排序，再按厂商和游戏名称排列 |
| 供应商排序 | 按后台供应商顺序，未排序的排在最后 |
| 供应商名称 | JILI、PG、PP、NetEnt统一显示简称，其他沿用供应商名称 |
| 封面 | 优先使用后台自定义封面，没有封面时显示游戏名称 |
| 维护状态 | 维护中的游戏仍显示，卡片标注Under maintenance，不能点击 |
| Hot Games | 全部可见游戏；首页最多显示6个，提供查看全部进入Slots目录页 |
| 供应商分区 | 首页按供应商分区展示该供应商的游戏 |
| 最近投注 | 已登录时显示本人最近8条投注的游戏、时间和净输赢，每5秒刷新；页面不可见时暂停。没有登录会话时提示登录 |

## 4. 操作规则

**启动。** 点击游戏卡片进入游戏页，服务端依次核对：第三方游戏已开启、账号未封禁、游戏已上架且供应商已启用且未维护、USD钱包和币种可用。同一账号5秒内只能启动一次。通过后在页内打开供应商游戏。没有登录会话时提示Log in to play并提供登录按钮，不启动。

**启动失败。** 15秒内没有结果或任一核对不通过时，提示暂时无法启动，请确认账号已开通并有可用的USD钱包后重新载入。

**余额。** 游戏页顶部提供Deposit，打开充值弹窗，不离开游戏。游戏进行中每15秒、窗口重新获得焦点时刷新余额。供应商通知余额不足时弹出Insufficient balance，可选择Deposit或Continue browsing；同一游戏30秒内只提示一次，同一事件不重复提示，充值弹窗已打开时不再提示。

**加载状态。** 目录加载中显示Loading games…；加载失败提示Games are temporarily unavailable并提供重试；第三方游戏未开启时按加载失败处理。

账号切换时关闭原游戏，按新账号重新启动。

## 5. 验收场景

| 需求编号 | 场景与操作 | 预期结果 |
|---|---|---|
| 游戏大厅-R1 | 未登录访客打开首页和Slots目录页 | 可浏览目录；最近投注提示登录；点击游戏提示登录，不启动 |
| 游戏大厅-R2 | 游戏未上架、供应商未启用，或非Slot类型 | 不出现在目录中，直接打开游戏地址也不能启动 |
| 游戏大厅-R3 | 游戏处于维护中 | 卡片标注Under maintenance，不能点击，服务端也拒绝启动 |
| 游戏大厅-R4 | 已封禁账号，或USD钱包不可用时启动 | 启动失败并提示，不进入游戏 |
| 游戏大厅-R5 | 5秒内连续启动 | 第二次被拒绝，提示暂时无法启动 |
| 游戏大厅-R6 | Slots目录页带无效供应商打开，或搜索无结果 | 前者回到Hot Games；后者显示空结果，不报错 |
| 游戏大厅-R7 | 玩家余额不足时下注，30秒内再次触发 | 弹出Insufficient balance一次；不重复弹出，同一事件不重复提示 |
| 游戏大厅-R8 | 第三方游戏未开启，或目录加载失败 | 提示暂时不可用并可重试，首页其他内容正常 |
