# 首页活动入口 · 首页 Hot Games 活动入口

## 1. 用途

玩家在首页 Hot Games 区域右侧看到运营配置的活动入口，点击后进入站内活动页。入口内容由后台[首页活动配置](../../M11-内容管理/11.4-首页活动配置/README.md)维护，本页只说明玩家看到什么、怎样操作。

适用于玩家端首页，桌面与移动端相同，不涉及金额。未登录访客和已登录玩家看到同一份配置。本版不按用户、渠道或时间投放，也不提供外部链接。

## 2. 查询条件

| 条件 | 含义和填写规则 |
|---|---|
| 访问者 | 不需要登录，不按身份筛选 |
| 语言 | 繁体中文站点显示繁体名称，英文站点显示英文名称 |

## 3. 结果字段

| 字段 | 含义 |
|---|---|
| 活动图标 | 运营上传的图片 |
| 入口名称 | 按站点语言取英文或繁体名称 |
| 跳转路径 | 站内路径，点击后进入 |
| 顺序 | 按配置顺序从上到下，最多 3 个 |

## 4. 操作规则

打开首页时读取当前配置。没有配置时不显示入口区域，游戏列表占满宽度。

点击入口进入配置的站内路径。每个入口带一个关闭按钮，关闭后该入口在当前页面隐藏，不写入服务端；刷新或重新进入首页后恢复显示。全部关闭后入口区域收起。

读取配置失败，或已保存的配置无法通过校验时，不显示入口区域，首页其他内容照常展示，不向玩家报错。

运营保存新配置后，玩家下次打开首页看到新内容，已打开的页面不实时更新。

## 5. 验收场景

| 需求编号 | 场景与操作 | 预期结果 |
|---|---|---|
| 首页活动入口-R1 | 运营配置 3 个入口，未登录访客分别用英文和繁体打开首页 | 按配置顺序显示 3 个入口，名称随语言切换，点击进入对应站内页 |
| 首页活动入口-R2 | 点击某个入口的关闭按钮，再刷新页面 | 关闭后该入口隐藏，其余入口不变；刷新后恢复 |
| 首页活动入口-R3 | 配置为空，或关闭全部入口 | 不显示入口区域，游戏列表占满宽度 |
| 首页活动入口-R4 | 读取配置失败，或已保存的配置内容无效 | 不显示入口区域，首页其他内容正常，不提示错误 |

## 6. 相关资料

- 入口：玩家端首页 Hot Games 区域右侧。
- 权限：玩家查看无需登录；后台配置权限见[首页活动配置](../../M11-内容管理/11.4-首页活动配置/README.md)。
- 数据归属：入口内容归 M11 内容管理，活动规则归各活动页面。
- Jira：见首页活动入口对应任务。
