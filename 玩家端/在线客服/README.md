# 在线客服 · 主分支入口与服务端能力

## 1. 用途

当前玩家主分支有 Support 浮动条，点击后展开 Email、Line、Talk、Telegram 四项图标文字，点击外部收起。这四项没有聊天、邮件或外部跳转动作。侧边栏 Live Support 也没有有效目标。主分支没有 Live Chat 会话界面、消息查询或发送接入。

后端和运营后台已提供真实客服能力。以下记录该服务契约，不能据此声称玩家主分支已支持文字、图片、已读或实时收发。

## 2. 查询与处理信息

| 能力 | 当前所在层及范围 |
|---|---|
| Support 浮动条 | 玩家主分支仅展示静态渠道项目 |
| 本人会话和消息 | 后端支持，玩家主分支未消费 |
| 消息文本 | 后端去首尾空格，最多 2000 字符；没有图片时不能为空 |
| 图片 | 后端每条最多 3 张，单张最多 5 MiB、边长不超过 4096 px 的静态 PNG/JPEG/WebP |
| 已读与未读 | 后端记录本人已读进度；当前主分支不展示未读数 |
| 客服工作台 | 已接入会话、回复、图片、状态、分类及自动回复配置 |

## 3. 处理规则

玩家服务端接口需要本人登录会话。每玩家一条会话，首次发送时创建；仅打开或查询不创建。发送使用客户端消息编号，同编号且同内容返回原结果，不重复生成消息；身份来自会话，调用者不能指定另一发送人。已读进度只前进，不后退。

后端支持实时消息通知、按序号补查与更早消息查询；当前玩家主分支没有相关订阅、30 秒补查、失败重试气泡或已读交互。

每账号每小时最多申请 30 次图片上传，签名图片地址最长 5 分钟。超过 90 天的消息由归档任务隐藏，停止签发新图片地址，已发地址在原有效期内仍可能可访问。自动接待语、关键词规则和人工回复后的抑制规则见客服工作台。已解决会话收到新消息时重开原会话。

## 4. 特殊情况

| 情况 | 实际行为 |
|---|---|
| 点击 Email/Line/Talk/Telegram | 只展示项目，没有发送或导航动作 |
| 未登录直接调用本人客服接口 | 服务端拒绝；主分支没有专用聊天登录页 |
| 超长文字、超数或不合规图片 | 服务端校验拒绝，不写入有效消息 |
| 相同消息编号但不同内容 | 幂等冲突，不覆盖原消息 |
| 服务端已有消息 | 不表示当前主分支存在可浏览的聊天记录页 |

## 5. 验收场景

| 需求编号 | 场景与操作 | 预期结果 |
|---|---|---|
| 在线客服-R1 | 点击主分支 Support | 展开四个静态渠道项目，不创建会话 |
| 在线客服-R2 | 无会话调用发送接口 | 鉴权拒绝 |
| 在线客服-R3 | 经接口提交空白无图或超长文字 | 拒绝；合规纯图片消息可受理 |
| 在线客服-R4 | 经接口重复提交同编号同内容 | 只产生一条消息 |
| 在线客服-R5 | 后台回复后查看主分支 | 主分支没有未读徽标或 Live Chat 消息界面 |
| 在线客服-R6 | 查找前端客服实时重连逻辑 | 当前主分支未接入，不能承诺自动补齐 |
| 在线客服-R7 | 经接口查询更早消息 | 按服务端分页契约返回；不是已交付的 Load earlier 按钮 |
| 在线客服-R8 | 点击展开的外部渠道项目 | 没有跳转或发送 |
| 在线客服-R9 | 用另一玩家会话查询 | 只能取得本人会话 |
| 在线客服-R10 | 提交第四张图片或超限文件 | 服务端拒绝，未形成有效消息 |
| 在线客服-R11 | 后台触发自动回复及人工回复 | 服务端保留来源区别，玩家主分支尚无展示 |
| 在线客服-R12 | 已解决会话再发送、查询已归档消息 | 原会话重开；归档消息不返回，不签发新图片地址 |
