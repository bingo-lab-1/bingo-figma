# 奖励记录接口与页面边界

后端已提供本人成功奖励历史查询，玩家主分支尚未接入统一页面，没有 `/account/rewards` 路由。以下说明后端契约，不表示已有对应列表、日期快捷选项或活动 History 入口。

## 查询范围

调用方须提供开始日和结束日；开始不得晚于结束，不能选未来日期。类型可选，未传时查询全部支持类型。默认每页 20 条，可传 1 至 100 的整数；按账变时间倒序、相同时间按账变 ID 升序排列。游标绑定账号、日期及类型，更换条件后不能复用。

服务端以业务时区把开始日转换为含边界的开始时间，把结束日次日转换为不含边界的结束时间。响应包含业务时区与今天日期，供后续界面使用；当前主分支没有对应的按日分组展示。金额保持奖励原币种及其配置精度，不合成一个跨币种总金额。

## 奖励类型

| 类型值 | 展示业务 |
|---|---|
| welcomeGift | 注册赠金 |
| depositBonus | 充值赠送 |
| firstDepositRelief | 首充破产补助 |
| dailyCheckIn | 每日签到 |
| signInRewards | VIP 签到 |
| sevenDayCheckIn | 常规七日签到 |
| luckyWheel | 幸运转盘 |
| inviteSpin | 拼多多转盘 |
| inviteChest | 邀请宝箱 |
| cashDrop | 红包雨 |
| scratchCard | 刮刮乐 |
| betRanking | 排行榜奖励 |
| vipReward | VIP 奖励 |
| redeemCode | 兑换码 |

只读取已成功账务操作中受支持来源的赠金及 VIP 奖励账变，并排除已有冲销的记录。待处理、失败、未领取权益、转盘券、人工调账和代理佣金不属于这个成功列表。接口返回来源类型和来源编号；玩家主分支没有从统一列表跳转活动详情的交互。

## 状态与边界

查询按当前认证玩家限定记录。非法日期、未来日期、无效类型、超限页大小或不匹配的游标均拒绝。此接口是只读查询，不触发奖励领取或补发。

## 验收依据

验证三类签到独立筛选、跨业务日边界、今天和未来日期、空列表、非法参数、超过一页、同一时间多记录、跨账号游标、冲销与混合币种。已到账金额必须能追溯到实际账变，列表出现一条记录不能视为新增发钱。
